## Novera 1.0.1

Novera 1.0.1 พร้อมใช้งานสำหรับแพลตฟอร์มที่แสดงด้านล่าง ดาวน์โหลดแพ็คเกจสำหรับระบบของคุณหรือใช้ช่องทางการอัพเดตที่เซ็นชื่อ การอัปเดตการติดตั้งที่มีอยู่เมื่อคุณติดตั้งแพ็คเกจใหม่หรือยอมรับการอัปเดต

- การรักษาความปลอดภัย: การอนุญาตดั้งเดิมที่เข้มงวดมากขึ้นสำหรับเพจระยะไกล การตรวจสอบสิทธิ์สำหรับ API เครือข่ายและเครื่องมือเซิร์ฟเวอร์ พื้นที่เก็บข้อมูลลับที่มีการป้องกันและการย้ายข้อมูล การเข้าถึงไฟล์/สื่อที่ปลอดภัยยิ่งขึ้น การแยกวิเคราะห์สเปรดชีตและสร้างสคริปต์ การขึ้นต่อกันที่เปิดเผยได้รับการอัปเดตแล้ว คำแนะนำที่เหลือจะถูกติดตามอย่างเปิดเผย
- ความเป็นส่วนตัว: สถิติและรายงานข้อผิดพลาดจำเป็นต้องได้รับความยินยอมแยกต่างหาก และจะปิดไว้ตามค่าเริ่มต้น บิวด์ประกอบด้วยการกำหนดค่าปลายทางที่บันทึกไว้ การวินิจฉัยทางเทคนิคจะถูกกรอง ผู้ใช้ควบคุมการเปิดใช้งาน
- เครื่องยนต์ท้องถิ่น: `llama.cpp v0.9.0` (`b12110`, `cd959bae99ff4bed22bef2604f45241c09bbb8c8`) เวอร์ชันเครื่องยนต์และเวอร์ชันแอปพลิเคชันแยกจากกัน การตั้งค่ารุ่นเริ่มต้นและการลงทะเบียนรุ่น/โปรเจ็กเตอร์ได้รับการแก้ไขแล้ว รวมถึงความล้มเหลวในการเริ่มต้นที่เกี่ยวข้องกับ `kv_unified` การตั้งค่าส่วนบุคคลที่มีอยู่จะยังคงอยู่
- ภาษา: 24 ภาษาและตัวแปรเพิ่มเติมนำอินเทอร์เฟซและคอลเล็กชัน README ที่แปลแล้วมาสู่ 104 โดยมีคีย์อินเทอร์เฟซ 2,435 ต่อแค็ตตาล็อก ความครอบคลุมนี้ไม่รับรองคุณภาพบทบรรณาธิการเจ้าของภาษาหรือการสนับสนุนคำพูดในทุกภาษา
- **LFM3-Omni-2B Q4_K_M** — โมเดลค่าเริ่มต้นบนเดสก์ท็อปกับมือถือ โมเดลขนาดเล็กสำหรับข้อความ รูปภาพ และเสียง ต้องมีไฟล์ `mmproj` ดาวน์โหลดสองไฟล์รวมประมาณ 1.39 GB เลือกใช้สำหรับระบบหลายสื่อที่เบากว่า ฟังก์ชันเสียงขึ้นอยู่กับแพลตฟอร์มและเอนจิน บริบทที่ยาวขึ้นใช้หน่วยความจำหลายขึ้น

| --- | --- |
| **1. เริ่ม** | เลือกภาษาของระบบที่รองรับตั้งแต่เปิดตัวครั้งแรกและบันทึกการตั้งค่าของคุณ นำเสนอโมเดลเริ่มต้นและข้อมูลฮาร์ดแวร์ที่เป็นประโยชน์ |
| **2. เตรียม** | การติดตั้งพร้อมคำแนะนำมีทั้งข้อความ การฝัง รูปภาพ เพลง วิดีโอ และการขยายขนาด โดยจะแสดงตัวอย่างส่วนประกอบ ขนาด และพื้นที่ว่างก่อนที่คุณจะอนุมัติ จากนั้นติดตามการดาวน์โหลดพร้อมความคืบหน้า หยุดชั่วคราว/ดำเนินการต่อ และการตรวจสอบ SHA-256 |
| **3. ตั้งค่า** | ลงทะเบียนโมเดลและส่วนประกอบต่างๆ เตรียมโปรไฟล์ที่เกี่ยวข้องและรายงานการขึ้นต่อกันที่จำเป็น การฝังการดึงข้อมูลเริ่มต้นบน CPU ด้วยตัวเลือก CPU/GPU ที่บันทึกไว้ โปรไฟล์เพลงใหม่มีค่าเริ่มต้นเป็นโหมดเครื่องดนตรี |

| **5. เฮ็ด** | หน่วยความจำอัตโนมัติจะรอการทำงานที่ใช้งานอยู่ เผยแพร่โมเดลที่ไม่จำเป็น และรีโหลดทรัพยากรที่จำเป็น ชุดงาน 1–10 จะรันตามลำดับและรีลีสรีซอร์สก่อนงานถัดไป ผู้ให้บริการคลาวด์ใช้บัญชีและการกำหนดค่าที่เลือก |

การครอบคลุมทางเทคนิคนี้บ่รับรองคุณภาพทางภาษา: **การตรวจสอบดั้งเดิมและการปรับให้เข้ากับภูมิภาคยังจำเป็น**. ดู label ดั้งเดิมและขีดจำกัดที่ฮู้ใน [คู่มือภาษา](docs/LANGUAGES.md) และ [รายงานการตรวจสอบ](deliverables/interface-audit-2026-10-29/RAPPORT.md).

## ช่วยผู้คน ในทุกภาคส่วน

นอกเหนือจากโรงเรียนและการศึกษาแล้ว ความทะเยอทะยานของเราคือการช่วยให้ผู้คนเรียนรู้ แก้ปัญหา สร้างและพัฒนาโครงการที่เป็นประโยชน์ทั่วโลก Novera มุ่งหวังที่จะทำให้ความก้าวหน้าของ AI ในปัจจุบันง่ายต่อการเข้าใจและใช้งาน ข้ามภาษา ระดับประสบการณ์ และฮาร์ดแวร์ที่มีอยู่

| ภาคส่วนที่เฮาอยากช่วยพัฒนา | ตัวอย่างการมีส่วนร่วมที่เป็นประโยชน์ |
| --- | --- |
| โรงเรียน การศึกษา และการเรียนรู้ตลอดชีวิต | อธิบายแนวคิด ปรับใช้สื่อการเรียนรู้ และสนับสนุนครู นักเรียน และครอบครัว |
| วิจัย วิทยาศาสตร์ และอวกาศ | สำรวจวรรณกรรม อธิบายวิธีการ วิเคราะห์ข้อมูล และแบ่งปันความรู้ |
| สุขภาพ การดูแล และการสนับสนุนทางสังคม | ทำให้ข้อมูลเข้าใจง่ายขึ้นและสนับสนุนการวิจัยและขั้นตอนการทำงานระดับมืออาชีพ |
| เกษตรกรรม อาหาร และชุมชนชนบท | แบ่งปันความรู้เชิงปฏิบัติ สนับสนุนการวางแผน และพัฒนาเครื่องมือที่มีประโยชน์ในท้องถิ่น |
| สิ่งแวดล้อม สภาพภูมิอากาศ น้ำ และความหลากหลายทางชีวภาพ | อธิบายหลักฐาน สนับสนุนการสังเกต และช่วยเหลือชุมชนในการวางแผนโครงการ |
| พลังงาน อุตสาหกรรม การก่อสร้าง และงานฝีมือ | สนับสนุนเอกสาร การออกแบบ การบำรุงรักษา การเรียนรู้ทางเทคนิค และการปรับปรุงกระบวนการ |
| ธุรกิจ การค้า การเงิน และการจ้างงาน | ช่วยจัดระเบียบงาน ทำความเข้าใจข้อมูล พัฒนาโครงการ และเรียนรู้ทักษะทางวิชาชีพ |
| บริการสาธารณะ กฎหมาย และการมีส่วนร่วมของพลเมือง | ทำให้เอกสารและขั้นตอนต่างๆ เข้าใจง่ายขึ้น และเข้าถึงข้อมูลได้ง่ายขึ้น |
| คอมพิวติ้ง, cybersecurity, robotics และ telecommunications | ช่วยพัฒนาซอฟต์แวร์ ทำความเข้าใจระบบ และสร้างเครื่องมือที่มีประโยชน์ |
| ศิลปะ วัฒนธรรม สื่อ ภาษา และมรดก | รองรับการเขียน การแปล รูปภาพ วิดีโอ โครงการสร้างสรรค์ และการแบ่งปันวัฒนธรรม |
| การขนส่ง โลจิสติกส์ การท่องเที่ยว กีฬา และชีวิตชุมชน | ช่วยเหลือในการวางแผน การสื่อสาร การเรียนรู้ และการริเริ่มในท้องถิ่น |
| การเข้าถึง งานด้านมนุษยธรรม และชีวิตประจำวัน | ลดอุปสรรคด้านภาษาและความรู้ และสนับสนุนผู้คนด้วยความช่วยเหลือในทางปฏิบัติ |

นี่เป็นแนวทางสำหรับการสนับสนุนและการพัฒนา ไม่ใช่การอ้างว่าแอปพลิเคชันเฉพาะภาคส่วนทุกรายการได้รับการจัดส่งหรือตรวจสอบแล้ว เราต้องการคำแนะนำง่ายๆ สำหรับการใช้งานในชีวิตประจำวัน ตัวเลือกขั้นสูงที่ชัดเจนเมื่อจำเป็น ข้อกำหนดด้านฮาร์ดแวร์และระบบคลาวด์ที่โปร่งใส และการทำงานร่วมกับบุคคลที่รู้แต่ละสาขาและบริบทท้องถิ่น

## สถานะโครงการ

ภาพหน้าจอแสดงแอปพลิเคชัน Windows ที่รวบรวมในเครื่องโดยผู้ดูแล การเปลี่ยนแปลงแหล่งที่มา การทดสอบเป้าหมาย และการตรวจสอบความถูกต้องของฮาร์ดแวร์ได้รับการจัดทำเป็นเอกสารแยกต่างหาก สิ่งนี้ไม่ได้ตรวจสอบทุกโมเดล แพลตฟอร์ม หรือบัญชีคลาวด์

บิลด์ GitHub Actions แบบแมนนวลเปิดใช้งานแล้วสำหรับตัวแปรการแจกจ่ายทั้ง 11 แบบ ปฏิบัติตาม [ผลลัพธ์ build และดาวน์โหลดผู้สมัครที่ตรวจสอบแล้ว](docs/CI_DISTRIBUTIONS.md); ความพร้อมใช้งานจะถูกบันทึกแยกกันสำหรับแต่ละแพลตฟอร์ม ผู้สมัครจะแตกต่างจากการเปิดตัวการผลิตที่มีการลงนาม ข้อกำหนดการจัดจำหน่ายมีอธิบายไว้ใน [นโยบายการปล่อยเวอร์ชันอย่างเป็นทางการ](OFFICIAL_RELEASES.md) และ [หน้า releases](https://github.com/TRON-ABS/Novera/releases). ผู้สมัครที่ปิดการใช้งานตัวอัพเดตที่มีอยู่ยังคงอยู่ภายใน การเผยแพร่สู่สาธารณะจำเป็นต้องมีกลไกการอัปเดตที่ได้รับการกำหนดค่าและตรวจสอบแล้ว [การตรวจสอบลายเซ็นเดสก์ท็อปและข้อกำหนดการเปิดใช้งานที่เหลือได้รับการบันทึกไว้](docs/LAUNCH_STATUS.md).
