## Novera 1.0.1

Novera 1.0.1 iyatholakala ezinkundleni ezibalwe ngezansi. Dawuniloda iphakheji yesistimu yakho noma usebenzise isiteshi sayo sokubuyekeza esisayiniwe. Ukufakwa okukhona kubuyekezwa uma ufaka iphakheji entsha noma wamukela isibuyekezo.

- Ukuphepha: izimvume zomdabu eziqinile zamakhasi akude, ukufakazela ubuqiniso kwama-API enethiwekhi namathuluzi eseva, isitoreji esiyimfihlo esivikelwe kanye nokuthutha, ukufinyelela kwefayela/imidiya okuphephile, ukuncozululwa kwesipredishithi nokwakha imibhalo. Ukuncika okuveziwe kubuyekeziwe; izeluleko ezisele zilandelwa ngokusobala.
- Ubumfihlo: izibalo nemibiko yamaphutha idinga imvume ehlukene futhi ihlale ivaliwe ngokuzenzakalela. Izakhiwo zihlanganisa ukulungiselelwa kwendawo okuyiwa kuyo okubhaliwe. Ukuxilonga kobuchwepheshe kuyahlungwa; abasebenzisi bagcina ukulawula kokuvula.
- Injini yendawo: `llama.cpp v0.9.0` (`b12110`, `cd959bae99ff4bed22bef2604f45241c09bbb8c8`). Inguqulo yenjini nenguqulo yohlelo lokusebenza zihlukene. Izilungiselelo zokuqala zemodeli nokubhaliswa kwemodeli/iphrojekthi kuyalungiswa, okuhlanganisa nokuhluleka kokuqala okubandakanya i-`kv_unified`. Izilungiselelo zomuntu siqu ezikhona zigciniwe.
- Izilimi: 24 izilimi ezengeziwe nokuhluka kuletha isixhumi esibonakalayo kanye nokuhunyushwa kweqoqo le-README kokuthi 104, ngokhiye bokusebenzelana be-2,435 kukhathalogi ngayinye. Lokhu kufakwa akuyiqinisekisi ikhwalithi yokuhlela yomdabu noma ukwesekwa kwenkulumo kuzo zonke izilimi.

Landa: cishe 1.39 GB kuwo womabili amafayela. Ikhethele ukusethwa kwe-multimodal okulula. Izici zezwi zincike endaweni kanye nenjini. Umongo omude usebenzisa inkumbulo eyengeziwe.
- **NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M** — Enye indlela yombhalo kuphela yengxoxo, ukubhala, amathuluzi nezimpendulo ezihlelekile. Landa: cishe 6.18 GB. Idinga inkumbulo eningi kune-LFM3-Omni futhi ayicubunguli izithombe noma umsindo ngokwawo. Izimpendulo ezikhulunywayo zisebenzisa izwi lesistimu. Ikhethele imisebenzi yombhalo uma unememori eyanele. ## Kusukela ekuqalisweni kokuqala kuya emiphumeleni

**Imishini yethu ezenzakalelayo ixhuma ukulungiselela nokugeleza komsebenzi okuphelele.** Novera iphatha izinyathelo zobuchwepheshe ezitholakalayo zokucushwa okukhethiwe, kuyilapho igcina izilawuli ezithuthukisiwe zifinyeleleka.

| Isinyathelo | Yiziphi izibambo ezingu-Novera |
| --- | --- |
| **1. Qala** | Ikhetha ulimi lwesistimu olusekelwe ekuqaleni futhi ilondoloza okuncamelayo. Iphrezenta amamodeli aqalayo kanye nolwazi oluwusizo lwehadiwe. |
| **2. Lungiselela** | Ukufakwa okuqondisiwe kunikeza umbhalo, ukushumeka, isithombe, umculo, ividiyo nokukhushulwa. Ihlola kuqala izingxenye, osayizi nesikhala esikhululekile ngaphambi kwemvume yakho, bese ilandelela ukulanda ngokuqhubekayo, misa isikhashana/qalisa kabusha kanye no-SHA-256 ukuqinisekiswa. |
| **3. Lungiselela** | Ibhalisa amamodeli nezingxenye zawo, ilungiselela amaphrofayili afanele kanye nemibiko okuncika okudingekayo. Ukushumeka kokubuyisa kuqala ku-CPU ngokukhetha okulondoloziwe okungu-CPU/GPU. Amaphrofayili omculo amasha azenzakalelayo abe yimodi yezinsimbi. |
| **4. Qonda isicelo** | Imizila ezenzakalelayo ibona izicelo zokudala zombhalo, isithombe, umculo noma ividiyo. Ungaphinda ukhethe ngokusobala imodi yokukhipha kanye nemodeli yendawo noma yamafu. |
| **5. Sebenzisa** | Inkumbulo ezenzakalelayo ilinda umsebenzi osebenzayo, ikhiphe amamodeli angadingeki futhi ilayishe kabusha izinsiza ezidingekayo. Uchungechunge lwemisebenzi engu-1–10 luhamba ngokulandelana futhi lukhipha izinsiza ngaphambi komsebenzi olandelayo. Abahlinzeki bamafu basebenzisa i-akhawunti ekhethiwe kanye nokucushwa. |
| **6. Buyisa futhi usebenzise kabusha** | Ilondoloza imidiya kumafolda esistimu angu-Novera, ibonisa imiphumela nezikhathi ezitholakalayo, bese inikeza okuhlukile, umtapo wolwazi, ukukopisha, ukuthumela ngaphandle noma ukwabelana ngesistimu. Ukuthumela kolunye uhlelo lokusebenza kuhlala kuyisenzo sakho. |

I-Automation ihlanganisa izinjini ezihlanganisiwe nokugeleza komsebenzi; ayenzi yonke imodeli ye-Hub isebenziseke. Izingxenyekazi zekhompuyutha, izingxenye ezifakiwe nokufinyelela komhlinzeki kunquma ukuthi yini engasebenza. Amafolda, izinguquko zefayela nemiyalo yegobolondo kulandela izibonelelo zokufinyelela zengxoxo.

## Ihabhu namamodeli ahambisanayo

**GGUF, okujwayelekile kanye nenani Safetensors, ONNX, kanye MLX**: hlola amamodeli ngomsebenzi bese ukhetha okuhlukile okuhambisana nenjini nehadiwe yakho.

| Umndeni | Ukusekela emthonjeni | Izidingo |
| --- | --- | --- |
| **GGUF** | Ukwenziwa kombhalo ngokusebenzisa llama.cpp; izingxenye zesithombe nevidiyo zamaphrofayili asekelwayo. | I-Architecture ebonwa injini ehlanganisiwe. |
| **Hlukanisa GGUF** | Okuhlukile okukodwa ngochungechunge oluphelele, usayizi ofingqiwe, ukulanda kwe-shard kanye nosayizi/SHA-256/ukuhlolwa kwesihloko. | Amagama wefayela anezinombolo ezijwayelekile; ukulanda 500 GB akusho ukuthi imodeli ilingana nale PC. |
| **Standard Safetensors** | Gcwalisa amafolda ngokuthi Transformers, umbhalo oyisizathu kokuthi CPU noma NVIDIA CUDA. | Ukucushwa, i-tokenizer kanye nawo wonke ama-shard adingekayo. |
| **ONNX Runtime** | Ukungenisa kwendawo kwamagrafu ezinombolo/e-bool futhi kwalungiselelwa ukuthunyelwa ngaphandle kombhalo okungu-GenAI. | Ifolda ephelele eqinisekisiwe; ukucubungula kwangaphambili/ukucubungula kwangemuva komsebenzi okudingekayo; [ukusetha kanye nemikhawulo](onnx-server/README.md). |
| **LoRA / PEFT ama-adaptha** | Ngenisa isisekelo esiphelele esine-adaptha yasendaweni ehlukile kumhlinzeki we-Safetensors. | Isizathu esingenakulinganiswa Transformers isisekelo, ubunikazi obufanayo, amasheke we-tensor kanye nesilinganiso senkumbulo esinqwabelene; [ukusetha kanye nemikhawulo](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | Ukukhishwa kwe-Native CUDA kokunye okuhambisanayo Llama/Qwen2/Qwen3 per-tensor FP8 ukuthunyelwa ngaphandle. | Ukuhlolwa kwe-Architecture/tensor kanye ne-kernel probe yangempela; [ukusetha kanye nemikhawulo](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |
| **NVFP4 LLM / ModelOpt** | Ibhulokhi epakishiwe-16 FP4 izilinganiso ngama-GEMM omdabu angu-CUDA; hlukana nesithombe NVFP4. | Iyahambisana Blackwell GPU, ubukhulu obusekelwe/ukuthekelisa kanye nophenyo lwangempela lwe-kernel; amamodeli okuhlola angaqeqeshiwe zihlolwe ku-RTX 5070. |
| **AWQ** | 4-bit GEMM imodeli yezindawo zokuhlola ngaphandle kokuhlanganiswa kokusebenza. | NVIDIA CUDA kanye nezilayishi ze-GPTQModel/Transformers ozikhethela. |
| **GPTQ** | Izilungiso ze-2/3/4/8-bit, iziformati ze-gptq/gptq_v2. | NVIDIA CUDA, GPTQModel kanye Optimum; ukubulawa kwangempela kuhlolwe ku-4 bits. |
| **bitsandbytes** | 4-bit NF4/FP4 noma 8-bit INT8. | NVIDIA CUDA kanye nokuncika ngokuzithandela; real NF4 kanye nokuhlolwa kwe-INT8. |
| **EXL3** | Gcwalisa inani lamafolda angamamodeli angu-Safetensors alayishwe nge-ExLlamaV3; isizukulwane sangempela nge-CUDA sihloliwe. | NVIDIA GPU, hlukanisa Python 3.12 imvelo kanye nezakhiwo ezihambisanayo; cha CPU ukubuyela emuva. |
| **EXL2** | Ezinikezelwe ExLlamaV2 isilayishi; ukusakaza, ukukhansela kanye nokukhipha kuhlolwe ku-GPU. | CUDA ukunakwa kufanele kukhethwe ngokusobala kusitaki sesofthiwe esihloliwe; iphoyinti lokuhlola eliphelele lemodeli kanye ne-VRAM etholakalayo. |
| **MLX** | Amamodeli ahambisanayo ku-Apple Silicon. | MLX injini kanye nesiteji esisekelwe. |

Ihabhu manje iyaphina **LFM3-1.7B** njengesincomo sayo se-LiquidAI sokucushwa okuhambisanayo, nge-Q4_K_M, Q6_K kanye ne-Q8_0 ehlukile. Imodeli eqalwe kuqala ihlala ileyo esohlwini lokucushwa okuqondisiwe ngenhla.

Hlunga ukulanda izisindo kusuka **ngaphansi kwe-1 GB kuya ku-500 GB nangaphezulu**, bese uhlunga ngokulingana kwehadiwe, usayizi, okwakamuva noma okulandiwe.
