# Novera source update — 23 October 2026

This update publishes the current 0.8.7 source integration on Novera's independent history. It includes the desktop identity, the agent's NOVERA.md instructions and .novera home, the novera-cli source directory, engine and conversation changes, interface adjustments and the language contributions already maintained by Novera.

## First model

Setup recommends [LiquidAI LFM2.5-2.6B Q6_K](https://huggingface.co/LiquidAI/LFM2.5-2.6B-GGUF/blob/main/LFM2.5-2.6B-Q6_K.gguf), approximately 2.22 GB. The user initiates the download.

| Setting | Initial value |
| --- | --- |

| Top-k | 50 |
| Repetition penalty | 1.1 |

The memory-fit probe uses the same context and a context-specific cache key. The recommendation no longer depends on the upstream Jan feed or its cached result. Model settings are saved at import and remain editable. An unchanged factory Novera assistant inherits model sampling settings; customized assistants and settings are preserved.

## Local validation and limits

The current source was compiled into a Windows x64 release executable using fat LTO, and started successfully in an isolated profile. The model/setup update has 238 passing targeted tests covering setup, recommendation persistence, import, engine presets and assistant migration. An earlier agent-path/skill check had 45 passing tests. A subsequent Vitest run over changed files in the web app, llama.cpp extension and assistant extension passed 4,972 tests, with 2 skipped (383 passing test files and 1 skipped). These checks do not constitute a complete repository or native cross-platform test pass.

This does not certify all engine experiments, model generations, providers or platforms. The full LFM weights were not downloaded for the setup change. Native-speaker review of translations remains pending; see [language coverage](LANGUAGES.md).

## Distribution

No installer, executable, weights, local logs, credentials or user data are included in this source update. No public binary release is created. Building a fresh checkout requires its normal dependencies and native engine/helper resources; the local Windows validation reused a separately built llama.cpp b11823 runtime.

GitHub Actions and automatic application updates remain disabled. Inherited publishing workflows and helper downloads require review before use as a Novera release pipeline. Signing, reproducible distribution and an independent update feed remain work to complete. The updater plugin stays unregistered while its required feed configuration is absent, fixing an observed startup failure.

Apache licensing and applicable attribution remain in place. See [identity policy](../BRANDING.md) and [official releases](../OFFICIAL_RELEASES.md).
