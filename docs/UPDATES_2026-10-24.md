# Novera 1.0.0 source update — 24 October 2026

This source update integrates all **35 Windows corrections** preserved from our Jan contributions into Novera 1.0.0. It publishes source code and documentation; it does not publish an installer, portable ZIP or executable.

## What changed

- Preserve conversation data and drafts when creation or deletion fails; keep assistant and project state consistent with successful storage operations.
- Serialize settings and message persistence, protect saved preferences after failed reads, and retain branch metadata.
- Scope model deletion records, caches, favorites, stream statistics and tool approvals to their owning provider or conversation.
- Preserve manual titles, generate automatic titles using the owning conversation's model, and handle failed history reads with retry.
- Preserve literal code in Markdown/table exports; reject obsolete syntax-highlighting results and escape fallback text.
- Handle mixed SSE line endings and retry streams, queued attachments/ingestion choices, remote auto-compaction and refused shell calls.
- Deduplicate advertised MCP tool definitions consistently with routing.

The [integration record](NOVERA_1_INTEGRATION.md) lists the corrections and adaptations. Versions in the frontend, desktop, CLI manifests and Cargo lockfiles are aligned to 1.0.0; compatibility command names remain where needed.

## Languages and first model

There are 36 selectable interface locales. The 18 complete contributed catalogs cover **1,465 English keys**, including new assistant-deletion and project-save error messages. Wu remains partial at 706 keys; native-speaker review remains necessary. See [language coverage](LANGUAGES.md).

The first-model recommendation remains **LiquidAI LFM2.5-2.6B Q6_K**, with temperature **0.1**, top-k **50**, repetition penalty **1.1** and context **32,768 tokens**. Downloading the weights remains a user action; no weights are included here.

## Validation and limits

- A full Windows x64 frontend/extensions and native release build completed using fat LTO, one code-generation unit and size optimization.
- The web test suite passed **4,906 tests**, with **2 skipped** (394 passing files, one skipped).
- After fixing a TypeScript declaration to allow Zustand's optional settings name, TypeScript compilation and **24 targeted settings tests** passed. These overlap with the web tests and should not be added to that count.
- **96 targeted native tests** passed: 33 conversation tests and 63 request/MCP tests. The Cargo test executable needed a Common-Controls v6 manifest on an isolated copy to resolve a Windows loader failure; this test-runner adjustment did not modify the production executable. The full native suite was not run.
- The compiled application stayed alive for a ten-second startup check in an isolated profile and reported the window title Novera. Runtime file hashes were checked and the bundled worker reported llama.cpp **b11823 / 0.7.0**.

No full model generation, exhaustive graphical workflow test, clean-PC portable validation or cross-platform runtime validation is claimed. A local build is not evidence that every integrated workflow is ready for public distribution.

## Distribution and governance

No public binary release is created. Portable packaging, prerequisite verification, signing and an independent update feed remain work to complete. The separate Linux AppIndicator correction (#9346) and portable distribution/CI contribution (#9302) are not included in these 35 Windows fixes. A read-only check of Jan main/dev on 24 October found neither contribution integrated.

GitHub Actions and automatic application updates remain disabled. Local logs, credentials, user data, build directories and executables are excluded from this source publication. Apache and applicable third-party notices remain unchanged.
