| **2. Gadzirira** | Kumisikidzwa kunotungamirwa kunopa zvinyorwa, zvinomisikidza, mufananidzo, mimhanzi, vhidhiyo uye kumusoro. Inotarisisa zvikamu, saizi nenzvimbo yemahara usati wabvumidza, yotevera kudhaunirodha nekufambira mberi, kumbomira/kutangazve uye SHA-256 ongororo. |
| **3. Configure** | Inonyoresa modhi uye zvikamu zvadzo, inogadzirira maprofile akakodzera uye mishumo inodiwa zvinoenderana. Kudzoreredza kunamatwa kunotanga pana CPU nesarudzo yakachengetedzwa CPU/GPU. Mimhanzi mitsva ma profiles anogara kune chiridzwa modhi. |
| **4. Nzwisisa chikumbiro** | Nzira dzoga dzinoziva zvikumbiro zvekugadzira zvemavara, mufananidzo, mimhanzi kana vhidhiyo. Iwe unogona zvakare kusarudza zvakajeka iyo yekubuda modhi uye yemuno kana yegore modhi. |

## Hub uye mhando dzinoenderana

**GGUF, chiyero uye chakayerwa Safetensors, ONNX, uye MLX**: ongorora modhi nebasa uye sarudza akasiyana anoenderana neinjini uye hardware yako.

| Mhuri | Tsigiro mune sosi | Zvinodiwa |
| --- | --- | --- |
| **GGUF** | Nyora kuburikidza nellama.cpp; mufananidzo/vhidhiyo zvikamu zveakatsigirwa profiles. | Architecture inozivikanwa neinjini yakaunganidzwa. |
| **Kupatsanura GGUF** | Musiyano mumwechete pane akatevedzana akazara, saizi yakapfupikiswa, zvese-shard kudhawunirodha uye saizi/SHA-256/macheki emusoro. | Mazita efaira akaverengerwa; kudhaunirodha 500 GB hazvirevi kuti modhi inokodzera izvi PC. |
| **Standard Safetensors** | Zadzisa maforodha kuburikidza neTransformers, causal mavara paCPU kana NVIDIA CUDA. | Configuration, tokenizer uye yega yega shard inodiwa. |
| **ONNX Runtime** | Kutorwa kwenzvimbo kwenhamba/bool graph uye yakagadzirirwa GenAI zvinyorwa kunze. | Yakagadziriswa folda yakazara; basa-chaiyo preprocessing / postprocessing inodiwa; [kuseta uye miganhu](onnx-server/README.md). |
| **LoRA / PEFT maadapter** | Ngenisa base yakakwana ine adapta yayo yemunharaunda mu Safetensors inopa. | Unquantized causal Transformers base, matching identity, tensor cheki uye cumulative memory estimate; [kuseta uye miganhu](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | Native CUDA kushandiswa kwedense inoenderana Llama/Qwen2/Qwen3 per-tensor FP8 zvinotengeswa kunze kwenyika. | Architecture/tensor cheki uye chaiyo kernel probe; [kuseta uye miganhu](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |
| **NVFP4 LLM / ModelOpt** | Packed block-16 FP4 mafungidziro kuburikidza nemaGEMM emuno CUDA; siyana nemufananidzo NVFP4. | Inoenderana Blackwell GPU, inotsigirwa zviyero / kutumira kunze uye chaiyo kernel probe; bvunzo dzisina kudzidziswa dzakaedzwa paRTX 5070. |
| **AWQ** | Yasina kushandiswa 4-bit GEMM yekutarisa. | NVIDIA CUDA uye zvingasarudzika GPTQModel/Transformers zvinorodha. |
| **GPTQ** | 2/3/4/8-bit magadzirirwo, gptq/gptq_v2 mafomati. | NVIDIA CUDA, GPTQModel uye Optimum; kuita chaiko kwakaedzwa pa 4 bits. |
| **bitsandbytes** | 4-bit NF4/FP4 kana 8-bit INT8. | NVIDIA CUDA uye zvingasarudzwa zvinotsamira; chaiyo NF4 uye INT8 bvunzo. |
| **EXL3** | Pedzisa maforodha akaverengerwa Safetensors kuburikidza neExLlamaV3; chaiyo CUDA chizvarwa chakaedzwa. | NVIDIA GPU, patsanura Python 3.12 nharaunda uye zvivakwa zvinoenderana; kwete CPU kudzoka shure. |
| **EXL2** | Yakazvipira ExLlamaV2 loader; kutepfenyura, kukanzura uye kuburutsa kwakaedzwa paGPU. | Sarudza zvakajeka iyo CUDA Yambiro kumashure kune yakaedzwa software stack; modhi yekutarisa yakakwana uye inokwana iripo VRAM inodiwa. |
| **MLX** | modhi dzinoenderana paApple Silicon. | MLX injini uye chikuva chinotsigirwa. |

Iyo Hub ikozvino inopinza **LFM3-1.7B** sekurudziro yavo yeLiquidAI yezvigadziriso zvinoenderana, ine Q4_K_M, Q6_K uye Q8_0 zvakasiyana. Yekutanga-run modhi inoramba iri iyo yakanyorwa mune inotungamirwa gadziriso pamusoro.

Sefa dhawunirodha uremu kubva **pasi pe1 GB kusvika 500 GB uye pamusoro**, wobva warongedza nehardware fit, saizi, zvazvinoita kana kudhawunirodha. Migumisiro inotakura zvishoma nezvishoma; mafirita anoshanda kune akatorwa mamodheru uye iwo default musiyano. Zano rendangariro rinoshandisa zviripo RAM/VRAM, mamiriro uye zvikamu zvinofambidzana, pasina kuverenga kaviri GPU ndangariro.

AWQ 4-bit, GPTQ 4-bit, NF4 uye INT8 yega yega inogadzirwa mavara paRTX 5070 Laptop uchishandisa mamodheru asina kudzidziswa akagadzirwa kunze kwenyika. Izvi zvinosimbisa kurodha nekuita, kwete kunaka kana kuita kwemhando yega yega. **Izvi zvekuwedzera zviri mune sosi: kuvakazve uye zvinoenderana zvinoenderana zvinodikanwa; iyi README yekuvandudza haikwidziridze binary yakaiswa.**

Hapana zvekumhanya kupfuura GGUF zvaratidzwa pano. Quantization/calibration inosiyana, uye EXL3 yatadza kuongorora masvomhu; mhinduro idzi hadzisi kukurumidza kukurumidza kana chimiro chemhando. [Zviyero zvakazara uye miganhu](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** ndeyekusarudza, inotungamirirwa zvakasiyana OpenAI-inoenderana nesevha yekubatanidza, yakadzimwa nekusingaperi. Yechokwadi EXL3 yekuwana uye kutepfenyura yakaedzwa. Nzira yemuno ExLlama inoramba yakasiyana. [ExLlama kuseta uye TabbyAPI kubatana](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

Iyo yakasarudzika hardware-yakagadziriswa mhando inofarira kuburitswa kutsva mukati mekuenderana kwakafanana uye inowanikwa-yendangariro tier. Mamodheru akaiswa haatsiviwa otomatiki.
