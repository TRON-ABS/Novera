## Novera 1.0.1

Novera 1.0.1 irahari kurubuga rwavuzwe hepfo. Kuramo paki ya sisitemu yawe cyangwa ukoreshe umuyoboro wogusinya. Kwishyiriraho biriho kuvugurura iyo ushyizeho pake nshya cyangwa wemera ibishya.

- Umutekano: uruhushya rukomeye kavukire kurupapuro rwa kure, kwemeza imiyoboro ya APIs hamwe nibikoresho bya seriveri, kurinda ububiko bwibanga no kwimuka, dosiye itekanye / kwinjira mu bitangazamakuru, urupapuro rusesuye kandi wubaka inyandiko. Kwishingikiriza kumugaragaro byavuguruwe; inama zisigaye zikurikiranwa kumugaragaro.
- Ibanga: imibare na raporo zamakosa bisaba kwemererwa gutandukana kandi bikagumaho byanze bikunze. Inyubako zirimo ibyerekanwe byerekanwe. Isuzuma rya tekiniki rirayungurura; abakoresha bakomeza kugenzura ibikorwa.
- Moteri yaho: `llama.cpp v0.9.0` (`b12110`, `cd959bae99ff4bed22bef2604f45241c09bbb8c8`). Imiterere ya moteri na verisiyo yo gusaba iratandukanye. Igenamiterere ryambere ryicyitegererezo hamwe nicyitegererezo / umushinga wiyandikisha birakosorwa, harimo gutsindwa gutangira birimo `kv_unified`. Igenamiterere ryihariye ririho.
- Indimi: 24 indimi zinyuranye hamwe nibihinduka bizana interineti kandi byahinduwe icyegeranyo cya README kuri 104, hamwe na 2,435 urufunguzo rwa interineti kuri catalog. Ibi bikubiyemo ntabwo byemeza ubwiza bwubwanditsi cyangwa inkunga yo kuvuga mururimi rwose.
- **LFM3-Omni-2B Q4_K_M** — Ibisanzwe kuri desktop na mobile. Icyitegererezo cyoroshye kubwandiko, amashusho n'amajwi, ukoresheje dosiye isabwa `mmproj`. Gukuramo: hafi 1.39 GB kuri dosiye zombi. Hitamo kugirango woroshye multimodal. Ibiranga amajwi biterwa na platform na moteri. Imirongo miremire ikoresha kwibuka cyane.
- **NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M** — Inyandiko-yonyine yo kuganira, kwandika, ibikoresho nibisubizo byubatswe. Gukuramo: hafi 6.18 GB. Irasaba kwibuka cyane kuruta LFM3-Omni kandi ntabwo itunganya amashusho cyangwa amajwi ubwayo. Ibisubizo byavuzwe koresha ijwi rya sisitemu. Hitamo kubikorwa byanditse mugihe ufite ububiko buhagije. Reba ibisubizo bifatika hamwe ninkomoko.
- Kuri 1.0.1, LFM3-Omni-2B Q4_K_M hamwe nibisabwa `mmproj-LFM3-Omni-2B-Q4_K_M.gguf` nibisabwa mbere kuri desktop na mobile; NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M ikomeza kuba inyandiko-yonyine. Imiterere yambere ni 32,768 ibimenyetso kuri desktop na 2,048 kuri mobile. Umwanya muremure ukoreshe kwibuka cyane. Guhitamo icyitegererezo no guhitamo birabitswe kugeza bihinduwe neza.
- Ijwi: kuyobora mikoro yaho yinjiza LFM3-Omni, ibiganiro bihoraho no kohereza byikora, amajwi yo gusubiza abagabo / abategarugori kumajwi yerekana amajwi, hamwe nijambo rya sisitemu ya moderi ya kera. Subiza gusoma nabyo bikora kubutumwa bwanditse no kuvugurura, utitaye kuri mikoro. Akabuto gato k'ijwi gashoboza cyangwa gucecekesha gusoma.
- Imiterere ya mikoro: icyatsi iyo kiboneka, umutuku mugihe uhuze, imvi iyo zitaboneka. Kumenyekana, gutegera amatwi, gutangira kwibanda hamwe nigitekerezo kigaragara byakosowe. - Optimizations: tegura gushakisha kurubuga inyuma mugihe interineti ishoboye, gusangira serivisi gutangira, gutegura igice gikurikira cyo kuvuga mbere yo gukina no kunoza interuro ikomeza. ## Hub hamwe nicyitegererezo

**GGUF, zisanzwe kandi zingana Safetensors, ONNX, na MLX**: shakisha icyitegererezo kubikorwa hanyuma uhitemo impinduka zijyanye na moteri nibikoresho byawe.

| Umuryango | Inkunga mu isoko | Ibisabwa |
| --- | --- | --- |
| **GGUF** | Kwandika inyandiko binyuze muri llama.cpp; ishusho na videwo yibigize imyirondoro ishyigikiwe. | Ubwubatsi bwemewe na moteri ihujwe. |
| **Gutandukanya GGUF** | Impinduka imwe kumurongo wuzuye, ingano yincamake, gukuramo byose-shard nubunini / SHA-256 / kugenzura imitwe. | Amazina asanzwe afite nomero; gukuramo 500 GB ntabwo bivuze ko moderi ihuye niyi PC. |
| **Bisanzwe Safetensors** | Ububiko bwuzuye binyuze muri Transformers, inyandiko yimpamvu kuri CPU cyangwa NVIDIA CUDA. | Iboneza, tokenizer na buri shard isabwa. |
| **ONNX Runtime** | Ibicuruzwa byinjira mubishushanyo mbonera / bool no gutegura GenAI yoherejwe hanze. | Ububiko bwuzuye bwemewe; imirimo yihariye itunganywa / itunganywa risabwa; [gushiraho no kugarukira](onnx-server/README.md). |
| **LoRA / PEFT** | Kuzana shingiro ryuzuye hamwe na adapt yihariye yaho muri Safetensors. | Icyo cy'Transformers cy'ubwoko butari cy'ubwoko bw'unquantized cy'ubwoko bw'causal, iby'identity by'matching, ibikoresho by'tensor kandi ikiganiro cy'ubwoko bw'umwihariko w'imemori; [gushiraho no kugarukira](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | Gukoresha cy'CUDA mu buryo bw'native ku by'Llama/Qwen2/Qwen3 by'dense by'compatible n'ibikoresho by'FP8 by'per-tensor. | Icyo cy'Architecture/tensor checks kandi cy'real kernel probe; [gushiraho no kugarukira](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |
| **NVFP4 LLM / ModelOpt** | Iby'projections by'16 FP4 by'packed block mu buryo bw'native by'CUDA GEMMs; bitandukanye n'image NVFP4. | Blackwell GPU ihuje n’iyi mikorere, dimensions/export bishyigikiwe n’ikizamini nyacyo cya kernel; moderi z’igerageza zitatojwe zapimwe kuri RTX 5070. |
| **AWQ** | 4-bit GEMM igenzurwa ntangarugero nta guhuza ibikorwa. | NVIDIA CUDA nubushake bwa GPTQModel/Transformers. |
| **GPTQ** | 2 / 3 / 4 / 8-bit-iboneza, gptq / gptq_v2. | NVIDIA CUDA, GPTQModel na Optimum; irangizwa ryukuri ryageragejwe kuri 4. |
| **bitsandbytes** | 4-bit NF4/FP4 cyangwa 8-bit INT8. | NVIDIA CUDA no guterwa kubushake; ibizamini bya NF4 na INT8. |
| **EXL3** | Ububiko bwuzuye bwa Safetensors bwuzuye bwuzuye bwuzuye ExLlamaV3; igisekuru nyacyo hamwe na CUDA cyageragejwe. | NVIDIA GPU, gutandukanya Python 3.12 hamwe nubwubatsi bujyanye; nta gusubira inyuma kwa CPU. |
| **EXL2** | Yiyeguriye ExLlamaV2; gutembera, guhagarika no gupakurura byageragejwe kuri GPU. | Hitamo CUDA Attention backend ku buryo bweruye muri software yapimwe; hakenewe checkpoint yuzuye ya moderi na VRAM ihagije iboneka. |
| **MLX** | Moderi ihuje kuri Apple Silicon. | MLX moteri hamwe na platform. |

Hub noneho **LFM3-1.7B** nkibisobanuro byayo bya LiquidAI kubishushanyo mbonera, hamwe na Q4_K_M, Q6_K na Q8_0. Moderi yambere-ikomeza kuba imwe murutonde ruyobowe hejuru.

Shungura ibipimo byo gukuramo **munsi ya 1 GB kugeza 500 GB no hejuru**, hanyuma utondekane kubikoresho bikwiranye, ingano, kwihuta cyangwa gukuramo. Ibisubizo biremereye buhoro buhoro; muyunguruzi ikoreshwa kuri moderi yazanywe hamwe nibisanzwe. Impanuro zo kwibuka zikoresha RAM/VRAM iboneka, imiterere nibice bya mugenzi wawe, utabariyemo kabiri ububiko bwa GPU.

AWQ 4-bit, GPTQ 4-bit, NF4 na INT8 buri kintu by'generate text kuri RTX 5070 Laptop bakoresheje ibikoresho by'tiny by'untrained by'offline. Ibi bivuga ko by'kwiriye gukoresha no gukorwa, atari ubuzima cyangwa ubushobozi by'ibikoresho byose. **Izi nyongera ziri mu nkomoko: kwiyubaka no guhuza biterwa birasabwa; iyi README ivugurura ntabwo izamura binary yashyizweho.**

**By'meze kuri RTX 5070 Laptop:** Qwen2.5-0.5B-Instruct, context 2,048, prompt 272 tokens, 128 generated tokens, ibigeragezo bitanu nyuma yo gushyushya sisitemu: median decode **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. Nta nyungu yihuta kurenza GGUF yerekanwe hano. Quantisation / kalibrasi iratandukanye, kandi EXL3 yananiwe ikizamini kimwe cy’imibare yoroshye; ibisubizo ntabwo ari umuvuduko rusange cyangwa urutonde rwiza. [Ibipimo byuzuye n'imbibi](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** nubushake, bucungwa butandukanye OpenAI ihuza seriveri ihuza, ihagarikwa kubusa. Icyitegererezo cya EXL3 kuvumbura no gutambuka byageragejwe. Inzira ya ExLlama icungwa ikomeza kuba itandukanye. [ExLlama gushiraho na TabbyAPI](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

Ubusanzwe ibyuma-byahinduwe byubwoko bushyigikira ibyasohotse bishya muburyo bumwe kandi biboneka-murwego rwo kwibuka. Moderi yashyizweho ntabwo isimburwa mu buryo bwikora.

[Imiterere ya Safetensors](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [Imiterere, ibyihutirwa no kwemeza](docs/SUIVI_MOTEURS.md)

Kode ivuguruye yongeramo **ibice bicungwa na Novera byo guhitamo muri Configurations kuri Windows x64**: ahantu hihariye ha Python, CPU/CUDA profiles zifite verisiyo zagenwe, kugereranya ibikenewe no kwemeza mbere yo gukurura, kugenzura, gusana no gukuraho. Inzira zihariye za Python interpreter ziguma mu mahitamo yisumbuye. GGUF engines zisanzwe zigumana ibice byazo; mobile na cloud ntibikurura Python/PyTorch bya desktop. CPU/export profiles eshatu zihariye zapimwe hakoreshejwe amakuru y’igerageza yakozwe; ushinzwe kubungabunga umushinga avuga ko desktop yakoreshejwe neza ku wa 1 Ugushyingo 2026. GPU profiles no gushyira porogaramu kuri PC itarayishyirwaho biracyakeneye igenzura ryihariye kandi rirambuye. [Profiles n’imbibi z’igerageza](docs/REPRISE_COMPOSANTS_GERES_80_LANGUES.md).
