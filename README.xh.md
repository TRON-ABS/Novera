Novera 1.0.1 iyafumaneka kumaqonga adweliswe ngezantsi. Khuphela iphakheji yesixokelelwano sakho okanye usebenzise itshaneli yohlaziyo esayiniweyo. Ufakelo olukhoyo luhlaziywa xa ufaka ipakethe entsha okanye wamkela uhlaziyo.

- Ukhuseleko: iimvume ezingqongqo zemveli zamaphepha akude, ukuqinisekiswa kwe-APIs yenethiwekhi kunye nezixhobo zeseva, ukugcinwa okuyimfihlo okukhuselweyo kunye nokufuduka, ukufikelela okukhuselekileyo kwefayile / ukufikelela kwimidiya, ukwahlula i-spreadsheet kunye nokwakha izikripthi. Ukuxhomekeka okuveziweyo kuye kwahlaziywa; iingcebiso eziseleyo zilandelwa ngokuvulelekileyo.

## Hub kunye neemodeli ezihambelanayo

**GGUF, umgangatho kunye nomlinganiselo we-Safetensors, ONNX, kunye ne-MLX**: phonononga iimodeli ngomsebenzi kwaye ukhethe ukwahluka okuhambelana nenjini kunye nehardware yakho.

| Usapho | Inkxaso kumthombo | Iimfuno |
| --- | --- | --- |
| **GGUF** | Ukuveliswa kombhalo nge-llama.cpp; umfanekiso kunye namacandelo evidiyo kwiiprofayili ezixhaswayo. | Uyilo olwamkelwa yinjini edityanisiweyo. |
| **Yahlula i-GGUF** | Ukwahluka omnye kuthotho olupheleleyo, ubungakanani obusisishwankathelo, ukukhuphela yonke into kunye nobukhulu/SHA-256/ukuhlolwa kwentloko. | Amagama eefayile aneenombolo ezisemgangathweni; ukukhuphela i-500 GB ayithethi ukuba imodeli ilingana nale PC. |
| **i-Safetensors eqhelekileyo** | Gqibezela iifolda nge-Transformers, i-causal text kwi-CPU okanye i-NVIDIA CUDA. | Uqwalaselo, i-tokenizer kunye nayo yonke i-shard efunekayo. |
| **ONNX Runtime** | Ukungeniswa kwendawo kwamanani / iigrafu ze-bool kunye nokuthunyelwa ngaphandle kwe-GenAI okubhaliweyo. | Ifolda egqibeleleyo eqinisekisiweyo; umsebenzi othe ngqo wangaphambili/ulungiso olufunekayo; [ukuseta kunye nemida](onnx-server/README.md). |
| **LoRA / PEFT iiadaptha** | Ngenisa isiseko esipheleleyo kunye neadaptha yendawo eyahlukileyo kumnikezeli we-Safetensors. | Isiseko esingenakulinganiswa se-causal Transformers, isazisi esihambelanayo, ukujonga i-tensor kunye noqikelelo lwenkumbulo olongezelekayo; [ukuseta kunye nemida](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | Ukusebenza kwe-CUDA ngokubanzi kubeziphathelene iindlebe ezibunzulu ze-Llama/Qwen2/Qwen3 ze-FP8 zokugqibela | I-architecture/tensor checks kunye ne-real kernel probe; [ukuseta kunye nemida](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |
| **NVFP4 LLM / ModelOpt** | Ukupakishwa kwebhloko-16 FP4 iingqikelelo ngee-GEMM zemveli ze-CUDA; yahlukana nomfanekiso NVFP4. | I-Blackwell GPU ehambelanayo, imilinganiselo exhaswayo / ukuthumela ngaphandle kunye ne-kernel probe yangempela; iimodeli zovavanyo ezingaqeqeshwanga zavavanywa kwi-RTX 5070. |
| **AWQ** | 4-bit GEMM imodeli yeendawo zokujonga ngaphandle kokudibanisa ukusebenza. | NVIDIA CUDA kunye nezilayishi GPTQModel/Transformers ozikhethelayo. |
| **GPTQ** | 2/3/4/8-bit ulungelelwaniso, gptq/gptq_v2 iifomati. | NVIDIA CUDA, GPTQModel kunye neOptimum; ukubulawa kwangempela kuvavanywa kwi-4 bits. |
| **bitsandbytes** | 4-bit NF4/FP4 okanye 8-bit INT8. | NVIDIA CUDA kunye nokuxhomekeka okukhethiweyo; yokwenene NF4 kunye novavanyo INT8. |
| **EXL3** | Gqibezela iifolda zemodeli ze-Safetensors ezifakwe kwi-ExLlamaV3; isizukulwana sokwenyani nge-CUDA savavanywa. | NVIDIA GPU, i-Python 3.12 eyahlukileyo yendawo kunye nezakhiwo ezihambelanayo; akukho CPU yokubuyela umva. |
| **EXL2** | Ezinikezelweyo ExLlamaV2 umlayishi; ukusasaza, ukurhoxiswa kunye nokukhulula kuvavanywa kwi-GPU. | CUDA ingqalelo mayikhethwe ngokuthe gca kwisitaki sesoftware evavanyiweyo; imodeli epheleleyo yokukhangela indawo kunye ne-VRAM ekhoyo iyafuneka. |
| **MLX** | Iimodeli ezihambelanayo kwi-Apple Silicon. | injini ye-MLX kunye neqonga elixhaswayo. |

I-Hub ngoku iyaqhaga **LFM3-1.7B** njengengcebiso yayo ye-LiquidAI yolungelelwaniso oluhambelanayo, kunye nokwahluka kwe-Q4_K_M, Q6_K kunye ne-Q8_0. Imodeli yokuqala ihlala iyilo idweliswe kuqwalaselo olukhokelwayo apha ngasentla.

Hlunga ukhuphelo lobunzima ukusuka **phantsi kwe-1 GB ukuya kwi-500 GB nangaphezulu**, emva koko uhlele ngokolungelelwaniso lwehardware, ubungakanani, umva okanye ukhuphelo. Iziphumo zilayisha ngokuqhubekayo; Amacebo okucoca ayasebenza kwimifuziselo elandiweyo kunye nokwahluka kwazo okungagqibekanga. Ingcebiso yememori isebenzisa i-RAM/VRAM ekhoyo, umxholo kunye namacandelo ahambelanayo, ngaphandle kokubala kabini imemori eyabelwe i-GPU.

AWQ 4-bit, GPTQ 4-bit, NF4 kunye ne-INT8 isicatshulwa ngasinye esiveliswe kwi-RTX 5070 Laptop kusetyenziswa imifuziselo emincinci engaqeqeshwanga. Oku kuqinisekisa ukulayishwa kunye nokwenziwa, hayi umgangatho okanye ukusebenza kwayo yonke imodeli. **Ezi zongezo zikumthombo: ukuxhomekeka kwakhiwe kwakhona kunye nokuhambelanayo kuyafuneka; olu hlaziyo lwe-README aluphuculi ibhinary efakiweyo.**

**Ilinganisiwe kwi-RTX 5070 Laptop:** Qwen2.5-0.5B-Instruct, umxholo we-2,048, iithokheni ze-272 ngokukhawuleza, i-128 zenziwe iithokheni, ii-run ezifudumeleyo ezintlanu: i-decode ye-median **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. Akukho nzuzo yesantya ngaphezulu kwe-GGUF yaboniswa apha. Ubungakanani/ukulinganisa kuyahluka, kwaye i-EXL3 ayiphumelelanga inyathelo elinye lomsi we-arithmetic; ezi ziphumo ayisosantya jikelele okanye umgangatho womgangatho. [Imilinganiselo epheleleyo kunye nemida](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** lukhetho, olulawulwa ngokwahlukeneyo OpenAI-uqhagamshelwano lweseva oluhambelanayo, luvaliwe ngokungagqibekanga. Ukufunyanwa kwemodeli ye-EXL3 eqinisekisiweyo kunye nokusasazwa kwavavanywa. Indlela ye-ExLlama elawulwayo yasekhaya ihlala yohlukile. [ExLlama ukuseta kunye noqhagamshelo lwe-TabbyAPI](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

Uhlobo olumiselweyo lwehardware olumiselweyo luthanda ukukhutshwa okutsha ngaphakathi kokuhambelana okufanayo kunye nenqanaba lememori ekhoyo. Iimodeli ezifakiweyo azitshintshwa ngokuzenzekelayo.

[Umiselo lwe-Quantized Safetensors](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [Iifomathi, izinto eziphambili kunye nokuqinisekiswa](docs/SUIVI_MOTEURS.md)

Imithombo ehlaziyiweyo yongeza **amacandelo alawulwayo ngokuzikhethela kuLungiselelo lwe-Windows x64**: Imimandla yangasese yePython, ekhonjiweyo yeeprofayili ze-CPU/CUDA, uqikelelo kunye nokuqinisekiswa ngaphambi kokukhuphela, ukuqinisekiswa, ukulungiswa kunye nokususwa. Iindlela zokutolika ngokwesiko zihlala phantsi kweenketho eziphambili. Iinjini ze-GGUF zoMthonyama zigcina amacandelo azo akhoyo; iselula kunye nelifu alikhupheli i-desktop Python/PyTorch. Iiprofayili ezintathu zabucala ze-CPU/zokuthunyelwa ngaphandle ziye zasetyenziswa ngokulungiswa kwenyani; Umlondolozi unika ingxelo yokusetyenziswa ngempumelelo kwe-desktop kwi-1 ngoNovemba 2026; Iiprofayili ze-GPU kunye nokucoca-PC ukufakela kusafuna ukwahluka, ukuqinisekiswa okuneenkcukacha. [Iiprofayili kunye nemida yovavanyo](docs/REPRISE_COMPOSANTS_GERES_80_LANGUES.md). Ukufakela isitaki kwi-EXE kuyarhoxiswa.
