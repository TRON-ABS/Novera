## Novera 1.0.1

Novera 1.0.1 નીચે સૂચિબદ્ધ પ્લેટફોર્મ્સ માટે ઉપલબ્ધ છે. તમારી સિસ્ટમ માટે પેકેજ ડાઉનલોડ કરો અથવા તેની સહી કરેલ અપડેટ ચેનલનો ઉપયોગ કરો. જ્યારે તમે નવું પેકેજ ઇન્સ્ટોલ કરો છો અથવા અપડેટ સ્વીકારો છો ત્યારે હાલની ઇન્સ્ટોલેશન અપડેટ થાય છે.

- સુરક્ષા: દૂરસ્થ પૃષ્ઠો માટે સખત મૂળ પરવાનગીઓ, નેટવર્ક API અને સર્વર સાધનો માટે પ્રમાણીકરણ, સુરક્ષિત ગુપ્ત સંગ્રહ અને સ્થળાંતર, સુરક્ષિત ફાઇલ/મીડિયા ઍક્સેસ, સ્પ્રેડશીટ પાર્સિંગ અને બિલ્ડ સ્ક્રિપ્ટ્સ. ખુલ્લી અવલંબન અપડેટ કરવામાં આવી છે; બાકીની સલાહ ખુલ્લેઆમ ટ્રેક કરવામાં આવે છે.
- ગોપનીયતા: આંકડા અને ભૂલ અહેવાલોને અલગ સંમતિની જરૂર છે અને મૂળભૂત રીતે બંધ રહે છે. બિલ્ડ્સમાં દસ્તાવેજીકૃત ગંતવ્ય ગોઠવણીનો સમાવેશ થાય છે. ટેકનિકલ ડાયગ્નોસ્ટિક્સ ફિલ્ટર કરવામાં આવે છે; વપરાશકર્તાઓ સક્રિયકરણ પર નિયંત્રણ રાખે છે.
- સ્થાનિક એન્જિન: `llama.cpp v0.9.0` (`b12110`, `cd959bae99ff4bed22bef2604f45241c09bbb8c8`). એન્જિન વર્ઝન અને એપ્લિકેશન વર્ઝન અલગ છે. પ્રારંભિક મોડલ સેટિંગ્સ અને મોડલ/પ્રોજેક્ટર નોંધણી સુધારેલ છે, જેમાં સ્ટાર્ટઅપ નિષ્ફળતા સામેલ છે જેમાં `kv_unified`નો સમાવેશ થાય છે. હાલની વ્યક્તિગત સેટિંગ્સ સાચવેલ છે.
- ભાષાઓ: 24 વધારાની ભાષાઓ અને વેરિઅન્ટ્સ ઈન્ટરફેસ અને અનુવાદિત README સંગ્રહને 104 પર લાવે છે, જેમાં કૅટેલોગ દીઠ 2,435 ઈન્ટરફેસ કી છે. આ કવરેજ દરેક ભાષામાં મૂળ સંપાદકીય ગુણવત્તા અથવા ભાષણ સમર્થનને પ્રમાણિત કરતું નથી.

## પ્રથમ લોન્ચથી પરિણામો સુધી

**અમારું ઓટોમેશન તૈયારીને સંપૂર્ણ એક્ઝેક્યુશન વર્કફ્લો સાથે જોડે છે.** Novera અદ્યતન નિયંત્રણોને સુલભ રાખીને પસંદ કરેલ ગોઠવણી માટે ઉપલબ્ધ ટેકનિકલ પગલાંઓનું સંચાલન કરે છે.

| પગલું | Novera શું હેન્ડલ કરે છે |
| --- | --- |
| **1. શરૂ કરો** | પ્રથમ લોન્ચ વખતે સપોર્ટેડ સિસ્ટમ લેંગ્વેજ પસંદ કરે છે અને તમારી પસંદગી સાચવે છે. પ્રારંભિક મોડલ અને ઉપયોગી હાર્ડવેર માહિતી રજૂ કરે છે. |
| **2. તૈયાર કરો** | માર્ગદર્શિત ઇન્સ્ટોલેશન ટેક્સ્ટ, એમ્બેડિંગ્સ, છબી, સંગીત, વિડિઓ અને અપસ્કેલિંગ પ્રદાન કરે છે. તે તમારી મંજૂરી પહેલાં ઘટકો, કદ અને ખાલી જગ્યાનું પૂર્વાવલોકન કરે છે, પછી પ્રગતિ, વિરામ/ફરી શરૂ અને SHA-256 ચકાસણી સાથે ડાઉનલોડ્સને ટ્રૅક કરે છે. |
| **3. રૂપરેખાંકિત કરો** | મોડેલો અને તેમના ઘટકોની નોંધણી કરે છે, સંબંધિત પ્રોફાઇલ તૈયાર કરે છે અને જરૂરી નિર્ભરતાનો અહેવાલ આપે છે. પુનઃપ્રાપ્તિ એમ્બેડિંગ્સ CPU પર સાચવેલ CPU/GPU પસંદગી સાથે શરૂ થાય છે. નવી સંગીત પ્રોફાઇલ્સ ઇન્સ્ટ્રુમેન્ટલ મોડ પર ડિફોલ્ટ છે. |
| **4. વિનંતી સમજો** | સ્વતઃ માર્ગે લખાણ, છબી, સંગીત અથવા વિડિયો બનાવવાની વિનંતીઓને માન્યતા આપી. તમે આઉટપુટ મોડ અને સ્થાનિક અથવા ક્લાઉડ મોડલ પણ સ્પષ્ટપણે પસંદ કરી શકો છો. |
| **5. ચલાવો** | સ્વચાલિત મેમરી સક્રિય કાર્ય માટે રાહ જુએ છે, બિનજરૂરી મૉડલ રિલીઝ કરે છે અને જરૂરી સંસાધનો ફરીથી લોડ કરે છે. 1–10 જોબ સિરીઝ ક્રમમાં ચાલે છે અને આગલી નોકરી પહેલાં સંસાધનો બહાર પાડે છે. ક્લાઉડ પ્રદાતાઓ પસંદ કરેલ એકાઉન્ટ અને ગોઠવણીનો ઉપયોગ કરે છે. |
| **6. પુનઃપ્રાપ્ત કરો અને ફરીથી ઉપયોગ કરો** | Novera સિસ્ટમ ફોલ્ડર્સમાં મીડિયાને સાચવે છે, પરિણામો અને ઉપલબ્ધ સમય દર્શાવે છે, પછી વેરિઅન્ટ્સ, લાઇબ્રેરી, કૉપિ, નિકાસ અથવા સિસ્ટમ શેરિંગ ઑફર કરે છે. બીજી એપ્લિકેશન પર મોકલવું એ તમારી ક્રિયા રહે છે. |

ઓટોમેશન એકીકૃત એન્જિન અને વર્કફ્લોને આવરી લે છે; તે દરેક હબ મોડેલને એક્ઝેક્યુટેબલ બનાવતું નથી. હાર્ડવેર, ઇન્સ્ટોલ કરેલ ઘટકો અને પ્રદાતા ઍક્સેસ નક્કી કરે છે કે શું ચાલી શકે છે. ફોલ્ડર્સ, ફાઈલ ફેરફારો અને શેલ આદેશો વાતચીતની ઍક્સેસ અનુદાનને અનુસરે છે.

| **EXL3** | પૂર્ણ ક્વોન્ટાઇઝ્ડ Safetensors મોડલ ફોલ્ડર્સ ExLlamaV3 દ્વારા લોડ થાય છે; CUDA સાથે વાસ્તવિક પેઢીનું પરીક્ષણ કરવામાં આવ્યું હતું. | NVIDIA GPU, અલગ Python 3.12 પર્યાવરણ અને સુસંગત આર્કિટેક્ચર; CPU ફોલબેક નથી. |

| **MLX** | Apple Silicon પર સુસંગત મોડલ્સ. | MLX એન્જિન અને સપોર્ટેડ પ્લેટફોર્મ. |

હબ હવે પિન કરે છે **LFM3-1.7B** Q4_K_M, Q6_K અને Q8_0 વેરિઅન્ટ્સ સાથે સુસંગત ગોઠવણીઓ માટે તેની LiquidAI ભલામણ તરીકે. ફર્સ્ટ-રન મોડલ ઉપરના માર્ગદર્શિત રૂપરેખાંકનમાં સૂચિબદ્ધ છે.

થી ફિલ્ટર ડાઉનલોડ વજન **1 GB થી 500 GB અને ઉપર**, પછી હાર્ડવેર ફિટ, કદ, તાજેતરની અથવા ડાઉનલોડ્સ દ્વારા સૉર્ટ કરો. પરિણામો ધીમે ધીમે લોડ થાય છે; ફિલ્ટર્સ મેળવેલા મોડલ્સ અને તેમના ડિફોલ્ટ વેરિઅન્ટ પર લાગુ થાય છે. મેમરી એડવાઈસ ઉપલબ્ધ RAM/VRAM, સંદર્ભ અને સાથી ઘટકોનો ઉપયોગ કરે છે, શેર કરેલી GPU મેમરી ડબલ-કાઉન્ટિંગ વિના.

AWQ 4-bit, GPTQ 4-bit, NF4 અને INT8 દરેકે RTX 5070 Laptopin બંધ ન કરેલ મોડલનો ઉપયોગ કરીને જનરેટ કરેલ ટેક્સ્ટ આ લોડિંગ અને એક્ઝેક્યુશનને માન્ય કરે છે, દરેક મોડેલની ગુણવત્તા અથવા પ્રદર્શનને નહીં. **આ ઉમેરણો સ્ત્રોતમાં છે: પુનઃનિર્માણ અને સુસંગત અવલંબન જરૂરી છે; આ README અપડેટ ઇન્સ્ટોલ કરેલ બાઈનરીને અપગ્રેડ કરતું નથી.**

**RTX 5070 Laptop પર માપવામાં આવે છે:** Qwen2.5-0.5B-Instruct, સંદર્ભ 2,048, પ્રોમ્પ્ટ 272 ટોકન્સ, 128 જનરેટ કરેલા ટોકન્સ, પાંચ ગરમ રન: મધ્ય ડીકોડ **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. GGUF પર કોઈ ઝડપ લાભ અહીં દર્શાવવામાં આવ્યો ન હતો. પરિમાણ/કેલિબ્રેશન અલગ છે, અને EXL3 એક સરળ અંકગણિત પરીક્ષણ નિષ્ફળ ગયો; આ પરિણામો સામાન્ય ગતિ અથવા ગુણવત્તા રેન્કિંગ નથી. [સંપૂર્ણ માપ અને મર્યાદા](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** એ વૈકલ્પિક, અલગથી સંચાલિત OpenAI- સુસંગત સર્વર કનેક્શન છે, જે ડિફોલ્ટ રૂપે અક્ષમ છે. પ્રમાણિત EXL3 મોડેલ શોધ અને સ્ટ્રીમિંગનું પરીક્ષણ કરવામાં આવ્યું હતું. સંચાલિત સ્થાનિક ExLlama માર્ગ અલગ રહે છે. [ExLlama સેટઅપ અને TabbyAPI કનેક્શન](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

ડિફૉલ્ટ હાર્ડવેર-અનુકૂલિત સૉર્ટ સમાન સુસંગતતા અને ઉપલબ્ધ-મેમરી ટાયરમાં નવા પ્રકાશનોની તરફેણ કરે છે. ઇન્સ્ટોલ કરેલ મોડલ આપમેળે બદલાતા નથી.

[ક્વોન્ટાઇઝ્ડ Safetensors સેટઅપ](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [ફોર્મેટ્સ, પ્રાથમિકતાઓ અને માન્યતા](docs/SUIVI_MOTEURS.md)

અપડેટ કરાયેલા સ્ત્રોતો ઉમેરે છે **Windows x64 માટે રૂપરેખાંકનોમાં વૈકલ્પિક વ્યવસ્થાપિત ઘટકો**: ખાનગી પાયથોન એન્વાયર્નમેન્ટ્સ, પિન કરેલ CPU/CUDA પ્રોફાઇલ્સ, ડાઉનલોડ, ચકાસણી, સમારકામ અને દૂર કરતા પહેલા અંદાજ અને પુષ્ટિ. કસ્ટમ દુભાષિયા પાથ અદ્યતન વિકલ્પો હેઠળ રહે છે. મૂળ GGUF એન્જિન તેમના હાલના ઘટકો રાખે છે; મોબાઇલ અને ક્લાઉડ ડેસ્કટોપ Python/PyTorch ડાઉનલોડ કરતા નથી. ત્રણ ખાનગી CPU/નિકાસ પ્રોફાઇલનો કૃત્રિમ પરીક્ષણ ડેટા સાથે ઉપયોગ કરવામાં આવ્યો હતો; જાળવણીકાર 1 નવેમ્બર 2026 પર ડેસ્કટોપના સફળ ઉપયોગની જાણ કરે છે; GPU પ્રોફાઇલ્સ અને સ્વચ્છ-PC ઇન્સ્ટોલેશનને હજુ પણ અલગ, વિગતવાર માન્યતાની જરૂર છે. [પ્રોફાઇલ્સ અને પરીક્ષણ મર્યાદા](docs/REPRISE_COMPOSANTS_GERES_80_LANGUES.md). EXE માં સ્ટેકને એમ્બેડ કરવાનું વિલંબિત છે.

## 120 ઈન્ટરફેસ ભાષાઓ અને પ્રકારો

**તમામ 120 કેટલોગ વર્તમાન 2,484 અંગ્રેજી કીને આવરી લે છે** સમગ્ર 15 નેમસ્પેસ, જેમાં મેનુઓ, ગોઠવણીઓ, સેટિંગ્સ, મદદ અને મીડિયા નિયંત્રણો સામેલ છે. બહુવચન સ્વરૂપો અને ઇન્ટરફેસ દિશા પસંદ કરેલી ભાષાને અનુસરે છે. પ્રતિભાવ અને અવાજની ભાષાઓ મોડેલ પર અલગથી આધાર રાખે છે.

આ તકનીકી કવરેજ ભાષાકીય ગુણવત્તાને પ્રમાણિત કરતું નથી: **મૂળ સમીક્ષા અને પ્રાદેશિક અનુકૂલન જરૂરી રહે છે**. માં મૂળ લેબલ્સ અને જાણીતી મર્યાદાઓ જુઓ [ભાષા માર્ગદર્શિકા](docs/LANGUAGES.md) અને [ઓડિટ રિપોર્ટ](deliverables/interface-audit-2026-10-29/RAPPORT.md).

## દરેક ક્ષેત્રમાં લોકોને મદદ કરવી

શાળા અને શિક્ષણ ઉપરાંત, અમારી મહત્વાકાંક્ષા લોકોને શીખવામાં, સમસ્યાઓ હલ કરવામાં, વિશ્વભરમાં ઉપયોગી પ્રોજેક્ટ બનાવવા અને વિકસાવવામાં મદદ કરવાની છે. Novera નો હેતુ વર્તમાન AI એડવાન્સિસને સમજવા અને ઉપયોગમાં સરળ બનાવવાનો છે, સમગ્ર ભાષાઓ, અનુભવના સ્તરો અને ઉપલબ્ધ હાર્ડવેર.

| સેક્ટર જેને અમે વિકસાવવામાં મદદ કરવા માંગીએ છીએ | ઉપયોગી યોગદાનના ઉદાહરણો |
| --- | --- |
| શાળાઓ, શિક્ષણ અને જીવનભરનું શિક્ષણ | ખ્યાલો સમજાવો, શીખવાની સામગ્રીને અનુકૂલિત કરો અને શિક્ષકો, વિદ્યાર્થીઓ અને પરિવારોને સહાય કરો. |
| સંશોધન, વિજ્ઞાન અને અવકાશ | સાહિત્યનું અન્વેષણ કરો, પદ્ધતિઓ સમજાવો, ડેટાનું વિશ્લેષણ કરો અને જ્ઞાન શેર કરો. |
| આરોગ્ય, સંભાળ અને સામાજિક સમર્થન | સંશોધન અને વ્યાવસાયિક વર્કફ્લોને સમજવા અને સમર્થન આપવા માટે માહિતીને સરળ બનાવો. |
| કૃષિ, ખોરાક અને ગ્રામીણ સમુદાયો | વ્યવહારુ જ્ઞાન શેર કરો, આયોજનને સમર્થન આપો અને સ્થાનિક રીતે ઉપયોગી સાધનો વિકસાવો. |
| પર્યાવરણ, આબોહવા, પાણી અને જૈવવિવિધતા | પુરાવા સમજાવો, નિરીક્ષણને સમર્થન આપો અને સમુદાયોને પ્રોજેક્ટની યોજના બનાવવામાં મદદ કરો. |
| ઊર્જા, ઉદ્યોગ, બાંધકામ અને હસ્તકલા | આધાર દસ્તાવેજીકરણ, ડિઝાઇન, જાળવણી, તકનીકી શિક્ષણ અને પ્રક્રિયા સુધારણા. |
| વ્યવસાયો, વાણિજ્ય, નાણાં અને રોજગાર | કાર્યને વ્યવસ્થિત કરવામાં, માહિતી સમજવામાં, પ્રોજેક્ટ વિકસાવવામાં અને વ્યાવસાયિક કુશળતા શીખવામાં મદદ કરો. |
| જાહેર સેવાઓ, કાયદો અને નાગરિક ભાગીદારી | દસ્તાવેજો અને પ્રક્રિયાઓને સમજવામાં સરળ અને માહિતીને ઍક્સેસ કરવામાં સરળ બનાવો. |
| કમ્પ્યુટિંગ, સાયબર સુરક્ષા, રોબોટિક્સ અને ટેલિકોમ્યુનિકેશન્સ | સોફ્ટવેર વિકસાવવામાં, સિસ્ટમને સમજવામાં અને ઉપયોગી સાધનો બનાવવામાં મદદ કરો. |
| કલા, સંસ્કૃતિ, મીડિયા, ભાષાઓ અને વારસો | લેખન, અનુવાદ, છબીઓ, વિડિયો, સર્જનાત્મક પ્રોજેક્ટ્સ અને સાંસ્કૃતિક શેરિંગને સપોર્ટ કરો. |

આ યોગદાન અને વિકાસ માટેના નિર્દેશો છે, એવો દાવો નથી કે દરેક ક્ષેત્ર-વિશિષ્ટ એપ્લિકેશન પહેલેથી જ વિતરિત અથવા માન્ય છે. અમે રોજિંદા ઉપયોગ માટે સરળ માર્ગદર્શન, જરૂર પડે ત્યારે અદ્યતન વિકલ્પો સ્પષ્ટ કરવા, પારદર્શક હાર્ડવેર અને ક્લાઉડ આવશ્યકતાઓ અને દરેક ક્ષેત્ર અને સ્થાનિક સંદર્ભને જાણતા લોકો સાથે સહયોગ ઇચ્છીએ છીએ.

## પ્રોજેક્ટ સ્થિતિ

સ્ક્રીનશૉટ જાળવણીકર્તા દ્વારા સ્થાનિક રીતે સંકલિત Windows એપ્લિકેશન બતાવે છે. સ્ત્રોત ફેરફારો, લક્ષિત પરીક્ષણો અને હાર્ડવેર માન્યતા અલગથી દસ્તાવેજીકૃત કરવામાં આવે છે; આ દરેક મોડેલ, પ્લેટફોર્મ અથવા ક્લાઉડ એકાઉન્ટને માન્ય કરતું નથી.

મેન્યુઅલ GitHub Actions બિલ્ડ તમામ અગિયાર વિતરણ પ્રકારો માટે સક્ષમ છે. અનુસરો [બિલ્ડ પરિણામો અને ચકાસાયેલ ઉમેદવાર ડાઉનલોડ્સ](docs/CI_DISTRIBUTIONS.md); દરેક પ્લેટફોર્મ માટે ઉપલબ્ધતા અલગથી રેકોર્ડ કરવામાં આવે છે. ઉમેદવારો સહી કરેલ ઉત્પાદન પ્રકાશનોથી અલગ છે. વિતરણ જરૂરિયાતો માં વર્ણવેલ છે [સત્તાવાર પ્રકાશન નીતિ](OFFICIAL_RELEASES.md) અને [પૃષ્ઠ પ્રકાશિત કરે છે](https://github.com/TRON-ABS/Novera/releases). હાલના અપડેટર-અક્ષમ ઉમેદવારો આંતરિક રહે છે. સાર્વજનિક પ્રકાશનોને રૂપરેખાંકિત અને ચકાસાયેલ અપડેટ મિકેનિઝમની જરૂર છે; [ડેસ્કટોપ હસ્તાક્ષર તપાસો અને બાકીની લોંચ આવશ્યકતાઓ દસ્તાવેજીકૃત છે](docs/LAUNCH_STATUS.md).

## આધાર Novera

એક સ્વતંત્ર સંશોધક તરીકે, હું જાણું છું કે કેવી રીતે ભંડોળનો અભાવ સંશોધનને આગળ ધપાવવાનું મુશ્કેલ બનાવી શકે છે.

જો તમે Novera સાહસનો ભાગ બનવા માંગતા હો, તો તમે સ્વૈચ્છિક બિટકોઈન યોગદાન સાથે મારા સંશોધન અને પ્રોજેક્ટના વિકાસને સમર્થન આપી શકો છો.

તમારા સમર્થન, યોગદાન, પ્રતિસાદ અને પ્રોત્સાહન માટે દરેકનો આભાર. દરેક હાવભાવ આ સાહસમાં ગણાય છે!
