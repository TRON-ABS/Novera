## Novera 1.0.1

Novera 1.0.1 تھلے دتے گئے پلیٹ فارماں لئی دستیاب اے۔ اپنے سسٹم لئی پیکیج ڈاؤن لوڈ کرو یا ایہدے دستخط شدہ اپ ڈیٹ چینل نوں ورتو۔ جدوں تسی نواں پیکیج انسٹال کردے او یا اپ ڈیٹ قبول کردے او تے موجودہ تنصیبات اپ ڈیٹ ہوندیاں نیں.

- سیکیورٹی: دور دراز دے صفحیاں لئی سخت مقامی اجازتاں، نیٹ ورک APIs تے سرور ٹولز لئی تصدیق، محفوظ خفیہ اسٹوریج تے منتقلی، محفوظ فائل/میڈیا تک رسائی، سپریڈ شیٹ پارسنگ تے بلڈ سکرپٹ۔ بے نقاب انحصار نو اپ ڈیٹ کر دتا گیا اے; باقی ایڈوائزریز نو کھل کے ٹریک کیتا جاندا اے۔
- رازداری: اعدادوشمار تے غلطی دی رپورٹاں نوں وکھری رضامندی دی لوڑ اے تے پہلے توں طے شدہ طور تے بند رہندیاں نیں. بلڈز چ دستاویزی منزل دی ترتیب شامل اے۔ تکنیکی تشخیص فلٹر کیتی جاندی اے; صارفین ایکٹیویشن دا کنٹرول رکھدے ہن۔
- لوکل انجن: `llama.cpp v0.9.0` (`b12110`, `cd959bae99ff4bed22bef2604f45241c09bbb8c8`)۔ انجن ورژن تے ایپلی کیشن ورژن وکھرے ہن۔ ابتدائی ماڈل دی ترتیبات تے ماڈل/پروجیکٹر رجسٹریشن نو درست کیتا گیا اے، جس چ `kv_unified` شامل اسٹارٹ اپ ناکامی وی شامل اے۔ موجودہ ذاتی ترتیبات محفوظ ہن۔
- بولیاں: 24 وادھو بولیاں تے ویریئنٹ انٹرفیس تے ترجمہ شدہ README مجموعہ نوں 104 وچ لیاؤندے نیں، ہر کیٹلاگ وچ 2,435 انٹرفیس کلیداں دے نال۔ ایہ کوریج ہر زبان وچ مقامی ادارتی معیار یا تقریر دی حمایت دی تصدیق نئیں کردی۔
- **LFM3-Omni-2B Q4_K_M** — ڈیسک ٹاپ تے موبائل تے ڈیفالٹ اے۔ متن، تصویراں تے آڈیو لئی اک کمپیکٹ ماڈل، مطلوبہ `mmproj` فائل دا استعمال کردے ہوئے۔ ڈاؤن لوڈ کرو: دوناں فائلاں لئی 1.39 GB دے بارے چ۔ ہلکے ملٹی موڈل سیٹ اپ لئی اینوں چنو۔ آواز دی خصوصیات پلیٹ فارم تے انجن تے منحصر اے۔ اک لمبا سیاق و سباق زیادہ میموری استعمال کردا اے۔
- **NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M** — گل بات، لکھن، اوزار تے منظم جواباں لئی صرف متن دا متبادل۔ ڈاؤن لوڈ کرو: 6.18 GB دے بارے چ۔ ایدے لئی LFM3-Omni توں زیادہ میموری دی لوڑ اے تے ایہ تصویراں یا آڈیو نوں آپ پروسیس نئیں کردا۔ بولے گئے جواباں چ سسٹم دی آواز ورتی جاندی اے۔ جدوں تہاڈے کول کافی میموری ہووے تے ٹیکسٹ ٹاسکاں لئی ایہنوں چنو۔ وسیلیاں دے نال حقیقت پسندانہ جواباں دی جانچ کرو۔
- 1.0.1 لئی، LFM3-Omni-2B Q4_K_M اپنے مطلوبہ `mmproj-LFM3-Omni-2B-Q4_K_M.gguf` دے نال ڈیسک ٹاپ تے موبائل تے ڈیفالٹ سفارش اے؛ NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M صرف متن دا متبادل رہندا اے۔ ابتدائی سیاق و سباق ڈیسک ٹاپ تے 32,768 ٹوکن تے موبائل تے 2,048 اے۔ لمے سیاق و سباق زیادہ میموری استعمال کردے ہن۔ موجودہ ماڈل دے انتخاب تے ترتیبات نو واضح طور تے تبدیل کرن تک محفوظ رکھیا جاندا اے۔
- آواز: LFM3-Omni لئی براہ راست مقامی مائیکروفون ان پٹ، مسلسل گل بات تے خودکار بھیجنا، آڈیو ماڈلاں لئی مرد/عورت دے جوابی آوازاں، تے کلاسک ماڈلاں لئی سسٹم تقریر۔ مائیکروفون کیپچر توں آزاد، ٹائپ کیتے گئے پیغامات تے دوبارہ پیدا کرن لئی جواب پڑھنا وی کم کردا اے۔ اک نکا جیا ساؤنڈ بٹن پڑھن نو فعال یا خاموش کردا اے۔

| **LoRA / PEFT اڈاپٹرز** | Safetensors فراہم کرن آلے وچ اپنے وکھرے لوکل اڈاپٹر دے نال اک مکمل بیس درآمد کرو۔ | غیر کوانٹائزڈ کازل Transformers بیس، ملاپ دی شناخت، ٹینسر چیک تے مجموعی میموری تخمینہ؛ [سیٹ اپ تے حداں](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | مطابقت گھنے Llama/Qwen2/Qwen3 فی ٹینسر FP8 برآمدات دے لیی مقامی CUDA عملدرآمد۔ | آرکیٹیکچر / ٹینسر چیک تے حقیقی کرنل پروب؛ [سیٹ اپ تے حداں](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |

| **AWQ** | 4-بٹ GEMM آپریشن فیوژن دے بغیر ماڈل چوکیاں۔ | NVIDIA CUDA تے اختیاری GPTQModel/Transformers لوڈر۔ |

| **EXL3** | مکمل کوانٹائزڈ Safetensors ماڈل فولڈرز ExLlamaV3 دے ذریعے لوڈ کیتے گئے؛ CUDA دے نال اصل نسل دا تجربہ کیتا گیا۔ | NVIDIA GPU، وکھرا Python 3.12 ماحول تے مطابقت پذیر فن تعمیر؛ کوئی CPU فال بیک نئیں۔ |
| **EXL2** | وقف ExLlamaV2 لوڈر؛ GPU. تے سٹریمنگ، کینسلیشن تے ان لوڈ ٹیسٹ کیتا گیا | CUDA Attention backend آزمائشی سافٹ ویئر اسٹیک دے لی واضح طور تے منتخب ہونی چاہیدی اے۔ اک مکمل ماڈل چیک پوائنٹ تے دستیاب VRAM دی لوڑ اے۔ |
| **MLX** | Apple Silicon تے مطابقت پذیر ماڈل۔ | MLX انجن تے سپورٹڈ پلیٹ فارم۔ |

ہب ہن پن کردا اے **LFM3-1.7B** مطابقت پذیر ترتیباں دے لی اس دی LiquidAI سفارش دے طور تے، Q4_K_M، Q6_K تے Q8_0 ویرینٹ دے نال۔ پہلا چلن آلا ماڈل اوہی رہندا اے جہڑا اوپر دتے گئے گائیڈڈ ترتیب وچ درج اے۔

فلٹر ڈاؤن لوڈ وزن توں **1 GB دے تحت 500 GB تے اپر**، فیر ہارڈ ویئر فٹ، سائز، حالیہ یا ڈاؤن لوڈ دے لحاظ نال ترتیب دیو۔ نتائج آہستہ آہستہ لوڈ ہوندے نیں; فلٹر لیان آلے ماڈلاں تے اوہناں دے ڈیفالٹ ویرینٹ تے لاگو ہوندے نے۔ میموری ایڈوائس دستیاب RAM/VRAM، سیاق و سباق تے ساتھی اجزاء نو استعمال کردی اے، بغیر ڈبل گنتی دے سانجھی GPU میموری دے۔

AWQ 4-بٹ، GPTQ 4-بٹ، NF4 تے INT8 ہر ایک نے آف لائن بنائے گئے چھوٹے غیر تربیت یافتہ ماڈلز استعمال کر کے RTX 5070 Laptop اُتے متن جنریٹ کیتا۔ ایں نال ہر ماڈل دی کوالٹی یا کارکردگی نئیں بلکہ لوڈنگ تے ایگزیکیوشن کی تصدیق ہوندی اے۔ **ایہ اضافے ماخذ وچ ہن: دوبارہ تعمیر تے مطابقت پذیر انحصار دی لوڑ اے; ایہ README اپ ڈیٹ انسٹال شدہ بائنری نو اپ گریڈ نئیں کردا۔**

**RTX 5070 Laptop تے ماپیا گیا:** Qwen2.5-0.5B-Instruct، سیاق و سباق 2,048، پرامپٹ 272 ٹوکن، 128 جنریٹڈ ٹوکن، پنج گرم رن: میڈین ڈیکوڈ **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. ایتھے GGUF توں ودھ کوئی رفتار دا فائدہ نئیں وکھایا گیا۔ کوانٹائزیشن / انشانکن مختلف اے، تے EXL3 اک سادہ ریاضی دے ٹیسٹ وچ ناکام رہیا؛ ایہ نتائج عام رفتار یا معیار دی درجہ بندی نئیں ہن۔ [مکمل پیمائش تے حدود](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** اک اختیاری، وکھرا منظم OpenAI-مطابقت آلا سرور کنکشن اے، جہڑا ڈیفالٹ دے طور تے غیر فعال اے۔ تصدیق شدہ EXL3 ماڈل دریافت تے سٹریمنگ دا تجربہ کیتا گیا۔ منظم مقامی ExLlama روٹ وکھرا رہندا اے۔ [ExLlama سیٹ اپ تے TabbyAPI کنکشن](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

ڈیفالٹ ہارڈویئر-موافقت شدہ ترتیب اسی مطابقت تے دستیاب میموری ٹائر دے اندر نویں ریلیزاں دا حق رکھدی اے۔ انسٹال کیتے گئے ماڈل خودبخود نئیں بدلے جاندے۔

[کوانٹائزڈ Safetensors سیٹ اپ](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [فارمیٹس، ترجیحات تے توثیق](docs/SUIVI_MOTEURS.md)

اپ ڈیٹ شدہ ذرائع نے شامل کیتا **Windows x64 لئی ترتیباں وچ اختیاری منظم اجزاء**: نجی Python ماحول، پن کیتے گئے CPU/CUDA پروفائلز، ڈاؤن لوڈ، تصدیق، مرمت تے ہٹان توں پہلے تخمینے تے تصدیق۔ اپنی مرضی دے مترجم دے راہ اعلیٰ درجے دے اختیارات دے تحت رہندے ہن۔ مقامی GGUF انجن اپنے موجودہ اجزاء نو برقرار رکھدے نیں; موبائل تے کلاؤڈ ڈیسک ٹاپ پائیتھن/PyTorch ڈاؤن لوڈ نئیں کردے۔ تن نجی CPU/برآمد پروفائلز مصنوعی ٹیسٹ ڈیٹا دے نال استعمال کیتے گئے؛ مینٹینر نے 1 نومبر 2026 تے ڈیسک ٹاپ دے کامیاب استعمال دی اطلاع دتی اے۔ GPU پروفائلز تے کلین-PC انسٹالیشن نوں ہُن وی وکھری، تفصیلی توثیق دی لوڑ اے۔ [پروفائلز تے ٹیسٹ دی حداں](docs/REPRISE_COMPOSANTS_GERES_80_LANGUES.md). EXE وچ اسٹیک نو سرایت کرنا ملتوی کر دتا گیا اے۔
