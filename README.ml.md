![Novera സൃഷ്ടിച്ച ഇമേജും അളവ്, വിത്ത്, അപ്‌സ്‌കേലിംഗ്, ഓട്ടോമാറ്റിക് മെമ്മറി എന്നിവയുള്ള ഏകീകൃത ഡാഷ്‌ബോർഡും](.github/assets/novera-dashboard-2026-11-01.png)

*റിയൽ Windows ആപ്ലിക്കേഷൻ സ്ക്രീൻഷോട്ട് 1 നവംബർ 2026-ൽ മെയിൻ്റനർ വിതരണം ചെയ്തു, ആപ്ലിക്കേഷൻ നന്നായി പ്രവർത്തിക്കുന്നുവെന്ന് റിപ്പോർട്ട് ചെയ്യുന്നു. ഇത് ഒരു ജനറേറ്റഡ് ലാൻഡ്‌സ്‌കേപ്പും അതിൻ്റെ സംരക്ഷിച്ച ഫയൽ നിയന്ത്രണങ്ങളും ഏകീകൃത ക്രിയേഷൻ ഡാഷ്‌ബോർഡും കാണിക്കുന്നു; ഇതൊരു മോക്കപ്പ് അല്ല.*

ഒരു പാനൽ, അഞ്ച് മോഡുകൾ: **ഓട്ടോ / വാചകം / ചിത്രം / സംഗീതം / വീഡിയോ**. നിയന്ത്രണങ്ങൾ തിരഞ്ഞെടുത്ത മോഡ് പിന്തുടരുന്നു: അനുപാതം, റെസല്യൂഷൻ, ദൈർഘ്യം, കാഡൻസ്, ഗുണനിലവാരം, ഇൻസ്ട്രുമെൻ്റൽ, വരികൾ, വിത്ത്, അളവ്. പാനലിൻ്റെ വീതിയും ബട്ടണുകളും വിൻഡോയിലേക്കും വിവർത്തനം ചെയ്‌ത ലേബലുകളിലേക്കും പൊരുത്തപ്പെടുന്നു.

- **1–10 തുടർച്ചയായ തലമുറകൾ**, 1-ലേക്ക് സ്ഥിരസ്ഥിതിയായി, ഇമേജ്, മ്യൂസിക്, വീഡിയോ എന്നിവയ്ക്കായുള്ള സ്വതന്ത്ര അളവുകൾ. സ്റ്റോപ്പ് സജീവമായ ടാസ്‌കും ശേഷിക്കുന്ന ക്യൂവും റദ്ദാക്കുന്നു.
- **ക്രമരഹിതമായ, സ്ഥിരമായ, +1, −1 വിത്തുകൾ**, പ്രീസെറ്റ് അല്ലെങ്കിൽ ഇഷ്‌ടാനുസൃത അനുപാതങ്ങളും ഓപ്‌ഷണലും **Real-ESRGAN ×2/×4** അപ്‌സ്‌കേലിംഗ്.
- തിരഞ്ഞെടുത്ത മോഡൽ, ഓട്ടോമാറ്റിക് മെമ്മറി, അറ്റാച്ച്‌മെൻ്റുകൾ, നിർദ്ദേശങ്ങൾ, വെബ് തിരയൽ, ടൂളുകൾ എന്നിവ ഒരേ ബാറിൽ തന്നെ തുടരും. ഉപകരണങ്ങൾ മോഡൽ കഴിവുകളെയും അനുവദിച്ച ആക്‌സസ്സിനെയും ആശ്രയിച്ചിരിക്കുന്നു.

## ആദ്യ ലോഞ്ച് മുതൽ ഫലങ്ങൾ വരെ

**ഞങ്ങളുടെ ഓട്ടോമേഷൻ തയ്യാറെടുപ്പിനെ സമ്പൂർണ്ണ നിർവ്വഹണ വർക്ക്ഫ്ലോയുമായി ബന്ധിപ്പിക്കുന്നു.** Novera തിരഞ്ഞെടുത്ത കോൺഫിഗറേഷനായി ലഭ്യമായ സാങ്കേതിക ഘട്ടങ്ങൾ കൈകാര്യം ചെയ്യുന്നു, അതേസമയം വിപുലമായ നിയന്ത്രണങ്ങൾ ആക്‌സസ് ചെയ്യാനാകും.

| ഘട്ടം | എന്താണ് Novera കൈകാര്യം ചെയ്യുന്നത് |
| --- | --- |
| **1. ആരംഭിക്കുക** | ആദ്യ ലോഞ്ചിൽ പിന്തുണയ്‌ക്കുന്ന ഒരു സിസ്റ്റം ഭാഷ തിരഞ്ഞെടുക്കുകയും നിങ്ങളുടെ മുൻഗണന സംരക്ഷിക്കുകയും ചെയ്യുന്നു. ആരംഭ മോഡലുകളും ഉപയോഗപ്രദമായ ഹാർഡ്‌വെയർ വിവരങ്ങളും അവതരിപ്പിക്കുന്നു. |
| **2. തയ്യാറാക്കുക** | ഗൈഡഡ് ഇൻസ്റ്റാളേഷൻ ടെക്‌സ്‌റ്റ്, എംബെഡിംഗുകൾ, ഇമേജ്, മ്യൂസിക്, വീഡിയോ, അപ്‌സ്‌കേലിംഗ് എന്നിവ വാഗ്ദാനം ചെയ്യുന്നു. ഇത് നിങ്ങളുടെ അംഗീകാരത്തിന് മുമ്പായി ഘടകങ്ങൾ, വലുപ്പങ്ങൾ, ശൂന്യമായ ഇടം എന്നിവ പ്രിവ്യൂ ചെയ്യുന്നു, തുടർന്ന് പുരോഗതി, താൽക്കാലികമായി നിർത്തുക/പുനരാരംഭിക്കുക, SHA-256 പരിശോധന എന്നിവ ഉപയോഗിച്ച് ഡൗൺലോഡുകൾ ട്രാക്കുചെയ്യുന്നു. |
| **3. കോൺഫിഗർ ചെയ്യുക** | മോഡലുകളും അവയുടെ ഘടകങ്ങളും രജിസ്റ്റർ ചെയ്യുന്നു, പ്രസക്തമായ പ്രൊഫൈലുകൾ തയ്യാറാക്കുകയും ആവശ്യമായ ഡിപൻഡൻസികൾ റിപ്പോർട്ട് ചെയ്യുകയും ചെയ്യുന്നു. വീണ്ടെടുക്കൽ ഉൾച്ചേർക്കലുകൾ CPU-ൽ സംരക്ഷിച്ച CPU/GPU ചോയ്‌സ് ഉപയോഗിച്ച് ആരംഭിക്കുന്നു. പുതിയ സംഗീത പ്രൊഫൈലുകൾ ഇൻസ്ട്രുമെൻ്റൽ മോഡിലേക്ക് ഡിഫോൾട്ട്. |

| **5. നടപ്പിലാക്കുക** | ഓട്ടോമാറ്റിക് മെമ്മറി സജീവമായ പ്രവർത്തനത്തിനായി കാത്തിരിക്കുന്നു, ആവശ്യമില്ലാത്ത മോഡലുകൾ പുറത്തിറക്കുകയും ആവശ്യമായ ഉറവിടങ്ങൾ വീണ്ടും ലോഡുചെയ്യുകയും ചെയ്യുന്നു. ഒരു 1–10 ജോബ് സീരീസ് ക്രമത്തിൽ പ്രവർത്തിക്കുകയും അടുത്ത ജോലിക്ക് മുമ്പ് ഉറവിടങ്ങൾ റിലീസ് ചെയ്യുകയും ചെയ്യുന്നു. ക്ലൗഡ് ദാതാക്കൾ തിരഞ്ഞെടുത്ത അക്കൗണ്ടും കോൺഫിഗറേഷനും ഉപയോഗിക്കുന്നു. |
| **6. വീണ്ടെടുത്ത് വീണ്ടും ഉപയോഗിക്കുക** | Novera സിസ്റ്റം ഫോൾഡറുകളിൽ മീഡിയ സംരക്ഷിക്കുന്നു, ഫലങ്ങളും ലഭ്യമായ സമയവും പ്രദർശിപ്പിക്കുന്നു, തുടർന്ന് വേരിയൻ്റുകൾ, ലൈബ്രറി, പകർത്തൽ, കയറ്റുമതി അല്ലെങ്കിൽ സിസ്റ്റം പങ്കിടൽ എന്നിവ വാഗ്ദാനം ചെയ്യുന്നു. മറ്റൊരു അപ്ലിക്കേഷനിലേക്ക് അയയ്‌ക്കുന്നത് നിങ്ങളുടെ പ്രവർത്തനമായി തുടരുന്നു. |

ഓട്ടോമേഷൻ സംയോജിത എഞ്ചിനുകളും വർക്ക്ഫ്ലോകളും ഉൾക്കൊള്ളുന്നു; ഇത് എല്ലാ ഹബ് മോഡലുകളും എക്സിക്യൂട്ടബിൾ ആക്കുന്നില്ല. ഹാർഡ്‌വെയർ, ഇൻസ്റ്റാൾ ചെയ്ത ഘടകങ്ങൾ, പ്രൊവൈഡർ ആക്‌സസ് എന്നിവ എന്തെല്ലാം പ്രവർത്തിപ്പിക്കാമെന്ന് നിർണ്ണയിക്കുന്നു. ഫോൾഡറുകൾ, ഫയൽ മാറ്റങ്ങൾ, ഷെൽ കമാൻഡുകൾ എന്നിവ സംഭാഷണത്തിൻ്റെ പ്രവേശന ഗ്രാൻ്റുകൾ പിന്തുടരുന്നു.

പുതുക്കിയ ഉറവിടങ്ങളിൽ, **കോൺഫിഗറേഷനുകൾ അതിൻ്റെ ശുപാർശകൾ മൊബൈലിലേക്കും പരിമിതമായ ഹാർഡ്‌വെയറിലേക്കും മാറ്റുന്നു**: LFM3-1.7B Q4, അല്ലെങ്കിൽ LFM3-Omni-2B Q4 അതിൻ്റെ പ്രൊജക്‌ടറിനൊപ്പം റിപ്പോർട്ട് ചെയ്‌ത മെമ്മറിയും എഞ്ചിൻ ആവശ്യകതകളും നിറവേറ്റുമ്പോൾ. ലഭ്യമല്ലാത്ത പ്രാദേശിക തലമുറ മറച്ചിരിക്കുന്നു അല്ലെങ്കിൽ തടഞ്ഞിരിക്കുന്നു; കോൺഫിഗർ ചെയ്‌ത ക്ലൗഡ് ഇമേജും സംഗീതവും വീഡിയോയും ലഭ്യമാണ്. ഇൻ്റർഫേസ് മാർഗ്ഗനിർദ്ദേശം 80 ഭാഷാ കാറ്റലോഗുകൾ വീണ്ടും ഉപയോഗിക്കുന്നു. ഈ എസ്റ്റിമേറ്റുകൾക്ക് ഇൻസ്റ്റോൾ ചെയ്ത ആപ്ലിക്കേഷനുകളിൽ എത്താൻ ഉപകരണ പരിശോധനയും പുനർനിർമ്മാണവും ആവശ്യമാണ്.

ഓപ്‌ഷണൽ മെയിൻ്റനൻസ് ഡയഗ്‌നോസ്റ്റിക്‌സ് ഇപ്പോൾ ബിൽഡുകളും ഇൻസ്ട്രുമെൻ്റ് കൈകാര്യം ചെയ്യുന്ന പരാജയങ്ങളും JavaScript ഒഴിവാക്കലുകളും പ്രത്യേക സമ്മതവും ഫിൽട്ടർ ചെയ്ത സാങ്കേതിക ഫീൽഡുകളും ഉപയോഗിച്ച് വേർതിരിച്ചിരിക്കുന്നു. പരിപാലിക്കുന്നയാൾക്കായി ഒരു മണിക്കൂർ തോറും ഒരു പ്രൊഡക്ഷൻ ഇമെയിൽ അലേർട്ട് കോൺഫിഗർ ചെയ്‌തിരിക്കുന്നു. സ്വകാര്യ ഉറവിട മാപ്പുകളും അലേർട്ട് വിശദാംശങ്ങളും പിന്തുടരുന്നു [മെയിൻ്റനൻസ് റൺബുക്ക്](docs/MAINTENANCE.md); ടെസ്റ്റ് ഇമെയിൽ രസീത് സ്ഥിരീകരിച്ചു, അതേസമയം ആധികാരിക ചിഹ്നം അപ്‌ലോഡ് ചെയ്യലും അടുത്ത ബൈനറിയിലെ പരിശോധനയും റിലീസ് ചെക്കുകളായി തുടരും.

AWQ 4-bit, GPTQ 4-bit, NF4, INT8 എന്നിവ ഓരോന്നും സൃഷ്‌ടിച്ച RTX 5070 Laptop ഓഫ്‌ലൈനിൽ സൃഷ്ടിക്കാത്ത മോഡലുകളിൽ സൃഷ്ടിച്ച ടെക്‌സ്‌റ്റ്. ഇത് ലോഡിംഗും എക്സിക്യൂഷനും സാധൂകരിക്കുന്നു, എല്ലാ മോഡലുകളുടെയും ഗുണനിലവാരമോ പ്രകടനമോ അല്ല. **ഈ കൂട്ടിച്ചേർക്കലുകൾ ഉറവിടത്തിലാണ്: പുനർനിർമ്മാണവും അനുയോജ്യമായ ഡിപൻഡൻസികളും ആവശ്യമാണ്; ഈ README അപ്‌ഡേറ്റ് ഇൻസ്റ്റാൾ ചെയ്ത ബൈനറി അപ്‌ഗ്രേഡ് ചെയ്യുന്നില്ല.**

**RTX 5070 Laptop-ൽ അളന്നു:** Qwen2.5-0.5B-Instruct, സന്ദർഭ 2,048, പ്രോംപ്റ്റ് 272 ടോക്കണുകൾ, 128 ജനറേറ്റഡ് ടോക്കണുകൾ, അഞ്ച് ഊഷ്മള റണ്ണുകൾ: മീഡിയൻ ഡീകോഡ് **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. ## 80 ഇൻ്റർഫേസ് ഭാഷകളും വകഭേദങ്ങളും

**എല്ലാ 80 കാറ്റലോഗുകളും നിലവിലെ 2,429 ഇംഗ്ലീഷ് കീകൾ ഉൾക്കൊള്ളുന്നു** മെനുകൾ, കോൺഫിഗറേഷനുകൾ, ക്രമീകരണങ്ങൾ, സഹായം, മീഡിയ നിയന്ത്രണങ്ങൾ എന്നിവയുൾപ്പെടെ 15 നെയിംസ്പേസുകളിലുടനീളം. ബഹുവചന രൂപങ്ങളും ഇൻ്റർഫേസ് ദിശയും തിരഞ്ഞെടുത്ത ഭാഷ പിന്തുടരുന്നു. പ്രതികരണവും ശബ്ദ ഭാഷകളും മോഡലിനെ പ്രത്യേകം ആശ്രയിച്ചിരിക്കുന്നു.

ഈ സാങ്കേതിക കവറേജ് ഭാഷാ നിലവാരം സാക്ഷ്യപ്പെടുത്തുന്നില്ല: **നേറ്റീവ് അവലോകനവും പ്രാദേശിക അനുരൂപീകരണവും ആവശ്യമാണ്**. എന്നതിലെ നേറ്റീവ് ലേബലുകളും അറിയപ്പെടുന്ന പരിധികളും കാണുക [ഭാഷാ ഗൈഡ്](docs/LANGUAGES.md) ഒപ്പം [ഓഡിറ്റ് റിപ്പോർട്ട്](deliverables/interface-audit-2026-10-29/RAPPORT.md).

## പ്രോജക്റ്റ് നില

**Novera 1.0.0 Windows, Linux, macOS, Android എന്നിവയ്ക്ക് ലഭ്യമാണ്.** മെയിൻ്റനർ പ്രാദേശികമായി സമാഹരിച്ച Windows ആപ്ലിക്കേഷൻ സ്ക്രീൻഷോട്ട് കാണിക്കുന്നു. ഉറവിട മാറ്റങ്ങൾ, ടാർഗെറ്റുചെയ്‌ത പരിശോധനകൾ, ഹാർഡ്‌വെയർ മൂല്യനിർണ്ണയം എന്നിവ പ്രത്യേകം രേഖപ്പെടുത്തുന്നു; ഇത് എല്ലാ മോഡലുകളേയും പ്ലാറ്റ്‌ഫോമുകളേയും ക്ലൗഡ് അക്കൗണ്ടുകളേയും സാധൂകരിക്കുന്നില്ല.

എല്ലാ പതിനൊന്ന് വിതരണ വേരിയൻ്റുകളിലും മാനുവൽ GitHub Actions ബിൽഡുകൾ പ്രവർത്തനക്ഷമമാക്കിയിരിക്കുന്നു. പിന്തുടരുക [ബിൽഡ് ഫലങ്ങളും പരിശോധിച്ച കാൻഡിഡേറ്റ് ഡൗൺലോഡുകളും](docs/CI_DISTRIBUTIONS.md); ഓരോ പ്ലാറ്റ്ഫോമിനും ലഭ്യത പ്രത്യേകം രേഖപ്പെടുത്തുന്നു. ഒപ്പിട്ട പ്രൊഡക്ഷൻ റിലീസുകളിൽ നിന്ന് സ്ഥാനാർത്ഥികൾ വ്യത്യസ്തരാണ്. വിതരണ ആവശ്യകതകൾ വിവരിച്ചിരിക്കുന്നു [ഔദ്യോഗിക റിലീസ് നയം](OFFICIAL_RELEASES.md) ഒപ്പം [റിലീസ് പേജ്](https://github.com/TRON-ABS/Novera/releases). നിലവിലുള്ള അപ്‌ഡേറ്റർ-അപ്രാപ്‌തരായ കാൻഡിഡേറ്റുകൾ ആന്തരികമായി തുടരുന്നു. പൊതു റിലീസുകൾക്ക് കോൺഫിഗർ ചെയ്തതും പരിശോധിച്ചുറപ്പിച്ചതുമായ ഒരു അപ്ഡേറ്റ് സംവിധാനം ആവശ്യമാണ്; [ഡെസ്ക്ടോപ്പ് സിഗ്നേച്ചർ പരിശോധനകളും ശേഷിക്കുന്ന ലോഞ്ച് ആവശ്യകതകളും രേഖപ്പെടുത്തിയിട്ടുണ്ട്](docs/LAUNCH_STATUS.md).
