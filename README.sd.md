## پروجيڪٽ جي حالت

**Novera 1.0.0 Windows, Linux, macOS ۽ Android لاءِ دستیاب آهي.** اسڪرين شاٽ هڪ Windows ايپليڪيشن ڏيکاري ٿو جيڪو مقامي طور تي سنڀاليندڙ طرفان مرتب ڪيو ويو آهي. ذريعن جي تبديلين، ٽارگيٽ ٽيسٽ ۽ هارڊويئر جي تصديق الڳ الڳ دستاويز ٿيل آهن؛ هي هر ماڊل، پليٽ فارم يا ڪلائوڊ اڪائونٽ جي تصديق نٿو ڪري.

دستي GitHub Actions تعميرات سڀني يارهن ورڇ وارين قسمن لاءِ فعال ٿيل آهن. جي تابعداري ڪريو [نتيجا ٺاھيو ۽ تصديق ٿيل اميدوار ڊائون لوڊ](docs/CI_DISTRIBUTIONS.md)؛ دستيابي هر پليٽ فارم لاءِ الڳ الڳ رڪارڊ ٿيل آهي. اميدوار دستخط ٿيل پيداوار رليز کان الڳ آهن. تقسيم جي گهرج ۾ بيان ڪيو ويو آهي [سرڪاري ڇڏڻ واري پاليسي](OFFICIAL_RELEASES.md) ۽ [صفحو جاري ڪري ٿو](https://github.com/TRON-ABS/Novera/releases)موجوده اپڊيٽر-معذور اميدوار اندروني طور تي رهندا آهن. عوامي رليز کي ترتيب ۽ تصديق ٿيل تازه ڪاري ميڪانيزم جي ضرورت آهي؛ [ڊيسڪ ٽاپ جي دستخط چيڪ ۽ باقي لانچ گهرجن دستاويز ٿيل آهن](docs/LAUNCH_STATUS.md).
