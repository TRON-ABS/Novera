# feat(creation): add image seed modes and optional Real-ESRGAN upscaling

Local image requests previously always used a numeric fixed seed and had no optional upscaling stage. Add random, fixed, incrementing and decrementing seed modes, a reusable previous seed, per-profile reservation and an explicit 2048 × 2048 generation limit. New configurations default to random; saved profiles without a mode retain fixed behavior. One concrete uint32 seed is reserved per request and preserved across busy retries. Video and cloud requests retain their existing behavior.

Add optional Real-ESRGAN upscaling, initially disabled, with ×2 selected by default and ×4 available. Automatic selection uses the official model for the chosen factor, including a registered custom installation directory; Browse accepts compatible RRDB 23-block .pth weights. Reuse the confirmed, resumable SHA-256 installer for the official RealESRGAN_x2plus.pth and RealESRGAN_x4plus.pth files (134,102,714 bytes combined).

The bundled C++ CPU runtime failed the official ×2 checkpoint test, reporting a shape mismatch while returning success with an unchanged image. Use an owned PyTorch worker for both factors instead: tensor-only checkpoint loading, bounded tiles, CPU output buffer, CPU/CUDA selection, and parent-process cancellation. The diffusion process exits before upscaling loads its weights. Only the owned Python progress is parsed after transition, and final publication checks the expected PNG dimensions. Source paths, actual seed and final dimensions remain in local metadata.

Generation supports at most 2048 × 2048 in Novera. Optional ×2/×4 output can therefore reach 4096 × 4096 / 8192 × 8192, subject to memory; those maximum sizes were not exercised. Upscaling requires the configured media Python environment with PyTorch, Pillow and NumPy. Cloud media and video are unchanged. No new native Novera binary or full graphical end-to-end run is claimed.

Validation: 82 web tests across nine files; four Python tests; seven Rust installer tests in the isolated harness using the exact source; native cargo check --lib; TypeScript, Vite frontend build, architecture checks and 70 locale catalogs at 1,704 keys. Real official checkpoint inference on CPU and CUDA: 16 × 16 input to 32 × 32 (×2) and 64 × 64 (×4). Language drafts/adaptations require native review. Update the user guide, engine tracking, changelog, dashboard, language inventory and READMEs. No issue closure or separate merge dependency.
