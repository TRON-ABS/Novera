# fix(release): finish Android startup and canonical Novera CLI delivery

Android could start without a window, lose provider secrets through an in-memory backend, launch a desktop process for web search, reopen the keyboard while reasoning and squeeze settings beside a fixed-width menu. The CLI still shipped as jan.exe/jan despite its Novera product name.

Create the Android HTTPS startup window, persist secrets in encrypted private app storage and add pinned signing and independent APK inspection. Restore the existing hand launcher, apply the maintainer's Desktop appearance once after hydration and preserve manual mobile typing without status/thread autofocus. On narrow screens, show collapsible settings navigation above full-width content and close it after selection. Keep the wide-screen navigation.

Use DuckDuckGo's official non-JavaScript Lite GET endpoint on mobile with an honest Novera client identity and parse its result/snippet rows. Validate HTTPS destinations, cap time/response/output sizes and stop on refused requests or verification challenges. Errors identify the refusing host. No automatic provider fallback, proxy, browser impersonation or challenge solving is added. The maintainer still reports a 403 in the preceding build; successful PC requests do not establish that the phone issue is resolved.

Rename the CLI package, executable, help, examples and terminal/ACP/MCP/RPC identities to Novera. Support NOVERA environment names with existing aliases and profiles retained. Signed ZIPs use identity format 2 and novera.exe/novera. Publish Windows x64 and Linux x64 through v1.0.0-cli-novera and latest-novera-cli.json. The initial migration from old executables is manual because old clients require a jan archive entry. Preserve upstream attributions and compatible stored/wire values.

The canonical CLI release is public and its native production checks pass. Desktop and portable manifests were carried forward byte-for-byte. Four historical releases are immutable; their assets remain accessible and their notes now point to the replacement. Twelve legacy CLI files were backed up with verified digests; no files were deleted. Update the README and Pages presentation to promote Novera and keep Android marked as device testing. Quarantine only the two newly created fixture files while preserving the pre-existing profile file.
