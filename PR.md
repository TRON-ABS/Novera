## Limits and dependencies

Wan now has a pinned GPU IM2COL_3D implementation and a separate CPU-reference validation module. Twelve numerical cases passed byte-for-byte. The same tiny 256 x 144, five-frame, four-step video improved from 65.102 to 32.046 seconds with an identical encoded WebM. A real 832 x 480, five-frame, 20-step clip completed, exported and played to its end, but took 346.512 seconds. It is only 0.625 seconds long. Low-resolution visual quality is poor; the target latency at useful resolution is not achieved. Runtime assets now share a content-versioned directory to prevent mixed cached JS/WASM versions. TypeScript and the production build including the verified runtime passed.

Browser-local ACE-Step and Wan remain experimental and are not validated public production functionality. Music now has an opt-in conversation integration with the real UI results above; video conversation integration remains unfinished. Earlier isolated ACE prototypes generated instrumental, French song and a-cappella files in 38.691, 34.911 and 37.294 seconds, respectively; these are distinct measurements. Musical quality, intelligible lyrics, instrument exclusion and matched Desktop performance still require validation. Full-resolution image output is real, but base diffusion remains much slower than the maintainer's 38.7-second Desktop report; the latter used x2 and did not reconfirm all underlying model/settings details. The alternative text model has not completed a real generation test; audio/vision inputs, full offline behavior, cache cleanup and broader device testing remain unfinished.
