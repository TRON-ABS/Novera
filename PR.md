# feat(engines): manage local model memory automatically with a manual parallel mode

Switching from a local text model to image/video previously left the text weights loaded, while one global native guard prevented image and video workers from running together even on capable machines.

Add a persistent Automatic policy by default and an explicit Manual policy, with shared translated controls in the composer and General settings. Automatic requests wait for incompatible active work, release idle local text models, wait for delivered/exited media workers and load the requested model through the existing engines. Model files, selections and conversation history are preserved. Same-model text work can share ownership; nested loads, RAG and local MCP routing are protected. Manual tracks active work while allowing text/image/video requests to overlap in separate conversations and bypasses implicit engine eviction. Media processes still exit after their generation; this is not a new permanent media cache.

Keep ownership through stream completion, errors and cancellation, including shared-preparation cancellation and a later change back to Automatic. Validate native policy values and never kill an active process or remove output while cleaning idle media handles. Leave cloud-only inference independent of local eviction.

Validation: 369 web tests across 24 files, three standalone Rust policy tests, native cargo check, TypeScript without emission, 70 complete locale catalogs at 1,689 keys, architecture checks and seven architecture tests. Tests use simulated engines and tiny orchestration fixtures; three heavy local models together still require a suitable-hardware application test. No new application build or binary release; source/showcase publication is authorized. Update the product direction around advanced automation with simple defaults and explicit expert control.
