# feat(sharing): add local media exports, messaging handoff and ratios

Results previously lacked a unified share action and local media dimensions required manual editing. Add a small Share icon to text responses, completed image/video outputs and conversation actions. Preview the clicked result, selected messages or the full active conversation branch, including offscreen history, before handing it to the OS or writing files. Internal reasoning/tool traces remain filtered. Questions, web sources and generation metadata are explicit options; metadata defaults off. Public hosting is deferred by user choice.

Produce real DOCX/ODT/RTF/EPUB containers alongside Markdown/TXT/HTML/JSON/CSV/ZIP and actual print/PDF. Preserve original videos/images; provide eleven image encoders including AVIF plus an honest raster-in-SVG wrapper. Windows DataTransferManager, macOS services, Android ACTION_SEND and iOS activity adapters hand files to installed targets; Linux uses XDG Email attachment FDs. Copy file and Save support compatible chat apps without automatic sending. Own generated assets are resolved by reference; in-memory exports are bounded at 256 MiB, original local media can stream-copy, and only marked private share-cache directories expire after seven days.

Add nineteen image/video ratios and custom proportions, with resolution pills preserving the current longest side and snapping dimensions to the supported grid. Scope: local media profiles; provider-specific cloud presets remain unchanged. Add thirty interface strings across seventy catalogs (1,734 keys each), and update the user guide, development notes, changelog, dashboard and bilingual showcase.

Reproduction: open a completed response or media result → Share → choose scope/format → Prepare. Before: no unified preview/system handoff. After: explicit preview, system share, copy file, save, rich copy or print; changing scope invalidates the prepared export. For dimensions, select 16:9 at 1024²: it becomes 1024 × 576; choose a resolution to fit the selected ratio.

Linux/macOS/Android/iOS adapters need platform compilation/device tests; Word/LibreOffice fidelity is not certified. PNG/JPEG/WebP are browser conversion options; native-only formats require the rebuilt application. PDF uses the system print dialog, not direct binary sharing. Animations require Original; conversions are still images. No binary release, external message, issue closure or hosted public link.
