## Novera 1.0.1

Novera 1.0.1 sayogi pikeun platform anu didaptarkeun di handap. Unduh pakét pikeun sistem anjeun atanapi nganggo saluran pembaruan anu ditandatanganan. Pembaruan pamasangan anu aya nalika anjeun masang pakét énggal atanapi nampi apdet.

- Kaamanan: idin asli anu langkung ketat pikeun halaman jauh, auténtikasi pikeun API jaringan sareng alat pangladén, neundeun rahasia sareng migrasi anu ditangtayungan, aksés file/média anu langkung aman, parsing spreadsheet sareng ngawangun skrip. kagumantungan kakeunaan geus diropéa; advisories sésana dilacak kabuka.
- Privasi: statistik jeung laporan kasalahan merlukeun idin misah tur tetep pareum sacara standar. Wangunan kalebet konfigurasi tujuan anu didokumentasikeun. Diagnostik téknis disaring; pamaké tetep ngadalikeun aktivasina.
- Mesin lokal: `llama.cpp v0.9.0` (`b12110`, `cd959bae99ff4bed22bef2604f45241c09bbb8c8`). Versi mesin sareng versi aplikasi misah. Setélan modél awal sareng pendaptaran modél/proyektor dilereskeun, kalebet kagagalan ngamimitian anu kalebet `kv_unified`. Setelan pribadi anu tos aya disimpen.
- Basa: 24 basa jeung varian tambahan mawa panganteur jeung kumpulan README ditarjamahkeun kana 104, kalawan 2,435 konci panganteur per katalog. Liputan ieu henteu ngajamin kualitas redaksi asli atanapi dukungan pidato dina unggal basa.
- **LFM3-Omni-2B Q4_K_M** — Default dina desktop jeung mobile. Model kompak pikeun téks, gambar sareng audio, nganggo file `mmproj` anu diperyogikeun. Unduh: kira-kira 1.39 GB pikeun duanana file. ## Ti mimiti peluncuran nepi ka hasil

**Otomasi kami nyambungkeun persiapan kana alur kerja palaksanaan lengkep.** Novera nanganan léngkah-léngkah téknis anu sayogi pikeun konfigurasi anu dipilih, bari ngajaga kadali canggih tiasa diaksés.

| Lengkah | naon Novera handles |
| --- | --- |
| **1. Mimitian** | Milih basa sistem anu dirojong nalika mimiti diluncurkeun sareng ngahemat kahoyong anjeun. Presents dimimitian model jeung informasi hardware mangpaat. |
| **2. Siapkeun** | Pamasangan dipandu nawiskeun téks, émbeddings, gambar, musik, video sareng upscaling. Éta nilik komponén, ukuran sareng rohangan bébas sateuacan persetujuan anjeun, teras ngalacak undeuran kalayan kamajuan, ngareureuhkeun / neruskeun sareng verifikasi SHA-256. |
| **3. Konpigurasikeun** | Ngadaptar modél sareng komponénna, nyiapkeun profil anu relevan sareng ngalaporkeun katergantungan anu diperyogikeun. Retrieval embeddings dimimitian dina CPU kalayan pilihan CPU/GPU disimpen. Propil musik anyar standar kana mode instrumental. |
| **4. Ngartos pamundut** | Rute otomatis ngenalkeun pamundut nyiptakeun kana téks, gambar, musik atanapi pidéo. Anjeun oge tiasa sacara eksplisit milih mode kaluaran sareng model lokal atanapi awan. |
| **5. Laksanakeun** | memori otomatis ngantosan karya aktip, ngaleupaskeun model unneeded na reloads sumberdaya diperlukeun. Runtuyan padamelan 1–10 jalan dina urutan sareng ngaluarkeun sumber sateuacan padamelan salajengna. Panyadia awan nganggo akun sareng konfigurasi anu dipilih. |
| **6. Cokot deui sareng dianggo deui** | Nyimpen média dina folder sistem Novera, mintonkeun hasil jeung timings sadia, lajeng nawarkeun varian, perpustakaan, nyalin, ékspor atawa babagi sistem. Ngirim ka aplikasi anu sanés tetep tindakan anjeun. |

Automation nyertakeun mesin terpadu jeung workflows; éta henteu ngajantenkeun unggal modél Hub tiasa dieksekusi. Hardware, komponén dipasang sareng aksés panyadia nangtukeun naon anu tiasa dijalankeun. Polder, parobahan file sareng paréntah cangkang turutan hibah aksés paguneman.

## Hub sareng modél anu cocog

**GGUF, standar sareng kuantitatif Safetensors, ONNX, sareng MLX**: ngajalajah model dumasar tugas jeung milih varian nu cocog jeung mesin jeung hardware Anjeun.

| Kulawarga | Rojongan dina sumber | sarat |
| --- | --- | --- |
| **GGUF** | Generasi téks ngaliwatan llama.cpp; gambar jeung video komponén pikeun propil dirojong. | Arsitéktur dipikawanoh ku mesin dibuntel. |
| **Beulah GGUF** | Hiji varian per runtuyan lengkep, ukuran dijumlahkeun, sadaya-shard download jeung ukuran / SHA-256 / cek header. | Ngaran koropak nomer standar; Ngundeur 500 GB henteu hartosna modél cocog sareng ieu PC. |
| **Standar Safetensors** | Ngalengkepan folder ngaliwatan Transformers, téks kausal dina CPU atawa NVIDIA CUDA. | Konfigurasi, tokenizer sareng unggal beling anu diperyogikeun. |
| **ONNX Runtime** | impor lokal tina numerik / grafik bool sarta disiapkeun GenAI ékspor téks. | folder lengkep disahkeun; tugas-spésifik preprocessing / postprocessing diperlukeun; [setelan sareng wates](onnx-server/README.md). |
| **LoRA / PEFT adaptor** | Impor basa lengkep sareng adaptor lokal anu misah dina panyadia Safetensors. | Unquantized kausal Transformers dasar, cocog identitas, cék tensor jeung estimasi memori kumulatif; [setelan sareng wates](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | asli CUDA palaksanaan pikeun padet cocog Llama/Qwen2/Qwen3 per-tensor FP8 ékspor. | Arsitéktur / cék tensor jeung usik kernel nyata; [setelan sareng wates](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |
| **NVFP4 LLM / ModelOpt** | Dipak block-16 FP4 projections ngaliwatan asli CUDA GEMMs; misah ti gambar NVFP4. | cocog Blackwell GPU, dirojong dimensi / ékspor jeung usik kernel sabenerna; modél uji anu can dilatih diuji dina RTX 5070. |
| **AWQ** | 4-bit GEMM checkpoints modél tanpa fusi operasi. | NVIDIA CUDA sarta pilihan GPTQModel/Transformers loaders. |
| **GPTQ** | Konfigurasi 2/3/4/8-bit, format gptq/gptq_v2. | NVIDIA CUDA, GPTQModel jeung Optimum; palaksanaan nyata diuji dina 4 bit. |
| **bitsandbytes** | 4-bit NF4/FP4 atanapi 8-bit INT8. | NVIDIA CUDA jeung kagumantungan pilihan; nyata NF4 jeung INT8 tés. |
| **EXL3** | Ngalengkepan quantized Safetensors polder model dimuat ngaliwatan ExLlamaV3; generasi sabenerna kalawan CUDA ieu diuji. | NVIDIA GPU, misah Python 3.12 lingkungan jeung arsitéktur cocog; euweuh CPU fallback. |
| **EXL2** | dedicated ExLlamaV2 loader; streaming, pembatalan sareng ngabongkar momotanana diuji dina GPU. | CUDA Attention backend kudu dipilih sacara eksplisit pikeun tumpukan software diuji; titik pamariksaan modél lengkep sareng sayogi VRAM diperyogikeun. |
| **MLX** | Model anu cocog dina Apple Silicon. | MLX mesin sareng platform anu dirojong. |

The Hub ayeuna pin **LFM3-1.7B** salaku na LiquidAI rekomendasi pikeun konfigurasi cocog, jeung Q4_K_M, Q6_K jeung Q8_0 varian. Modél anu munggaran dijalankeun tetep anu didaptarkeun dina konfigurasi anu dipandu di luhur.

Filter download beurat ti **dina 1 GB nepi ka 500 GB ka luhur**, teras diurutkeun dumasar hardware pas, ukuran, recency atanapi undeuran. Hasil beban progressively; saringan dilarapkeun ka model anu dipulut sareng varian standarna. Saran memori ngagunakeun sadia RAM/VRAM, kontéks jeung komponén pendamping, tanpa ganda-cacah dibagikeun GPU memori.

AWQ 4-bit, GPTQ 4-bit, NF4, jeung INT8 unggal ngahasilkeun téks dina hiji RTX 5070 Laptop maké modél leutik anu teu dilatih anu dijieun *offline*. Ieu ngavalidasi pamuat jeung eksekusi, lain kakuatan atawa kanyamanan unggal modél. **Tambihan ieu aya dina sumberna: rebuilding sareng dependensi anu cocog diperyogikeun; ieu README update teu ningkatkeun hiji binér dipasang.**

**Diukur dina RTX 5070 Laptop:** Qwen2.5-0.5B-Instruct, konteks 2,048, ajakan 272 tokens, 128 token dihasilkeun, lima warmed ngalir: decode median **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. Taya kauntungan speed leuwih GGUF ieu nunjukkeun di dieu. Quantization / calibration béda, jeung EXL3 gagal hiji tés aritmetika basajan; hasilna ieu lain speed umum atawa ranking kualitas. [Pangukuran sareng wates lengkep](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** mangrupa pilihan, junun misah OpenAI-konéksi server cocog, ditumpurkeun sacara standar. Dioténtikasi EXL3 kapanggihna model jeung streaming diuji. Rute lokal ExLlama anu dikelola tetep béda. [ExLlama setelan sareng sambungan TabbyAPI](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

Diurutkeun hardware-diadaptasi standar ni'mat Kaluaran anyar dina kasaluyuan sarua jeung tingkat sadia-memori. Modél anu dipasang henteu otomatis diganti.

[Jumlah Safetensors setup](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [Format, prioritas sareng validasi](docs/SUIVI_MOTEURS.md)

Sumber anu diropéa nambihan **komponén junun opsional dina Konfigurasi pikeun Windows x64**: lingkungan Python swasta, pinned CPU/CUDA propil, estimasi jeung konfirmasi saméméh undeuran, verifikasi, perbaikan sarta ngaleupaskeun. Jalur juru khusus tetep dina pilihan canggih. Mesin asli GGUF ngajaga komponénna anu aya; mobile sareng awan henteu ngaunduh desktop Python/PyTorch. Tilu swasta CPU / propil ékspor ieu exercised kalawan data uji sintétik; The maintainer ngalaporkeun suksés pamakéan desktop on 1 November 2026; GPU profil sareng pamasangan bersih-PC masih peryogi papisah, validasi lengkep. [Propil sarta wates test](docs/REPRISE_COMPOSANTS_GERES_80_LANGUES.md). Embedding tumpukan dina EXE ditunda.
