# Novera Flatpak status

No Novera Flatpak package is provided or validated by this repository yet.

The inherited `ai.jan.Jan` recipe downloaded and built Jan v0.8.5 and advertised
Jan's identity, screenshots and release history. It was removed together with
the dedicated legacy Flatpak workflows on 25 October 2026. It must not be
presented as a Novera distribution.

Future Flatpak support needs a recipe based on Novera sources, the Novera app ID
`io.github.tronabs.novera`, current dependency pins and independent build/runtime
validation. Existing Linux AppImage/deb build paths and the engine sources are
retained. This cleanup does not publish or build a Linux package.
