## Novera 1.0.1

Novera 1.0.1 متاح للأنظمة الأساسية المذكورة أدناه. قم بتنزيل الحزمة لنظامك أو استخدم قناة التحديث الموقعة الخاصة بها. يتم تحديث عمليات التثبيت الموجودة عند تثبيت الحزمة الجديدة أو قبول التحديث.

- الأمان: أذونات أصلية أكثر صرامة للصفحات البعيدة، ومصادقة واجهات برمجة تطبيقات الشبكة وأدوات الخادم، وتخزين وترحيل سري محمي، ووصول أكثر أمانًا إلى الملفات/الوسائط، وتحليل جداول البيانات، وإنشاء البرامج النصية. تم تحديث التبعيات المكشوفة؛ ويتم تتبع التحذيرات المتبقية بشكل علني.
- الخصوصية: تتطلب الإحصائيات وتقارير الأخطاء موافقة منفصلة وتظل معطلة بشكل افتراضي. تتضمن البنيات تكوين الوجهة الموثق. تتم تصفية التشخيص الفني. يحتفظ المستخدمون بالتحكم في التنشيط.
- المحرك المحلي: `llama.cpp v0.9.0` (`b12110`, `cd959bae99ff4bed22bef2604f45241c09bbb8c8`). إصدار المحرك وإصدار التطبيق منفصلان. تم تصحيح إعدادات النموذج الأولية وتسجيل النموذج/جهاز العرض، بما في ذلك فشل بدء التشغيل الذي يتضمن `kv_unified`. يتم الاحتفاظ بالإعدادات الشخصية الموجودة.
- اللغات: 24 لغات ومتغيرات إضافية تعمل على جلب الواجهة ومجموعة README المترجمة إلى 104، مع 2,435 مفاتيح واجهة لكل كتالوج. لا تصادق هذه التغطية على جودة التحرير الأصلية أو دعم الكلام في كل لغة.
- **LFM3-Omni-2B Q4_K_M** — هاد الموديل هو الافتراضي فالكمبيوتر والتلفون. نموذج صغير للنصوص والصور والصوت، يحتاج ملف `mmproj`. حجم تنزيل الملفين نحو 1.39 GB. مناسب لإعداد متعدد الوسائط أخف. ميزات الصوت تعتمد على المنصة والمحرك، والسياق الأطول يحتاج ذاكرة أكبر.
- **NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M** — هاد موديل بديل ديال النصوص. بديل نصي للمحادثة والكتابة والأدوات والإجابات المنظمة. التنزيل نحو 6.18 GB. يحتاج ذاكرة أكثر من LFM3-Omni ولا يعالج الصور أو الصوت بنفسه. قراءة الإجابات تستعمل صوت النظام. اختاره للمهام النصية إذا كانت الذاكرة كافية، وتحقق من المعلومات بمصادر.
- بالنسبة إلى 1.0.1، فإن LFM3-Omni-2B Q4_K_M مع `mmproj-LFM3-Omni-2B-Q4_K_M.gguf` المطلوب هو التوصية الافتراضية على سطح المكتب والجوال؛ يظل NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M بديلاً للنص فقط. السياق الأولي هو 32,768 من الرموز المميزة على سطح المكتب و2,048 على الهاتف المحمول. تستخدم السياقات الأطول المزيد من الذاكرة. يتم الاحتفاظ باختيارات وإعدادات النموذج الحالي حتى يتم تغييرها بشكل صريح.
- الصوت: إدخال ميكروفون محلي مباشر لـ LFM3-Omni، محادثة مستمرة وإرسال تلقائي، أصوات رد ذكر/أنثى للنماذج الصوتية، ونظام الكلام للنماذج الكلاسيكية. تعمل قراءة الرد أيضًا على الرسائل المكتوبة وتجديدها، بشكل مستقل عن التقاط الميكروفون. يعمل زر الصوت الصغير على تمكين القراءة أو كتم صوتها.
- حالة الميكروفون: أخضر عندما يكون متاحًا، وأحمر عندما يكون مشغولاً، ورماديًا عندما لا يكون متاحًا. تم تصحيح التعرف وإعادة الاستماع والتعامل مع التركيز والإملاء المرئي. يتم تنفيذ خطاب النموذج الصوتي الأصلي حاليًا على Windows؛ لا تزال الأنظمة الأساسية الأخرى بحاجة إلى التحقق الأصلي والدعم الصوتي المناسب.
- الويب: كشف أكثر موثوقية لطلبات الطقس، وإرشادات التاريخ الحالي، ونتائج واستشهادات جديدة، وإجابات تتمحور حول الطلب الحالي بعد استخدام الأداة. يحذف الكلام تسميات وروابط المصادر المزخرفة مع الاحتفاظ بالاقتباسات المرئية. تتبع لغة الاستجابة والكلام لغة المستخدم بقدر ما يدعمها النموذج المحدد.

## من أول تشغيل حتى النتائج

**الأتمتة ديالنا كتربط التحضير بدورة العمل التنفيذية الكاملة.** Novera كيتكلف بالخطوات التقنية المتوفرة للتكوين المختار، مع إبقاء الضوابط المتقدمة متاحة.

| خطوة | شنو كيتكلف بيه Novera |
| --- | --- |
| **1. ابدأ** | كيختار لغة النظام المدعومة عند أول تشغيل وكيحفظ التفضيل ديالك. كيعرض النماذج الأولية ومعلومات هامة على العتاد. |
| **2. تحضير** | التثبيت المُوَجَّه كيعرض نصوص، تضمينات، صور، موسيقى، فيديو وتكبير. كيشوف المكونات والأحجام والمساحة الخاوية قبل الموافقة ديالك، ومن بعد كيتبع التنزيلات بالتقدم، الإيقاف/الاستئناف و SHA-256. |
| **3. ضبط** | كيسجل النماذج والمكونات ديالها، كيوجد البروفيلات والمستندات الضرورية. تضمينات الاسترجاع كتبدا على CPU مع اختيار محفوظ CPU/GPU. بروفيلات الموسيقى الجديدة كيكونوا افتراضياً في وضع الآلات الموسيقية. |
| **4. فهم الطلب** | كيوجه تلقائياً طلبات الإنشاء المعترف بها للنص، الصورة، الموسيقى أو الفيديو. تقدر حتى تختار طريقة الإخراج صراحةً ونموذج محلي أو سحابي. |
| **5. تنفيذ** | الذاكرة الأوتوماتيكية كتسنى الخدمة النشطة، كتفرغ النماذج غير الضرورية وكتعاود تحمل الموارد المطلوبة. سلسلة مهام 1–10 كتخدم بالترتيب وكتفرغ الموارد قبل المهمة الموالية. مزودي السحابة كيستعملو الحساب والتكوين المختارين. |
| **6. استرجاع وإعادة استخدام** | كيخزن الوسائط في مجلدات نظام Novera، كيعرض النتائج والأوقات المتاحة، ومن بعد كيعرض التنوعات، المكتبة، النسخ، التصديرات أو المشاركة بالنظام. الإرسال لتطبيق آخر يبقى قرارك. |

الأتمتة كتغطي المحركات وسير العمل المتكاملة؛ ما كتخليش كل نماذج Hub قابلة للتنفيذ. العتاد، المكونات المثبتة، ووصول المزود كيحددو شنو يقدر يخدم. المجلدات، تغييرات الملفات وأوامر الـ shell كيتبعو صلاحيات الوصول ديال المحادثة.

## الهب والموديلات المتوافقة

**GGUF، Safetensors القياسي والمكمم، ONNX، و MLX**: شوف الموديلات حسب المهمة واختار الأنواع المتوافقة مع الموطور (engine) و الهاردوير ديالك.

| عائلة | دعم فالمصدر | التكوين، المرمز (tokenizer)، وكل شارد مطلوب. |
| --- | --- | --- |
| **GGUF** | توليد النصوص عبر llama.cpp؛ مكونات صور وفيديو للحسابات المدعومة. | مجلد كامل مُصادق عليه؛ يتطلب معالجة مسبقة/لاحقة خاصة بالمهمة؛ |
| **تقسيم GGUF** | واحد متغير لكل سلسلة كاملة، الحجم المجموع، تحميل جميع الأجزاء، وفحوصات الحجم/SHA-256/الرأس | أسماء ملفات مرقمة عادية؛ تحميل 500 GB ما كيعنيش بلي الموديل كيصلح مع PC. |
| **قياسي Safetensors** | كمل المجلدات عبر Transformers، النص السببي على CPU ولا NVIDIA CUDA. | المتطلبات |
| **ONNX Runtime** | نص عبر GenAI؛ مكونات صورة/فيديو للبروفايلات المدعومة. | المعمارية اللي كتعرفها الموطور المضمّن. [إعدادات والحدود](onnx-server/README.md). |
| **LoRA / PEFT محولات** | استيراد قاعدة كاملة مع المُكيّف المحلي المنفصل ديالها فـ مُزوّد Safetensors | الأساس Transformers غير مُكمّم سببي، كيوافق فحوصات الهوية والتنسور وتقدير الذاكرة التراكمي؛ [إعدادات والحدود](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | التنفيذ الأصلي لـ CUDA لـ exports FP8 لكل تنسور متوافقة مع Llama/Qwen2/Qwen3 كثيفة. | فحوصات المعمارية/التنسور واستقصاء النواة الحقيقي؛ [إعدادات والحدود](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |
| **NVFP4 LLM / ModelOpt** | إسقاطات البلوك المعبأة 16 FP4 عبر GEMMs CUDA الأصلية؛ منفصل عن صورة NVFP4. | Blackwell GPU متوافقة، أبعاد/تصدير مدعومة واستقصاء نواة حقيقي؛ نماذج اختبار غير مدربة مُختبرة على RTX 5070. |
| **AWQ** | نقاط تفتيش نموذج GEMM بـ 4-bit بلا دمج العمليات. | مُحمّلات NVIDIA CUDA و GPTQModel/Transformers اختيارية. |
| **GPTQ** | تكوينات 2/3/4/8-bit، صيغ gptq/gptq_v2. | NVIDIA CUDA، GPTQModel و Optimum؛ تنفيذ حقيقي مُختبر عند بتات 4. |
| **bitsandbytes** | 4-bit NF4/FP4 أو 8-bit INT8. | NVIDIA CUDA والتبعيات الاختيارية؛ اختبارات حقيقية لـ NF4 و INT8. |
| **EXL3** | تم تحميل مجلدات موديل Safetensors الكمّي الكامل عبر ExLlamaV3; تم اختبار التوليد الفعلي مع CUDA. | NVIDIA GPU، بيئة Python 3.12 منفصلة ومعمارية متوافقة؛ ماكاينش رجوع لـ CPU. |
| **EXL2** | مُحمّل ExLlamaV2 مخصص؛ البث، الإلغاء والتفريغ مُختبرين على GPU.. | لازم تختار CUDA Attention backend بوضوح للبيئة البرمجية المختبرة؛ مطلوب checkpoint كامل للموديل وذاكرة VRAM متاحة كافية. |
| **MLX** | نماذج متوافقة على Apple Silicon. | محرك MLX والمنصة المدعومة. |

الهاب دابا كيثبّت **LFM3-1.7B** بحال التوصية ديال LiquidAI ديالو للتكوينات المتوافقة، مع النسخ Q4_K_M و Q6_K و Q8_0. الموديل ديال أول تشغيل كيبقى هو اللي مكتوب فالتكوين الموجه الفوق.

صفي أوزان التنزيل من **تحت 1 GB حتى ل 500 GB وفوق**, من بعد رتب حسب التوافق ديال الهاردوير، الحجم، الحداثة أو التنزيلات. النتائج كتتحمل تدريجياً؛ الفلاتر كتطبق على الموديلات اللي تفرطات و النسخة الافتراضية ديالها. النصيحة ديال الذاكرة كتستعمل RAM/VRAM، السياق و المكونات المرافقة المتوفرة، بلا ما تحسب الذاكرة المشتركة ديال GPU جوج مرات.

AWQ 4-bit، GPTQ 4-bit، NF4 و INT8 كل واحد كيولد نص على RTX 5070 Laptop باستعمال موديلات صغار غير مدربين ومصاوبين أوفلاين. هادا كيأكد التحميل والتنفيذ، ماشي الجودة أو الأداء ديال كل موديل. **هاد الإضافات كاينة فالسورس: خاص إعادة البناء و التبعيات المتوافقة؛ هاد التحديث ديال README ما كيرقيش باينري مُثبت.**

**مقيس على RTX 5070 Laptop:** Qwen2.5-0.5B-Instruct، سياق 2,048، توكنات ديال البرومبت 272، توكنات مولدة ديال 128، خمسة تشغيلات دافئة: وسيط سرعة توليد التوكنات **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. ما تبينش شي فائدة فالسُرعة مقارنة بـ GGUF هنا. التكميم/المعايرة مختلف، و EXL3 فشل فواحد الاختبار ديال الحساب البسيط؛ هاد النتائج ماشي تصنيف عام ديال السرعة أو الجودة. [القياسات والحدود الكاملة](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** هو اتصال خادم اختياري، مُدار بشكل منفصل ومتوافق مع OpenAI، معطل افتراضياً. تم اختبار اكتشاف الموديل و البث ديال EXL3 الموثق. المسار المحلي المُدار ديال ExLlama كيبقى منفصل. [إعداد ExLlama و اتصال TabbyAPI](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

الترتيب الافتراضي المتكيف مع الهاردوير كيعطي الأولوية للإصدارات الأحدث فنفس مستوى التوافق والذاكرة المتوفرة. الموديلات المثبتة ما كيتعوضوش أوتوماتيكياً.

[إعداد Safetensors المُكمَّم](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [التنسيقات، الأولويات و التحقق](docs/SUIVI_MOTEURS.md)

المصادر المحدّثة كاتزيد **مكونات مُدارة اختيارية فالتكوينات ديال Windows x64**: بيئات بايثون خاصة، بروفايلات CPU/CUDA مثبتة، تقديرات وتأكيد قبل التنزيلات، تحقق، إصلاح وإزالة. مسارات المفسر المخصصة كتبقاو تحت الخيارات المتقدمة. محركات GGUF الأصلية كيبقاو عندهم المكونات ديالهم؛ الموبايل والسحابة ما كينزلوش بايثون ديسكتوب/PyTorch. تمرينات ثلاثة بروفايلات خاصة CPU/export مع بيانات اختبار اصطناعية؛ المطور كيبلغ على استعمال ناجح ديسكتوب على 1 نونبر 2026؛ بروفايلات GPU والتثبيت النظيف ديال PC باقي خاصهم تحقق منفصل ومفصل. [البروفايلات وحدود الاختبار](docs/REPRISE_COMPOSANTS_GERES_80_LANGUES.md). تضمين المكدس فـ EXE مؤجل.

| البيئة، المناخ، الماء والتنوع البيولوجي | الطاقة، الصناعة، البناء والحرف اليدوية |
| ندعم التوثيق، التصميم، الصيانة، التعلم التقني وتحسين العمليات. | الأعمال، التجارة، المالية والتشغيل |
| النقل، اللوجستيك، السياحة، الرياضة والحياة المجتمعية | المساعدة في التخطيط، التواصل، التعلم والمبادرات المحلية. |
| إمكانية الوصول، العمل الإنساني والحياة اليومية | تقليل حواجز اللغة والمعرفة ودعم الناس بمساعدة عملية. |

هادو توجيهات للمساهمة والتطوير، ماشي تأكيد أن كل تطبيق خاص بقطاع معين تْقدّم أو تْصادق عليه. بغينا توجيه بسيط للاستعمال اليومي، خيارات متقدمة واضحة ملي تكون ضرورية، متطلبات شفافة للأجهزة والسحابة، وتعاون مع الناس اللي كيعرفو كل مجال والسياق المحلي.

## حالة المشروع

لقطة الشاشة كتعرض تطبيق Windows مْجمّع محلياً من طرف المُحافظ. تغييرات المصدر، الاختبارات المستهدفة والتحقق من الأجهزة موثقة بشكل منفصل؛ هادشي ما كيصادقش على كل موديل، منصة أو حساب سحابة.

التجميعات اليدوية لـ GitHub Actions مُمكّنة لجميع أحد عشر نوع توزيع. تبع [نتائج التجميع وتنزيلات المرشحين الموثقين](docs/CI_DISTRIBUTIONS.md); التوفر مسجل بشكل منفصل لكل منصة. المرشحين مختلفين عن الإصدارات الإنتاجية الموقعة. متطلبات التوزيع موصوفة في [سياسة الإصدار الرسمية](OFFICIAL_RELEASES.md) و [صفحة الإصدارات](https://github.com/TRON-ABS/Novera/releases). المرشحين الحاليين اللي معطلين التحديث كيبقاو داخليين. الإصدارات العامة كتحتاج آلية تحديث مُهيأة وموثقة; [فحوصات التوقيع على سطح المكتب ومتطلبات التشغيل المتبقية موثقة](docs/LAUNCH_STATUS.md).
