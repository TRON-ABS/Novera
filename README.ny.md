- **Chisawawa, chokhazikika, +1 ndi −1 mbewu**, kusinthidwa kapena kusinthidwa mwamakonda ndikusankha **Real-ESRGAN ×2/×4** kukweza ndi miyeso yomaliza yowonetsedwa.
- Mtundu wosankhidwa, zokumbukira zokha, zomata, malangizo, kusaka pa intaneti ndi zida zimakhala mu bar yomweyo. Zida zimadalira luso lachitsanzo ndi mwayi wopatsidwa.

## Hub ndi mitundu yogwirizana

**GGUF, yokhazikika komanso yochulukitsidwa Safetensors, ONNX, ndi MLX**: fufuzani zitsanzo ndi ntchito ndikusankha zosintha zomwe zimagwirizana ndi injini ndi zida zanu.

| Banja | Thandizo pagwero | Zofunikira |
| --- | --- | --- |
| **GGUF** | Lembani kudzera llama.cpp; zigawo zazithunzi/kanema zama profaili othandizidwa. | Zomangamanga zozindikiridwa ndi injini yolumikizidwa. |
| **Gawani GGUF** | Mtundu umodzi pamndandanda wathunthu, kukula kwake mwachidule, kutsitsa ndi kukula kwake/SHA-256/macheke amutu. | Maina afayilo okhazikika; kutsitsa 500 GB sikutanthauza kuti mtunduwo ukukwanira PC. |
| **Standard Safetensors** | Malizitsani zikwatu kudzera Transformers, mawu oyambitsa pa CPU kapena NVIDIA CUDA. | Kusintha, tokenizer ndi shard iliyonse yofunikira. |
| **ONNX Runtime** | Kulowetsedwa kwanuko kwa ma graph a manambala/bool ndikukonza zotumiza GenAI zotumizidwa kunja. | Foda yathunthu yovomerezeka; ntchito yeniyeni yokonzekera / postprocessing yofunika; [kukhazikitsa ndi malire](onnx-server/README.md). |
| **LoRA / PEFT ma adapter** | Lowetsani chida chathunthu chokhala ndi adaputala yake yosiyana m'dera la Safetensors. | Choyambitsa chosawerengeka Transformers maziko, zidziwitso zofananira, macheke a tensor ndi kuyerekeza kukumbukira kukumbukira; [kukhazikitsa ndi malire](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | Mchitidwe Wachilengedwe CUDA pazowundana zogwirizana Llama/Qwen2/Qwen3 pa tensor FP8 zotumizidwa kunja. | Macheke a zomangamanga / ma tensor ndi kafukufuku wa kernel weniweni; [kukhazikitsa ndi malire](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |
| **NVFP4 LLM / ModelOpt** | Mdawu wolongedwa-16 FP4 zolozera kudzera mu CUDA ma GEMM; siyana ndi chithunzi NVFP4. | Yogwirizana Blackwell GPU, miyeso yothandizidwa / kutumiza kunja ndi kafukufuku weniweni wa kernel; zitsanzo zosaphunzitsidwa zoyesedwa pa RTX 5070. |
| **AWQ** | Malo osagwiritsiridwa ntchito 4-bit GEMM. | NVIDIA CUDA ndi GPTQModel/Transformers zojambulira. |
| **GPTQ** | 2/3/4/8-bit masinthidwe, ma gptq/gptq_v2. | NVIDIA CUDA, GPTQModel ndi Optimum; zenizeni zoyesedwa pa 4 bits. |
| **bitsandbytes** | 4-bit NF4/FP4 kapena 8-bit INT8. | NVIDIA CUDA ndi zodalira zomwe mwasankha; zenizeni NF4 ndi INT8 zoyesa. |
| **EXL3** | Malizitsani zikwatu Safetensors zochulukira kudzera ExLlamaV3; mbadwo weniweni wa CUDA woyesedwa. | NVIDIA GPU, patulani Python 3.12 chilengedwe ndi kamangidwe kogwirizana; palibe CPU kubwereranso. |
| **EXL2** | Wodzipatulira ExLlamaV2 chojambulira; kutsitsa, kuletsa ndi kutsitsa kuyesedwa pa GPU. | Sankhani mwatsatanetsatane CUDA Chidziwitso chakumbuyo kwa staki ya mapulogalamu oyesedwa; malo oyendera athunthu ndi zokwanira VRAM ndizofunikira. |
| **MLX** | Mitundu yogwirizana pa Apple Silicon. | MLX injini ndi nsanja yothandizira. |

The Hub tsopano yakhazikika **LFM3-1.7B** monga upangiri wake wa LiquidAI pazosintha zofananira, ndi Q4_K_M, Q6_K ndi Q8_0 zosintha. Mtundu woyamba umakhalabe womwe walembedwa pamakonzedwe owongolera pamwambapa.

Sefa zotsitsa zolemera kuchokera **pansi pa 1 GB mpaka 500 GB ndi pamwamba**, kenako sankhani molingana ndi ma hardware, kukula, zaposachedwa kapena kutsitsa. Zotsatira zimachuluka pang'onopang'ono; Zosefera zimagwira ntchito kumitundu yolandidwa komanso kusiyanasiyana kwawo. Upangiri wa pamtima umagwiritsa ntchito RAM/VRAM, nkhani ndi zigawo zina, osawerengera kawiri kukumbukira komwe adagawana GPU.

AWQ 4-bit, GPTQ 4-bit, NF4 and INT8 each generated text on an RTX 5070 Laptop using tiny untrained models created popanda intaneti. Izi zimatsimikizira kutsitsa ndikuchita, osati mtundu kapena magwiridwe antchito amtundu uliwonse. **Zowonjezera izi zili mugwero: kumanganso ndi kudalira kogwirizana kumafunika; zosintha za READMEzi sizikweza makina oyikapo.**

**Kuyezedwa pa RTX 5070 Laptop:** Qwen2.5-0.5B-Instruct, nkhani 2,048, mwamsanga 272 ma tokeni, 128 ma tokeni opangidwa, mipikisano yotenthetsera isanu: decode yapakatikati **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. Palibe liwiro loposa GGUF lomwe lawonetsedwa apa. Kuchulutsa/kuwerengetsa kumasiyana, ndipo EXL3 yalephera cheke chofunikira cha masamu; zotsatira izi si liwiro wamba kapena kusanja khalidwe. [Miyezo yonse ndi malire](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** ndiyosasankha, yoyendetsedwa payokha OpenAI-malumikizidwe a seva omwe amazimitsidwa mwachisawawa. Kupeza ndi kukhamukira kovomerezeka kwa EXL3 kudayesedwa. Njira yoyendetsedwa ndi ExLlama idakali yosiyana. [ExLlama kukhazikitsa ndi kulumikiza TabbyAPI](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

Mtundu wokhazikika wosinthidwa ndi hardware umakonda kutulutsa kwatsopano mkati mwa mayendedwe omwewo komanso gawo la kukumbukira lomwe likupezeka. Zitsanzo zoyikidwa sizisinthidwa zokha.

[Kukhazikitsa Safetensors](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [Mawonekedwe, zofunika ndi kutsimikizira](docs/SUIVI_MOTEURS.md)

Zomwe zasinthidwa zimawonjezera **zigawo zoyendetsedwa mwasankha mu Zosintha za Windows x64**: malo achinsinsi a Python, mbiri yakale ya CPU/CUDA, kuyerekezera ndi kutsimikizira musanatsitse, kutsimikizira, kukonza ndi kuchotsa. Njira zotanthauzira mwamakonda zimakhala pansi pa zosankha zapamwamba. Ma injini a GGUF amasunga zida zawo zomwe zilipo kale; mafoni ndi mtambo samatsitsa Python pakompyuta/PyTorch. Zitatu zachinsinsi CPU/mbiri zotumiza kunja zidayesedwa pogwiritsa ntchito data yoyeserera; wosamalira anena kuti anagwiritsa ntchito bwino pa kompyuta pa 1 Novembala 2026; GPU ma profailo ndikuyeretsa-PC akufunikabe kutsimikizira mwatsatanetsatane. [Mbiri ndi malire a mayeso](docs/REPRISE_COMPOSANTS_GERES_80_LANGUES.md). Kuphatikiza zigawo izi mu EXE kwachedwetsedwa.
