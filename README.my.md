## ဗားရှင်းပြင်ဆင်နေသည် 1.0.1

အများသူငှာ ဒေါင်းလုဒ်များကို 1.0.0 တွင် ကျန်ရှိနေပါသည်။ အောက်ပါတိုးတက်မှုများကို 1.0.1 အတွက် အရင်းအမြစ်များတွင် ပြင်ဆင်ထားပါသည်။ ၎င်းတို့သည် ပြန်လည်တည်ဆောက်ထားသော ပက်ကေ့ဂျ်များ၊ စစ်ဆေးမှုများနှင့် ထုတ်ဝေမှုများ လိုအပ်ပါသည်။ ဤစာရွက်စာတမ်းကို အပ်ဒိတ်လုပ်ခြင်းသည် ထည့်သွင်းထားသော အပလီကေးရှင်းများကို အပ်ဒိတ်မလုပ်ပါ။

- လုံခြုံရေး- အဝေးမှ စာမျက်နှာများအတွက် ပိုမိုတင်းကျပ်သော မူရင်းခွင့်ပြုချက်များ၊ ကွန်ရက် API များနှင့် ဆာဗာတူးလ်များအတွက် စစ်မှန်ကြောင်းအထောက်အထားပြခြင်း၊ ကာကွယ်ထားသော လျှို့ဝှက်သိုလှောင်မှုနှင့် ရွှေ့ပြောင်းခြင်း၊ ပိုမိုဘေးကင်းသော ဖိုင်/မီဒီယာဝင်ရောက်ခွင့်၊ ဇယားကွက်ခွဲခြမ်းစိတ်ဖြာခြင်းနှင့် ဇာတ်ညွှန်းများတည်ဆောက်ခြင်း။ ဖော်ပြထားသော မှီခိုမှုများအား အပ်ဒိတ်လုပ်ထားပါသည်။ ကျန်ရှိသော အကြံပေးချက်များကို ပွင့်လင်းစွာ ခြေရာခံပါသည်။
- ကိုယ်ရေးကိုယ်တာ- စာရင်းဇယားများနှင့် အမှားအယွင်းအစီရင်ခံစာများသည် သီးခြားသဘောတူခွင့်ပြုချက် လိုအပ်ပြီး မူရင်းအတိုင်း ဆက်ရှိနေပါသည်။ တည်ဆောက်မှုများတွင် မှတ်တမ်းတင်ထားသော ဦးတည်ရာဖွဲ့စည်းပုံများ ပါဝင်သည်။ နည်းပညာဆိုင်ရာ ရောဂါရှာဖွေမှုများကို စစ်ထုတ်ထားပါသည်။ အသုံးပြုသူများသည် activation ကိုထိန်းချုပ်ထားသည်။
- စက်တွင်းအင်ဂျင်- `llama.cpp v0.9.0` (`b12110`, `cd959bae99ff4bed22bef2604f45241c09bbb8c8`)။ အင်ဂျင်ဗားရှင်းနှင့် အပလီကေးရှင်းဗားရှင်းသည် သီးခြားဖြစ်သည်။ `kv_unified` ပါ ၀ င်သည့်စတင်မှုမအောင်မြင်ခြင်းအပါအဝင် ကနဦးမော်ဒယ်ဆက်တင်များနှင့် မော်ဒယ်/ပရိုဂျက်တာမှတ်ပုံတင်ခြင်းကို ပြုပြင်ထားပါသည်။ လက်ရှိ ကိုယ်ရေးကိုယ်တာ ဆက်တင်များကို ထိန်းသိမ်းထားသည်။
- ဘာသာစကားများ- 24 အပိုဘာသာစကားများနှင့် မျိုးကွဲများသည် အင်တာဖေ့စ်နှင့် ဘာသာပြန်ထားသော README စုစည်းမှုကို 104 သို့ ယူဆောင်လာပြီး ကတ်တလောက်တစ်ခုလျှင် အင်တာဖေ့စ်ကီး 2,435 ခု ပါရှိသည်။ ဤအကျုံးဝင်မှုသည် ဘာသာစကားတိုင်းတွင် မူရင်းတည်းဖြတ်မှုအရည်အသွေး သို့မဟုတ် စကားအထောက်အပံကို အသိအမှတ်မပြုပါ။

## ပရောဂျက်အခြေအနေ

**Novera 1.0.0 ကို Windows၊ Linux၊ macOS နှင့် Android အတွက် ရနိုင်ပါသည်။** စခရင်ရှော့တွင် ထိန်းသိမ်းသူမှ စက်တွင်းပြုစုထားသော Windows အပလီကေးရှင်းကို ပြသသည်။ ရင်းမြစ်ပြောင်းလဲမှုများ၊ ပစ်မှတ်ထားသော စမ်းသပ်မှုများနှင့် ဟာ့ဒ်ဝဲအတည်ပြုခြင်းကို သီးခြားစီ မှတ်တမ်းတင်ထားပါသည်။ ၎င်းသည် မော်ဒယ်၊ ပလပ်ဖောင်း သို့မဟုတ် cloud အကောင့်တိုင်းကို တရားဝင်မသတ်မှတ်ပါ။

လက်စွဲ GitHub Actions တည်ဆောက်မှုများကို ဖြန့်ချီမှု 11 မျိုးကွဲအားလုံးအတွက် ဖွင့်ထားသည်။ လိုက်နာပါ။ [တည်ဆောက်မှုရလဒ်များနှင့် အတည်ပြုထားသော ကိုယ်စားလှယ်လောင်းများကို ဒေါင်းလုဒ်လုပ်ပါ။](docs/CI_DISTRIBUTIONS.md); ရရှိနိုင်မှုကို ပလပ်ဖောင်းတစ်ခုစီအတွက် သီးခြား မှတ်တမ်းတင်ထားသည်။ ကိုယ်စားလှယ်လောင်းများသည် လက်မှတ်ရေးထိုးထားသော ထုတ်လုပ်ဖြန့်ချိမှုများနှင့် ကွဲပြားပါသည်။ ဖြန့်ဖြူးရေးလိုအပ်ချက်များကို ဖော်ပြထားပါသည်။ [တရားဝင်ထုတ်ပြန်သည့်မူဝါဒ](OFFICIAL_RELEASES.md) နှင့် [စာမျက်နှာ ထုတ်ဝေသည်။](https://github.com/TRON-ABS/Novera/releases)လက်ရှိ အပ်ဒိတ်-ပိတ်ထားသော ကိုယ်စားလှယ်လောင်းများသည် အတွင်းပိုင်း၌ ရှိနေပါသည်။ အများသူငှာ ထုတ်ဝေမှုများတွင် ပြင်ဆင်ပြီး အတည်ပြုထားသော အပ်ဒိတ်ယန္တရားတစ်ခု လိုအပ်ပါသည်။ [ဒက်စ်တော့၏ လက်မှတ်စစ်ဆေးမှုများနှင့် လက်ကျန်စတင်ခြင်းဆိုင်ရာ လိုအပ်ချက်များကို မှတ်တမ်းတင်ထားသည်။](docs/LAUNCH_STATUS.md).

## Novera ပံ့ပိုးမှု

အကယ်၍ သင်သည် Novera စွန့်စားမှု၏ တစ်စိတ်တစ်ပိုင်းဖြစ်လိုပါက၊ ကျွန်ုပ်၏ သုတေသနနှင့် ပရောဂျက်၏ ဖွံ့ဖြိုးတိုးတက်မှုကို စေတနာအလျောက် bitcoin ပံ့ပိုးမှုဖြင့် ပံ့ပိုးနိုင်ပါသည်။
