| **bitsandbytes** | 4-بٹ NF4/FP4 یا 8-بٹ INT8. | NVIDIA CUDA تے اختیاری انحصار؛ حقیقی NF4 تے INT8 ٹیسٹ۔ |
| **EXL3** | مکمل کوانٹائزڈ Safetensors ماڈل فولڈرز ExLlamaV3 دے ذریعے لوڈ کیتے گئے؛ CUDA نال اصل جنریشن جانچی گئی۔ | NVIDIA GPU، الگ Python 3.12 ماحول تے مطابقت پذیر فن تعمیر؛ کوئی CPU فال بیک نئیں۔ |
| **EXL2** | مخصوص ExLlamaV2 لوڈر؛ GPU. تے سٹریمنگ، منسوخی تے ان لوڈ ٹیسٹ کیتا گیا۔ | CUDA Attention backend جانچے گئے سافٹ ویئر اسٹیک لئی واضح طور تے منتخب کی جانی چاہیدی اے؛ اک مکمل ماڈل چیک پوائنٹ تے دستیاب VRAM ضروری اے۔ |
| **MLX** | Apple Silicon تے مطابقت پذیر ماڈلز۔ | MLX انجن تے سپورٹڈ پلیٹ فارم۔ |

ہب ہن پن کردا ہے **LFM3-1.7B** اپنے LiquidAI سازگار ترتیب دے دیوے، Q4_K_M، Q6_K تے Q8_0 واریئنٹاں نال۔ پہلا چلن والا ماڈل اُتے دی گائیڈڈ ترتیب وچ درج ہون والا رہندا ہے۔

فرن وچ ڈاؤن لوڈ وزن فلٹر کرو **1 GB توں 500 GB تے اُتے تک**, پھر ہارڈ ویئر فٹ، سائز، حالیہ یا ڈاؤن لوڈاں دے حساب نال ترتیب کرو۔ نتائج تدریجی طور تے لوڈ ہوندے نیں؛ فلٹر حاصل کیتے ماڈل تے اوہناں دے ڈیفالٹ واریئنٹ اُتے لاگو ہوندے نیں۔ میموری مشورہ دستیاب RAM/VRAM، سیاق و سباق تے ساتھی اجزاء استعمال کردا اے، مشترکہ GPU میموری نوں دوہری گنتی نال بغیر۔

AWQ 4-بٹ، GPTQ 4-بٹ، NF4 تے INT8 ہر اک ایک RTX 5070 Laptop اُتے ٹائنی غیر تربیت یافتہ ماڈل استعمال کر کے متن تیار کردا اے جو آف لائن بنائے گئے نیں۔ ایہہ لوڈنگ تے ایگزیکیوشن دی تصدیق کردا اے، ہر ماڈل دی کوالٹی یا کارکردگی دی نہیں۔ **ایہہ اضافے سورس وچ نیں: دوبارہ بنانا تے سازگار انحصاراں دی ضرورت اے؛ ایہہ README اپڈیٹ انسٹال شدہ بائنری نوں اپ گریڈ نہیں کردا۔**

**RTX 5070 Laptop اُتے ماپیا گیا:** Qwen2.5-0.5B-Instruct، سیاق و سباق 2,048، پرامپٹ 272 ٹوکن، 128 تیار کردہ ٹوکن، پنج گرم چلن: میڈین ڈیکوڈ **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. GGUF اُتے کوئی رفتار دا فائدہ ظاہر نہیں کیتا گیا۔ کوانٹائزیشن/کیلیبریشن مختلف اے، تے EXL3 اک سادہ حساب دے ٹیسٹ وچ ناکام ہویا؛ ایہہ نتائج کوئی عام رفتار یا کوالٹی درجہ بندی نہیں نیں۔ [مکمل پیمائشاں تے حدود](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** ایک اختیاری، الگ طرح مینج کیتا جانے والا OpenAI-سازگار سرور کنکشن ہے، ڈیفالٹ طور تے بند ہے۔ تصدیق شدہ EXL3 ماڈل کی دریافت تے سٹریمنگ جانچی گئی۔ مینج کیتا جانے والا مقامی ExLlama روٹ الگ رہندا ہے۔ [ExLlama سیٹ اپ تے TabbyAPI کنکشن](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

ڈیفالٹ ہارڈ ویئر-مطابقت والا ترتیب نوی ریلیزاں نوں ترجیح دیندا اے جیہڑی اُتھے ئي سازگاری تے دستیاب میموری ٹیر وچ ہوندی اے۔ انسٹال شدہ ماڈل خودکار طور تے تبدیل نہیں ہوندے۔

[کوانٹائزڈ Safetensors سیٹ اپ](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [فارمیٹ، ترجیحات تے تصدیق](docs/SUIVI_MOTEURS.md)
