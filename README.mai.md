## पहिल लॉन्च स परिणाम तक

**हमरऽ स्वचालन तैयारी क॑ पूरा निष्पादन कार्यप्रवाह स॑ जोड़ै छै.** Novera चयनित विन्यास कें लेल उपलब्ध तकनीकी चरणक कें संभालयत छै, जखन कि उन्नत नियंत्रणक कें सुलभ रखयत छै.

| चरण | Novera की संभालैत अछि |
| --- | --- |
| **1. शुरू करू** | पहिल लॉन्च पर एकटा समर्थित सिस्टम भाषा कें चयन करयत छै आ अहां कें पसंद कें सहेजयत छै. प्रारंभिक मॉडल आ उपयोगी हार्डवेयर जानकारी प्रस्तुत करयत छै. |
| **2. तैयार करब** | निर्देशित स्थापना पाठ, एम्बेडिंग, छवि, संगीत, वीडियो आ अपस्केलिंग प्रदान करयत छै. इ अहां कें मंजूरी सं पहिले घटक, आकार आ मुक्त स्थान कें पूर्वावलोकन करयत छै, तखन प्रगति, विराम/पुनरारंभ आ SHA-256 सत्यापन कें साथ डाउनलोड कें ट्रैक करयत छै. |
| **3. विन्यस्त करू** | मॉडल आ ओकर घटक कें रजिस्टर करयत छै, संबंधित प्रोफाइल तैयार करयत छै आ आवश्यक निर्भरताक कें रिपोर्ट करयत छै. पुनर्प्राप्ति एम्बेडिंग CPU पर शुरू होइत अछि एकटा सहेजल गेल CPU/GPU विकल्प क संग. नव संगीत प्रोफाइल डिफ़ॉल्ट रूप सँ वाद्ययंत्र मोड मे अछि. |
| **4. अनुरोध बुझू** | ऑटो मान्यता प्राप्त निर्माण अनुरोधक कें पाठ, छवि, संगीत या वीडियो कें लेल रूट करयत छै. अहां आउटपुट मोड आओर स्थानीय या क्लाउड मॉडल कें सेहो स्पष्ट रूप सं चुन सकय छी. |
| **5. निष्पादित करू** | स्वचालित मेमोरी सक्रिय काज कें इंतजार करयत छै, अनावश्यक मॉडल जारी करयत छै आ आवश्यक संसाधनक कें पुनः लोड करयत छै. एकटा 1–10 जॉब सीरीज क्रम मे चलैत अछि आओर अगिला जॉब सं पहिने संसाधन जारी करैत अछि. क्लाउड प्रदाता चयनित खाता आ विन्यास कें उपयोग करएयत छै. |
| **6. पुनर्प्राप्त करू आ पुनः उपयोग करू** | मीडिया कें Novera सिस्टम फोल्डर मे सहेजयत छै, परिणाम आ उपलब्ध समय प्रदर्शित करयत छै, तखन वेरिएंट, लाइब्रेरी, कॉपीिंग, निर्यात या सिस्टम साझा करनाय कें पेशकश करयत छै. दोसर एप्लीकेशन पर भेजनाय अहां कें क्रिया बनल रहत. |

स्वचालन एकीकृत इंजन आ कार्यप्रवाह कें कवर करयत छै; इ हर हब मॉडल कें एक्जीक्यूटिव नहि बनायत छै. हार्डवेयर, इंस्टॉल घटक आ प्रदाता पहुंच इ निर्धारित करएयत छै की की चल सकएय छै. फोल्डर, फाइल परिवर्तन आ शेल कमांड बातचीत कें पहुंच अनुदान कें पालन करएयत छै.

[उपयोगकर्ता गाइड](docs/USER_GUIDE.md) · [इंजन आ सत्यापन](docs/SUIVI_MOTEURS.md) · [विकास](docs/DEVELOPMENT.md)

अद्यतन स्रोत मे, **विन्यास अपन सिफारिशक कें मोबाइल आ बाध्य हार्डवेयर कें अनुकूल बनायत छै**: LFM3-1.7B Q4, या LFM3-Omni-2B Q4 कें साथ ओकर प्रोजेक्टर कें साथ जखन रिपोर्ट कैल गेल मेमोरी आ इंजन कें आवश्यकताक कें पूरा कैल जायत छै. अनुपलब्ध स्थानीय पीढ़ी नुकायल वा अवरुद्ध अछि; कॉन्फ़िगर कैल गेल क्लाउड इमेज, संगीत आ वीडियो उपलब्ध रहत. इंटरफेस मार्गदर्शन 80 भाषा कैटलॉग कें पुन: उपयोग करय छै. ई अनुमानऽ क॑ अखनी भी इंस्टॉल करलऽ गेलऽ एप्लीकेशन तलक पहुँचै लेली डिवाइस परीक्षण आरू पुनर्निर्माण के जरूरत छै ।

**सब 80 कैटलॉग वर्तमान 2,429 अंग्रेजी कुंजी कें कवर करयत छै** 15 नामस्थानक कें पार, मेनू, विन्यास, सेटिंग्स, मदद आ मीडिया नियंत्रण सहित. बहुवचन रूप आ अंतरफलक दिशा चयनित भाषाक अनुसरण करैत अछि | प्रतिक्रिया आ आवाज भाषा अलग-अलग मॉडल पर निर्भर करैत अछि ।

इ तकनीकी कवरेज भाषाई गुणवत्ता कें प्रमाणित नहि करएयत छै: **देशी समीक्षा आ क्षेत्रीय अनुकूलन आवश्यक बनल छै**के। मे देशी लेबल आ ज्ञात सीमा देखू [भाषा मार्गदर्शक](docs/LANGUAGES.md) एवं [लेखा परीक्षा रिपोर्ट](deliverables/interface-audit-2026-10-29/RAPPORT.md).

## लोगक कें मदद करनाय, हर क्षेत्र मे

स्कूल आ शिक्षा सं परे, हमर महत्वाकांक्षा दुनिया भर मे लोगक कें सीखय, समस्याक कें हल करय, उपयोगी परियोजनाक कें निर्माण आ विकास मे मदद करनाय छै. Novera कें उद्देश्य वर्तमान AI प्रगति कें समझय आ उपयोग करय मे आसान बनानाय छै, भाषाक, अनुभव कें स्तर आ उपलब्ध हार्डवेयर कें पार.

| क्षेत्रक कें विकास मे हम मदद करय चाहय छी | उपयोगी योगदान के उदाहरण |
| --- | --- |
| स्कूल, शिक्षा आ आजीवन सीखनाय | अवधारणाअक कें व्याख्या करनाय, सीखय कें सामग्री कें अनुकूलित करनाय आ शिक्षकक, छात्रक आ परिवारक कें सहायता करनाय. |
| अनुसंधान, विज्ञान एवं अंतरिक्ष | साहित्य कें खोज करनाय, विधियक कें व्याख्या करनाय, आंकड़ाक कें विश्लेषण करनाय आ ज्ञान कें साझा करनाय. |
| स्वास्थ्य, देखभाल आ सामाजिक समर्थन | जानकारी कें समझय मे आसान बनावा आ शोध आ पेशेवर कार्यप्रवाह कें समर्थन करनाय. |
| कृषि, खाद्य आ ग्रामीण समुदाय | व्यावहारिक ज्ञान साझा करनाय, योजना कें समर्थन करनाय आ स्थानीय रूप सं उपयोगी उपकरणक कें विकास करनाय. |
| पर्यावरण, जलवायु, जल आ जैव विविधता | साक्ष्य कें व्याख्या करनाय, अवलोकन कें समर्थन करनाय आ समुदायक कें परियोजनाक कें योजना बनावा मे मदद करनाय. |
| ऊर्जा, उद्योग, निर्माण आ शिल्प | समर्थन दस्तावेजीकरण, डिजाइन, रखरखाव, तकनीकी सीखनाय आ प्रक्रिया सुधार. |
| व्यवसाय, वाणिज्य, वित्त आ रोजगार | काज कें संगठित करय मे मदद करनाय, जानकारी कें समझनाय, परियोजनाक कें विकास करनाय आ पेशेवर कौशल सीखनाय. |
| लोक सेवा, कानून आ नागरिक भागीदारी | दस्तावेज आ प्रक्रियाक कें समझ मे आसान बनावा आ जानकारी कें पहुंच मे आसान बनावा. |
| कंप्यूटिंग, साइबर सुरक्षा, रोबोटिक्स आ दूरसंचार | सॉफ्टवेयर कें विकास मे मदद करनाय, सिस्टम कें समझनाय आ उपयोगी उपकरणक कें निर्माण करनाय. |
| कला, संस्कृति, मीडिया, भाषा आ धरोहर | लेखन, अनुवाद, छवि, वीडियो, रचनात्मक परियोजना आ सांस्कृतिक साझा करय कें समर्थन करनाय. |
| परिवहन, रसद, पर्यटन, खेल आ सामुदायिक जीवन | योजना, संचार, सीखनाय आ स्थानीय पहलक मे मदद करनाय. |
| सुलभता, मानवीय कार्य आ रोजमर्रा कें जीवन | भाषा आ ज्ञान कें बाधाक कें कम करनाय आ व्यावहारिक सहायता सं लोगक कें समर्थन करनाय. |

इ योगदान आ विकास कें लेल दिशा निर्देश छै, इ दावा नहि छै की हर क्षेत्र-विशिष्ट आवेदन पइहले सं वितरित या मान्य कैल गेल छै. हम रोजमर्रा कें उपयोग कें लेल सरल मार्गदर्शन, जरूरत पड़ला पर स्पष्ट उन्नत विकल्प, पारदर्शी हार्डवेयर आ क्लाउड कें आवश्यकता, आ प्रत्येक क्षेत्र आ स्थानीय संदर्भ कें जानय वाला लोगक कें साथ सहयोग चाहय छी.

## परियोजना के स्थिति

**Novera 1.0.0 Windows, Linux, macOS आ Android कें लेल उपलब्ध छै.** स्क्रीनशॉट एकटा Windows एप्लीकेशन कें दर्शा रहल छै जे रखरखाव करय वाला दूवारा स्थानीय रूप सं संकलित कैल गेल छै. स्रोत परिवर्तन, लक्षित परीक्षण आ हार्डवेयर सत्यापन कें अलग सं दस्तावेजीकरण कैल गेल छै; इ हर मॉडल, प्लेटफॉर्म या क्लाउड खाता कें मान्य नहि करएयत छै.

मैनुअल GitHub Actions बिल्ड सब एगारह वितरण वेरिएंट कें लेल सक्षम कैल गेल छै. के पालन करू [परिणाम आ सत्यापित उम्मीदवार डाउनलोड कें निर्माण](docs/CI_DISTRIBUTIONS.md); उपलब्धता प्रत्येक प्लेटफॉर्म कें लेल अलग सं रिकॉर्ड कैल जायत छै. उम्मीदवार हस्ताक्षरित प्रोडक्शन रिलीज स अलग छथि। वितरण कें आवश्यकताक कें वर्णन मे कैल गेल छै [आधिकारिक रिलीज नीति](OFFICIAL_RELEASES.md) एवं [पृष्ठ जारी करैत अछि](https://github.com/TRON-ABS/Novera/releases)के। मौजूदा अपडेटर-अक्षम उम्मीदवार आंतरिक रहैत अछि. सार्वजनिक रिलीज कें लेल एकटा विन्यस्त आ सत्यापित अपडेट तंत्र कें आवश्यकता होयत छै; [डेस्कटॉप हस्ताक्षर जांच आ शेष लॉन्च आवश्यकताक कें दस्तावेजीकरण कैल गेल छै](docs/LAUNCH_STATUS.md).
