## Novera 1.0.1

Novera 1.0.1 তলত তালিকাভুক্ত প্লেটফৰ্মসমূহৰ বাবে উপলব্ধ। আপোনাৰ ব্যৱস্থাপ্ৰণালীৰ বাবে সৰঞ্জাম ডাউনল'ড কৰক বা ইয়াৰ স্বাক্ষৰিত আপডেইট চেনেল ব্যৱহাৰ কৰক । বৰ্ত্তমানৰ সংস্থাপনসমূহ আপডেইট কৰে যেতিয়া আপুনি নতুন সৰঞ্জাম সংস্থাপন কৰে বা আপডেইট গ্ৰহণ কৰে ।

- সুৰক্ষা: দূৰৱৰ্তী পৃষ্ঠাসমূহৰ বাবে কঠোৰ স্থানীয় অনুমতিসমূহ, নে'টৱৰ্ক APIসমূহ আৰু চাৰ্ভাৰ সঁজুলিসমূহৰ বাবে প্ৰমাণীকৰণ, সুৰক্ষিত গোপন সংৰক্ষণ আৰু প্ৰব্ৰজন, সুৰক্ষিত নথিপত্ৰ/মিডিয়া অভিগম, স্প্ৰেডশ্বীট বিশ্লেষণ আৰু বিল্ড স্ক্ৰিপ্টসমূহ। উন্মুক্ত নিৰ্ভৰশীলতাসমূহ আপডেইট কৰা হৈছে; বাকী থকা পৰামৰ্শসমূহ মুকলিকৈ অনুসৰণ কৰা হয়।
- গোপনীয়তা: পৰিসংখ্যা আৰু ভুল প্ৰতিবেদনসমূহৰ বাবে পৃথক সন্মতিৰ প্ৰয়োজন আৰু অবিকল্পিতভাৱে বন্ধ হৈ থাকে। বিল্ডসমূহে নথিভুক্ত গন্তব্য বিন্যাস অন্তৰ্ভুক্ত কৰে। কাৰিকৰী নিদানসমূহ ফিল্টাৰ কৰা হয়; ব্যৱহাৰকাৰীসকলে সক্ৰিয়কৰণৰ নিয়ন্ত্ৰণ ৰাখে।

## প্ৰথম আৰম্ভণিৰ পৰা ফলাফললৈ

**আমাৰ স্বয়ংচালিত প্ৰণালীয়ে প্ৰস্তুতিক সম্পূৰ্ণ কাৰ্যকাৰী প্ৰবাহৰ সৈতে সংযোগ কৰে।** Novera নিৰ্বাচিত কনফিগাৰেচনৰ বাবে উপলব্ধ প্ৰযুক্তিগত পদক্ষেপসমূহ সামলায়, লগতে উন্নত নিয়ন্ত্ৰণসমূহ সহজলভ্য ৰাখে।

| পদ | Novera কি সামলায় |
| --- | --- |
| **1। আৰম্ভ কৰক** | প্ৰথম আৰম্ভণীত এটা সমৰ্থন কৰা ছিষ্টেম ভাষা নিৰ্বাচন কৰে আৰু আপোনাৰ পছন্দ সেভ কৰে। আৰম্ভণি মডেল আৰু উপযোগী হাৰ্ডৱেৰ তথ্য প্ৰদৰ্শন কৰে। |
| **2। প্ৰস্তুত কৰক** | গাইড কৰা স্থাপনৱে পাঠ্য, এমবেডিং, ছবি, সংগীত, ভিডিঅ' আৰু আপস্কেলিং আগবঢ়ায়। ই আপোনাৰ অনুমোদনৰ পূৰ্বে উপাদান, আকাৰ আৰু মুক্ত স্থানৰ প্ৰিভিউ দিয়ে, তাৰ পিছত প্ৰগ্ৰেছ, পজ/পুনৰুদ্ৰৱন আৰু SHA-256 প্ৰমাণীকৰণৰ সৈতে ডাউনলোডৰ খবৰ ৰাখে। |
| **3। কনফিগাৰ কৰক** | মডেল আৰু ইয়াৰ উপাদানসমূহ ৰেকGLOBALS কৰে, প্ৰাসংগিক প্ৰোফাইল প্ৰস্তুত কৰে আৰু প্ৰয়োজনীয় নিৰ্ভৰশীলতাৰ প্ৰতিবেদন দিয়ে। CPU/GPU সঞ্চয় কৰা পছন্দৰ সৈতে CPU ত ৰিট্ৰিভাল এমবেডিং আৰম্ভ হয়। নতুন সংগীত প্ৰোফাইলসমূহ ইনষ্ট্ৰমেণ্টেল মোডত ডিফল্ট হয়। |
| **4। অনুৰোধ বুজি লওক** | স্বয়ংক্রিয়ভাৱে চিনাক্ত কৰা সৃষ্টিৰ অনুৰোধসমূহ পাঠ্য, ছবি, সংগীত বা ভিডিঅ'লৈ পথ প্ৰদৰ্شي কৰে। আপুনি আউটপুট মোড আৰু এটা স্থানীয় বা ক্লাউড মডেল স্পষ্টভাৱে বাছনি কৰিব পাৰে। |
| **5। কাৰ্যকৰী কৰক** | স্বয়ংক্রিয় মেমৰিয়ে কাৰ্য্যশীল কামৰ বাবে অপেক্ষা কৰে, প্ৰয়োজন নোহোৱা মডেলসমূহ মুক্ত কৰে আৰু প্ৰয়োজনীয় সম্পদসমূহ পুনৰ লোড কৰে। এটা 1–10 কামৰ শৃংখলা ক্ৰম অনুসৰি চলি থাকে আৰু পৰৱৰ্তী কামৰ পূৰ্বে সম্পদসমূহ মুক্ত কৰে। ক্লাউড প্ৰোভাইডেৰসকলে বাছনি কৰা একাউণ্ট আৰু কনফিগাৰেশ্যন ব্যৱহাৰ কৰে। |
| **6। পুনৰুদ্ধাৰ কৰক আৰু পুনৰ ব্যৱহাৰ কৰক** | Noveraৰ ছিষ্টেম ফোল্ডাৰত মিডিয়া সংৰক্ষণ কৰে, ফলাফল আৰু উপলব্ধ সময় দেখুৱায়, তাৰ পিছত বিকল্পসমূহ, লাইব্ৰেৰী, কপি কৰা, এক্সপৰ্ট বা ছিষ্টেম শেৰিং আগবঢ়ায়। আন এটা এপ্লিকেচনলৈ প্ৰেৰণ কৰাটো আপোনাৰ কাৰ্য্য হৈ থাকে। |

স্বয়ংক্রিয়তাৰ অধীনত ইন্টিগ্ৰেটেড ইঞ্জিন আৰু কাৰ্য্য প্ৰবাহ অন্তৰ্ভুক্ত; ই প্ৰতিটো Hub মডেল কাৰ্যকৰী কৰে নহয়। হাৰ্ডৱেৰ, স্থাপন কৰা উপাদান আৰু প্ৰোভাইডেৰৰ প্ৰৱেশাধিকাৰ নিৰ্ধাৰণ কৰে কি কি চলিব পাৰে। ফোল্ডাৰ, ফাইলৰ পৰিৱৰ্তন আৰু শেল কামানডসমূহ কথোপকথনৰ প্ৰৱেশাধিকাৰ অনুসৰণ কৰে।

বিদ্যালয় আৰু শিক্ষাৰ বাহিৰেও, আমাৰ উচ্চাকাংক্ষা হৈছে বিশ্বজুৰি মানুহক শিকিবলৈ, সমস্যা সমাধান কৰিবলৈ, সৃষ্টি কৰিবলৈ আৰু উপযোগী প্ৰকল্প গঢ়ি তুলিবলৈ সহায় কৰা। Novera-ৰ লক্ষ্য হৈছে বৰ্তমানৰ AI অগ্ৰগতিসমূহ ভাষা, অভিজ্ঞতাৰ স্তৰ আৰু উপলব্ধ হার্ডৱেৰৰ জৰিয়তে বুজিবলৈ আৰু ব্যৱহাৰ কৰিবলৈ সহজ কৰা।

এইবোৰ অৱদান আৰু বিকাশৰ দিশ, কোনো খণ্ড-ভিত্তিক প্ৰয়োগ সকলোৱে ইতিমধ্যে প্ৰদান কৰা বা প্ৰমাণিত হৈছে বুলি দাবী নহয়। আমি দৈনন্দিন ব্যৱহাৰৰ বাবে সহজ পথপ্ৰদৰ্শন, প্ৰয়োজন হ'লে স্পষ্ট উন্নত বিকল্প, স্বচ্ছ হাৰ্ডৱেৰ আৰু ক্লাউডৰ প্ৰয়োজনীয়তা, আৰু প্ৰতিটো ক্ষেত্ৰ আৰু স্থানীয় পৰিস্থিতি জনা লোকৰ সৈতে সহযোগিতা বিচাৰোঁ।

## প্ৰকল্পৰ স্থিতি

স্ক্ৰীণশ্বটটোৱে ৰক্ষণাবেক্ষণকাৰীৰ দ্বাৰা স্থানীয়ভাৱে সংকলিত Windows প্ৰয়োগ দেখুৱায়। উৎসৰ পৰিৱৰ্তন, লক্ষ্যভিত্তিক পৰীক্ষা আৰু হাৰ্ডৱেৰ প্ৰমাণীকৰণ পৃথকভাৱে নথিভুক্ত কৰা হৈছে; ই সকলো মডেল, Platfrom বা ক্লাউড একাউণ্ট প্ৰমাণিত নকৰে।

সকলো এঘাৰটা বিতৰণ প্ৰকাৰৰ বাবে ম্যানুৱেল GitHub Actions বিল্ড সক্ষম কৰা হৈছে। তলত অনুসৰণ কৰক [বিল্ড ফলাফল আৰু প্ৰমাণিত প্ৰাৰ্থী ডাউনলোডসমূহ](docs/CI_DISTRIBUTIONS.md); উপলব্ধতা প্ৰতিটো Platfromৰ বাবে পৃথকভাৱে লিপিবদ্ধ কৰা হৈছে। প্ৰাৰ্থীসমূহ স্বাক্ষৰিত উৎপাদন মুকলিৰ পৰা পৃথক। বিতৰণৰ প্ৰয়োজনীয়তাসমূহ তলত বৰ্ণনা কৰা হৈছে [আনুষ্ঠানিক মুকলি নীতি](OFFICIAL_RELEASES.md) আৰু [মুকলি পৃষ্ঠা](https://github.com/TRON-ABS/Novera/releases). বিদ্যমান আপডেটাৰ-নিষ্ক্ষম প্ৰাৰ্থীসমূহ আভ্যন্তৰীণ হৈ থাকে। সাধাৰণ মুকলিৰ বাবে এটা কনফিগাৰেট আৰু প্ৰমাণিত আপডেট মেকানিজমৰ প্ৰয়োজন; [ডেস্কটপ স্বাক্ষৰ পৰীক্ষা আৰু বাকী লঞ্চ প্ৰয়োজনীয়তাসমূহ নথিভুক্ত কৰা হৈছে](docs/LAUNCH_STATUS.md).
