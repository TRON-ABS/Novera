## Novera 1.0.1

Novera 1.0.1은(는) 아래 나열된 플랫폼에서 사용할 수 있습니다. 시스템에 맞는 패키지를 다운로드하거나 서명된 업데이트 채널을 사용하세요. 새 패키지를 설치하거나 업데이트를 수락하면 기존 설치가 업데이트됩니다.

- 보안: 원격 페이지에 대한 더 엄격한 기본 권한, 네트워크 API 및 서버 도구에 대한 인증, 보호된 비밀 저장 및 마이그레이션, 더 안전한 파일/미디어 액세스, 스프레드시트 구문 분석 및 빌드 스크립트. 노출된 종속성이 업데이트되었습니다. 나머지 권고 사항은 공개적으로 추적됩니다.
- 개인정보 보호: 통계 및 오류 보고에는 별도의 동의가 필요하며 기본적으로 꺼져 있습니다. 빌드에는 문서화된 대상 구성이 포함됩니다. 기술 진단은 필터링됩니다. 사용자는 활성화를 계속 제어합니다.
- 로컬 엔진: `llama.cpp v0.9.0` (`b12110`, `cd959bae99ff4bed22bef2604f45241c09bbb8c8`). 엔진 버전과 애플리케이션 버전은 별개입니다. `kv_unified`과 관련된 시작 실패를 포함하여 초기 모델 설정 및 모델/프로젝터 등록이 수정되었습니다. 기존 개인 설정은 유지됩니다.
- 언어: 24 추가 언어 및 변형은 인터페이스 및 번역된 README 컬렉션을 카탈로그당 2,435 인터페이스 키와 함께 104로 가져옵니다. 이 적용 범위는 모든 언어의 기본 편집 품질이나 음성 지원을 인증하지 않습니다.
- **LFM3-Omni-2B Q4_K_M** — 데스크톱 및 모바일의 기본값입니다. 필수 `mmproj` 파일을 사용하는 텍스트, 이미지 및 오디오용 컴팩트 모델입니다. 다운로드: 두 파일 모두에 대한 1.39 GB 정보입니다. 더 가벼운 다중 모드 설정을 위해 선택하십시오. 음성 기능은 플랫폼과 엔진에 따라 다릅니다. 컨텍스트가 길수록 더 많은 메모리를 사용합니다.
- **NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M** — 대화, 글쓰기, 도구 및 구조화된 답변을 위한 텍스트 전용 대안입니다. 다운로드: 6.18 GB 정보. LFM3-Omni보다 더 많은 메모리가 필요하며 이미지나 오디오 자체를 처리하지 않습니다. 음성 응답은 시스템 음성을 사용합니다. 메모리가 충분할 때 텍스트 작업에 선택하세요. 출처를 통해 사실적인 답변을 확인하세요.
- 1.0.1의 경우 필수 `mmproj-LFM3-Omni-2B-Q4_K_M.gguf`가 포함된 LFM3-Omni-2B Q4_K_M가 데스크톱 및 모바일의 기본 권장 사항입니다. NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M는 텍스트 전용 대안으로 남아 있습니다. 초기 컨텍스트는 데스크톱에서는 32,768 토큰이고 모바일에서는 2,048입니다. 컨텍스트가 길수록 더 많은 메모리를 사용합니다. 기존 모델 선택 및 설정은 명시적으로 변경될 때까지 유지됩니다.
- 음성: LFM3-Omni에 대한 직접 로컬 마이크 입력, 지속적인 대화 및 자동 전송, 오디오 모델에 대한 남성/여성 응답 음성, 클래식 모델에 대한 시스템 음성. 응답 읽기는 마이크 캡처와 별도로 입력된 메시지 및 재생성에도 작동합니다. 작은 사운드 버튼으로 독서를 활성화하거나 음소거할 수 있습니다.
- 마이크 상태: 사용 가능한 경우 녹색, 사용 중인 경우 빨간색, 사용할 수 없는 경우 회색. 인식, 듣기 재시작, 포커스 처리 및 보이는 받아쓰기가 수정되었습니다. 기본 오디오 모델 음성은 현재 Windows에 구현되어 있습니다. 다른 플랫폼에는 여전히 기본 검증과 적절한 음성 지원이 필요합니다.
- 웹: 더욱 안정적인 날씨 요청 감지, 현재 날짜 안내, 새로운 결과 및 인용, 도구 사용 후 현재 요청을 중심으로 한 답변. 음성에서는 눈에 띄는 인용을 유지하면서 장식적인 소스 라벨과 링크를 생략합니다. 응답 및 음성 언어는 선택한 모델이 지원하는 한 사용자의 언어를 따릅니다.
- 최적화: 인터넷이 활성화된 경우 백그라운드에서 웹 검색을 준비하고, 서비스 시작을 공유하고, 재생 전에 다음 음성 세그먼트를 준비하고, 문장 연속성을 향상시킵니다. 프랑스어 연도, 십진수 및 단위가 더 자연스럽게 읽혀집니다. 네트워크 대기 시간과 모델 속도는 여전히 설정에 따라 달라집니다.
- 편안함: 입력이 계속 표시되는 동안 낮은 컨트롤이 축소됩니다. 컴팩트한 마이크 및 공개 컨트롤, 마이크 아래의 사운드 버튼, 반응형 음악 설정 및 번역된 구성 요소 라벨을 통해 작은 화면에서의 사용이 향상됩니다.
- API 카탈로그: 43 제공자 프로필(로컬에서 TabbyAPI 포함), 새로워진 채팅 및 미디어 선택이 포함됩니다. 새 항목에는 지원되는 경우 GPT-6.1 Terra, Kimi K3.1 Pro, MiniMax M3.1 Flash, GLM 5.3 Flash, Hy4 및 GPT Image 2.6, Gemini Omni 1.2, FLUX 3가 포함됩니다. 새로 고침 시 더 이상 모델 10개를 초과하는 결과를 숨기지 않습니다. 정확한 식별자, 지역 엔드포인트, 비공개 배포 및 가져온 모델이 존중됩니다.
- 검증: 대상 애플리케이션, 네이티브 라이브러리, 공개 카탈로그 및 언어 확인이 세부 메모에 기록됩니다. Windows / macOS / Linux / Android / iOS용 인터페이스가 빌드되었습니다. 이러한 프런트엔드 빌드는 모든 장치에서 기본 패키지 또는 추론을 인증하지 않습니다.
- 가용성 및 완료된 확인 사항은 다음과 같습니다. 지원되는 기능은 하드웨어, 공급자 액세스 및 플랫폼에 따라 다릅니다. 보안 발견 사항 및 기본 장치 유효성 검사 제한은 문서화되어 있습니다. 업데이트하기 전에 백업을 유지하십시오.

## 첫 출시부터 성과까지

**우리의 자동화는 준비를 전체 실행 워크플로우에 연결합니다.** Novera는 선택한 구성에 사용할 수 있는 기술 단계를 처리하는 동시에 고급 제어 기능에 대한 액세스를 유지합니다.

| 단계 | Novera가 다루는 것 |
| --- | --- |
| **1. 시작** | 처음 실행 시 지원되는 시스템 언어를 선택하고 기본 설정을 저장합니다. 시작 모델과 유용한 하드웨어 정보를 제공합니다. |
| **2. 준비하다** | 설치 안내는 텍스트, 임베딩, 이미지, 음악, 비디오 및 업스케일링을 제공합니다. 승인 전에 구성 요소, 크기 및 여유 공간을 미리 본 다음 진행률, 일시 중지/재개 및 SHA-256 확인을 통해 다운로드를 추적합니다. |
| **3. 구성** | 모델과 해당 구성 요소를 등록하고 관련 프로필을 준비하며 필요한 종속성을 보고합니다. 검색 임베딩은 저장된 CPU/GPU 선택으로 CPU에서 시작됩니다. 새로운 음악 프로필은 기본적으로 악기 모드로 설정됩니다. |
| **4. 요청을 이해하세요** | 인식된 생성 요청을 텍스트, 이미지, 음악 또는 비디오로 자동 라우팅합니다. 출력 모드와 로컬 또는 클라우드 모델을 명시적으로 선택할 수도 있습니다. |
| **5. 실행하다** | 자동 메모리는 활성 작업을 기다리고, 불필요한 모델을 해제하고, 필요한 리소스를 다시 로드합니다. 1–10 작업 시리즈는 순서대로 실행되고 다음 작업 전에 리소스를 해제합니다. 클라우드 공급자는 선택한 계정과 구성을 사용합니다. |
| **6. 검색 및 재사용** | Novera 시스템 폴더에 미디어를 저장하고 결과와 사용 가능한 타이밍을 표시한 다음 변형, 라이브러리, 복사, 내보내기 또는 시스템 공유를 제공합니다. 다른 응용 프로그램으로 보내는 것은 귀하의 작업으로 유지됩니다. |

자동화는 통합 엔진과 워크플로우를 다룹니다. 모든 허브 모델을 실행 가능하게 만드는 것은 아닙니다. 하드웨어, 설치된 구성 요소 및 공급자 액세스에 따라 실행할 수 있는 항목이 결정됩니다. 폴더, 파일 변경 및 셸 명령은 대화의 액세스 권한을 따릅니다.

[이용안내](docs/USER_GUIDE.md) · [엔진 및 검증](docs/SUIVI_MOTEURS.md) · [개발](docs/DEVELOPMENT.md)

1.0.1의 경우 필수 `mmproj-LFM3-Omni-2B-Q4_K_M.gguf`가 포함된 LFM3-Omni-2B Q4_K_M가 데스크톱 및 모바일의 기본 권장 사항입니다. NVIDIA Nemotron-3.5-Bolt-E4B Q4_K_M는 텍스트 전용 대안으로 남아 있습니다. 초기 컨텍스트는 데스크톱에서는 32,768 토큰이고 모바일에서는 2,048입니다. 컨텍스트가 길수록 더 많은 메모리를 사용합니다. 기존 모델 선택 및 설정은 명시적으로 변경될 때까지 유지됩니다.

| **LoRA / PEFT 어댑터** | Safetensors 공급자에서 별도의 로컬 어댑터를 사용하여 완전한 베이스를 가져옵니다. | 양자화되지 않은 인과 Transformers 기반, 일치 ID, 텐서 검사 및 누적 메모리 추정; [설정 및 제한](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | 호환 가능한 고밀도 Llama/Qwen2/Qwen3 텐서별 FP8 내보내기를 위한 기본 CUDA 실행. | 아키텍처/텐서 검사 및 실제 커널 프로브; [설정 및 제한](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |
| **NVFP4 LLM / ModelOpt** | 네이티브 CUDA GEMM을 통한 패킹된 블록-16 FP4 투영; 이미지 NVFP4와 별개입니다. | 호환 가능한 Blackwell GPU, 지원되는 치수/내보내기 및 실제 커널 프로브; RTX 5070에서 학습되지 않은 테스트 모델로 검증했습니다. |
| **AWQ** | 4-bit GEMM 모델 체크포인트는 연산 융합이 없습니다. | NVIDIA CUDA 및 옵션 GPTQModel/Transformers 로더. |
| **GPTQ** | 2/3/4/8 비트 구성, gptq/gptq_v2 형식. | NVIDIA CUDA, GPTQModel 및 Optimum; 4 비트에서 실제 실행 테스트를 거쳤습니다. |
| **bitsandbytes** | 4비트 NF4/FP4 또는 8비트 INT8. | NVIDIA CUDA 및 선택적 종속성; 실제 NF4 및 INT8 테스트. |
| **EXL3** | ExLlamaV3를 통해 로드된 완전한 양자화 Safetensors 모델 폴더; CUDA를 사용한 실제 세대가 테스트되었습니다. | NVIDIA GPU, 별도의 Python 3.12 환경 및 호환 아키텍처; CPU 대체가 없습니다. |
| **EXL2** | 전용 ExLlamaV2 로더; 스트리밍, 취소 및 언로드는 GPU.에서 테스트되었습니다. | 테스트한 소프트웨어 구성에서는 CUDA Attention 백엔드를 명시적으로 선택해야 합니다. 완전한 모델 체크포인트와 충분한 VRAM 공간이 필요합니다. |
| **MLX** | Apple Silicon와 호환되는 모델입니다. | MLX 엔진 및 지원 플랫폼. |

이제 허브가 고정됩니다. **LFM3-1.7B** Q4_K_M, Q6_K 및 Q8_0 변형과 호환되는 구성을 위한 LiquidAI 권장 사항입니다. 첫 실행 모델은 위의 안내 구성에 나열된 모델로 유지됩니다.

다운로드 가중치 필터링: **1 GB ~ 500 GB 이상**그런 다음 하드웨어 적합성, 크기, 최신성 또는 다운로드별로 정렬합니다. 결과는 점진적으로 로드됩니다. 필터는 가져온 모델과 기본 변형에 적용됩니다. 메모리 조언은 공유 GPU 메모리를 이중 계산하지 않고 사용 가능한 RAM/VRAM, 컨텍스트 및 동반 구성 요소를 사용합니다.

AWQ 4-bit, GPTQ 4-bit, NF4 및 INT8는 각각 오프라인으로 생성된 훈련되지 않은 작은 모델을 사용하여 RTX 5070 Laptop에 텍스트를 생성했습니다. 이는 모든 모델의 품질이나 성능이 아닌 로드 및 실행을 검증합니다. **이러한 추가 사항은 소스에 있습니다. 다시 빌드하고 호환 가능한 종속성이 필요합니다. 이 README 업데이트는 설치된 바이너리를 업그레이드하지 않습니다.**

**RTX 5070 Laptop에서 측정:** Qwen2.5-0.5B-Instruct, 컨텍스트 2,048, 프롬프트 272 토큰, 128 생성 토큰, 5번의 워밍 실행: 중앙값 디코드 **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. 여기서는 GGUF에 비해 속도 이점이 입증되지 않았습니다. 양자화/보정이 다르며 EXL3가 기초 산술 테스트 하나를 통과하지 못했습니다. 이 결과는 일반적인 속도나 품질 순위가 아닙니다. [전체 측정 및 한계](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** 는 선택 사항이며 별도로 관리되는 OpenAI 호환 서버 연결이며 기본적으로 비활성화되어 있습니다. 인증된 EXL3 모델 검색 및 스트리밍이 테스트되었습니다. 관리형 로컬 ExLlama 경로는 고유하게 유지됩니다. [ExLlama 설정 및 TabbyAPI 연결](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

기본 하드웨어 조정 정렬은 동일한 호환성 및 사용 가능한 메모리 계층 내에서 최신 릴리스를 선호합니다. 설치된 모델은 자동으로 교체되지 않습니다.

[양자화 Safetensors 설정](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [형식, 우선순위 및 유효성 검사](docs/SUIVI_MOTEURS.md)

업데이트된 소스 추가 **Windows x64 구성의 선택적 관리 구성 요소**: 비공개 Python 환경, 고정된 CPU/CUDA 프로필, 다운로드 전 견적 및 확인, 확인, 수리 및 제거. 사용자 정의 통역사 경로는 고급 옵션 아래에 있습니다. 기본 GGUF 엔진은 기존 구성 요소를 유지합니다. 모바일 및 클라우드에서는 데스크톱 Python/PyTorch를 다운로드하지 않습니다. 3개의 개인용 CPU/내보내기 프로파일이 합성 테스트 데이터를 사용하여 실행되었습니다. 관리자는 2026년 11월 1일에 성공적인 데스크톱 사용을 보고합니다. GPU 프로필 및 클린 PC 설치는 여전히 별도의 자세한 검증이 필요합니다. [프로필 및 테스트 한도](docs/REPRISE_COMPOSANTS_GERES_80_LANGUES.md). EXE에 스택을 포함하는 것은 연기됩니다.

## 프로젝트 현황

**Novera 1.0.1는 Windows, Linux, macOS 및 Android에 사용할 수 있습니다.** 스크린샷은 관리자가 로컬로 컴파일한 Windows 애플리케이션을 보여줍니다. 소스 변경, 대상 테스트 및 하드웨어 검증은 별도로 문서화됩니다. 이는 모든 모델, 플랫폼 또는 클라우드 계정을 검증하지는 않습니다.

수동 GitHub Actions 빌드는 11개 배포 변형 모두에 대해 활성화됩니다. 따라가다 [빌드 결과 및 검증된 후보 다운로드](docs/CI_DISTRIBUTIONS.md); 가용성은 각 플랫폼마다 별도로 기록됩니다. 후보자는 서명된 프로덕션 릴리스와 다릅니다. 배포 요구 사항은 [공식 출시 정책](OFFICIAL_RELEASES.md) 그리고 [출시 페이지](https://github.com/TRON-ABS/Novera/releases). 기존 업데이트 프로그램이 비활성화된 후보는 내부에 남아 있습니다. 공개 릴리스에는 구성되고 검증된 업데이트 메커니즘이 필요합니다. [데스크톱 서명 확인 및 나머지 실행 요구 사항이 문서화되어 있습니다.](docs/LAUNCH_STATUS.md).
