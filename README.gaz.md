![Novera fakkii fi daashboordii tokkummaa kan baay'ina, sanyii, olka'iinsaa fi yaadannoo ofumaan qabu maddisiise](.github/assets/novera-dashboard-2026-11-01.png)

*Fakkii iskiriinii iyyannoo dhugaa Windows kan kunuunsaan 1 Sadaasa 2026 irratti dhihaate, innis aplikeeshiniin akka gaariitti akka hojjetu gabaase. Laandiskaappii uumame, too'annoowwan faayilii qusatame isaa fi daashboordii uumuu tokkummaa agarsiisa; kun mockup miti.*

Paanaalii tokko, haalawwan shan: **Ofumaan / Barreeffama / Fakkii / Muuziqaa / Viidiyoo**. To'annoon haalata filatame hordofu: reeshiyoo, furmaata, yeroo, kaadeensi, qulqullina, meeshaa, jechoota, sanyii fi baay'ina. Bal'inni paanaalii fi qareewwan foddaa fi asxaalee hiikamanitti madaqu.

- **1–10 dhaloota tartiiba**, durtii 1, baay'ina of danda'e fakkii, muuziqaa fi viidiyoo wajjin. Dhaabi hojii socho'aa fi tarree hafe haqa.
- **Sanyiiwwan tasaa, dhaabbataa, +1 fi −1**, reeshiyoo dursee murtaa’e ykn amala fi filannoo **Real-ESRGAN ×2/×4** olkaasuun safara dhumaa agarsiifameen.
- Moodeelli filatame, yaadannoo ofumaan, dabalataa, qajeelfama, barbaacha weebii fi meeshaaleen barruu tokko keessa turu. Meeshaaleen dandeettii moodeela fi qaqqabummaa kenname irratti hundaa'u.

## Jalqaba eegaluu irraa kaasee hanga bu’aa

**Otoomaatikiin keenya qophii adeemsa hojii raawwii guutuu waliin walqabsiisa.** Novera tarkaanfiiwwan teeknikaa qindeessaa filatameef jiran ni qabata, too'annoowwan sadarkaa olaanaa akka dhaqqabamaa ta'an eega.

| Tarkaanfii | Waan Novera qabatu |
| --- | --- |
| **1. Jalqaba** | Afaan sirna deeggaramee jalqaba eegaluu filatee filannoo kee qusata. Moodeelota jalqabaa fi odeeffannoo haardwaaraa faayidaa qabu ni dhiheessa. |
| **2. Qophii** | Qajeelfama fe'iinsi barreeffama, ukkaamsuu, fakkii, muuziqaa, viidiyoo fi olka'iinsa ni dhiheessa. Qaamolee, guddinaa fi bakka bilisaa osoo hin hayyamiin dura dursee ilaala, sana booda buufachuu adeemsa, dhaabuu/deebi'ee jalqabuu fi mirkaneessuu SHA-256 hordofa. |
| **3. Qindeessi** | Moodeelotaa fi qaamolee isaanii galmeessa, piroofaayilii barbaachisoo ta’an ni qopheessa, hirkattummaa barbaachisan ni gabaasa. Ukkaamsiwwan deebisuu filannoo CPU/GPU qusatameen CPU irraa jalqaba. Profaayiloonni muuziqaa haaraa durtii gara haalata meeshaatti. |
| **4. Gaaffii kana hubachuu** | Ofiin gaaffii uumama beekame gara barreeffama, fakkii, muuziqaa ykn viidiyootti qajeelcha. Akkasumas haalata baasaa fi moodeela naannoo ykn duumessaa ifatti filachuu dandeessa. |
| **5. Raawwadhu** | Miimooriin ofumaan hojii sochii qabu eega, moodeelota hin barbaachifne gadhiisa fi qabeenya barbaachisu irra deebi'ee fe'a. Tartiiba hojii 1–10 tartiiba fi qabeenya hojii itti aanu dura gadhiisa. Dhiyeessitoonni duumessaa akkaawuntii fi qindeessaa filatame fayyadamu. |
| **6. Fudhachuu fi irra deebi'anii fayyadamuu** | Miidiyaa galmeewwan sirnaa Novera keessatti saaga, bu'aa fi yeroowwan jiran agarsiisa, sana booda garaagarummaa, mana kitaabaa, waraabbii, al-ergii ykn qoodinsa sirnaa dhiyeessa. Gara application biraatti erguun tarkaanfii kee ta'ee hafa. |

Otoomaashiniin motora fi adeemsa hojii walitti makame kan hammatudha; moodeela Hub hunda akka raawwatamu hin godhu. Hardware, installed components fi provider access maaltu hojjechuu akka danda'u murteessa. Galmeewwan, jijjiiramni faayilii fi ajajoota qaaqa deeggarsa qaqqabummaa haasawa hordofu.

[Qajeelfama fayyadamaa](docs/USER_GUIDE.md) · [Mootora fi mirkaneessuu](docs/SUIVI_MOTEURS.md) · [Misooma](docs/DEVELOPMENT.md)

Maddoota haaromfame keessatti, . **Qindeessitoonni yaada isaa gara haardwaara sochootuu fi danqameetti madaqsa**: LFM3-1.7B Q4, ykn LFM3-Omni-2B Q4 pirojektara isaa waliin yeroo mimoorii fi motora gabaafame barbaachisummaan guutamu. Dhaloonni naannoo hin argamne dhokatee ykn uggurama; suuraa duumessaa qindaa'e, muuziqaa fi viidiyoon ni hafu. Qajeelfamni walqunnamtii kataloogota afaanii 80 irra deebi'ee fayyadama. Tilmaamni kun ammallee qorannoo meeshaa fi irra deebiin ijaaruu kan barbaadu application fe'aman bira ga'uuf.

## AI moodeelota meeshaa keessan irratti naannootti hojjetan

Moodeelotni kunniin qindeessaa qajeelfama ammaa uumu. Moodeelota walsimsiisan biroo galchuu ykn piroofaayilii jijjiiruu dandeessa.

| **Sanada argachuu** | **Qwen3-Embedding-0.6B Q8_0**, **CPU akka durtiitti**, filannoo CPU/GPU qusatamee wajjin. |
| **Suuraa** | **FLUX.2 Klein 4B Q4_K_M**, **Qwen3-4B Q4_K_M** enkoodaraa fi ofiisaa FLUX.2 VAE. |
| **Fakkii — filannoo haardwaaraa** | **FLUX.2 Klein 4B NVFP4**, karaa daandii dhalootaa CUDA yeroo GPU fi naannoon walsimsiisu. |
| **Muuziqaa** | **ACE-Step 1.5 Turbo 2B Q4_K_M**, `acestep-5Hz-lm-1.7B-Q8_0.gguf` karoora, kan of kenne Qwen enkoodara muuziqaa fi VAE. |
| **Viidiyoo** | **Wan2.1 T2V 1.3B Q4_K_M**, **UMT5-XXL Q4_K_M** enkoodarii fi Wan 2.1 VAE. |
| **Olkaa’uu** | Filannoodha **Real-ESRGAN ×2 fi ×4 irratti kan argamudha**, sakatta’iinsa hirkattummaa wajjin. |

## Hub fi moodeelota walsimsiisan

**GGUF, istaandaardii fi kuwantii Safetensors, ONNX, fi MLX**: hojiidhaan moodeelota qorachuu fi garaagarummaa motoraa fi haardwaara kee wajjin walsimu filachuu.

| Maatii | Deeggarsa madda keessatti | Ulaagaalee |
| --- | --- | --- |
| **GGUF** | Dhaloota barreeffamaa hanga llama.cpp; qaamolee fakkii fi viidiyoo piroofaayilii deeggaramaniif. | Arkiteekcharii motora walitti qabameen beekame. |
| **Qoqqoodinsa GGUF** | Garaagarummaa tokko tartiiba guutuu tokkoof, guddina walitti qabame, hunda-shaard buufachuu fi guddina/SHA-256/mata duree sakatta'iinsa. | Maqaawwan faayilii lakkoofsa istaandaardii qaban; 500 GB buufachuun moodeelli kun PC. kanaaf ni simata jechuu miti |
| **Istaandardii Safetensors** | Galmeewwan guutuu hanga Transformers, barreeffama sababa CPU ykn NVIDIA CUDA irratti. | Qindeessi, tokenizer fi shard barbaachisu hunda. |
| **ONNX Runtime** | Galtee biyya keessaa giraafii lakkoofsaa/bool fi al-ergii barruu qophaa'e GenAI. | Galmee guutuu mirkanaa'e; hojii addaa dursee adeemsisuun/booda adeemsisuun barbaachisaadha; [setup fi daangaa](onnx-server/README.md). |
| **LoRA / PEFT adaaptaroota** | Bu'uura guutuu adaaptara naannoo isaa adda ta'e waliin dhiyeessaa Safetensors keessatti galchi. | Bu’uura sababa Transformers kan hin baay’anne, eenyummaa walsimsiisu, sakatta’iinsa tensaraa fi tilmaama yaadannoo kuufamaa; [setup fi daangaa](transformers-server/README.md#local-lora--peft-adapters). |
| **FP8 LLM / ModelOpt** | Raawwii dhalootaa CUDA walsimsiisaa dhangala'aa Llama/Qwen2/Qwen3 teensara tokkoof FP8 al-ergii. | Sakatta’iinsa arkiteekcharii/tensaraa fi qorannoo kernel dhugaa; [setup fi daangaa](transformers-server/README.md#modelopt-fp8-and-nvfp4-llms). |
| **NVFP4 LLM / ModelOpt** | Pirojekshinii bilookii-16 FP4 karaa GEMM dhalootaa CUDA; suuraa NVFP4 irraa adda. | Walsimsiisaa Blackwell GPU, safara/al-ergii deeggaramee fi qorannoo keernii qabatamaa; moodeelota yaalii hin leenjifamne RTX 5070 irratti qorataman. |
| **AWQ** | 4-bit GEMM buufataalee sakatta'iinsaa moodeela fiyuushinii hojii malee. | NVIDIA CUDA fi filannoo GPTQModel/Transformers fe’umsa. |
| **GPTQ** | 2/3/4/8-bit qindeessaa, gptq/gptq_v2 bifa. | NVIDIA CUDA, GPTQModel fi Optimum; raawwii dhugaa 4 bits irratti qoratame. |
| **bitsandbytes** | 4-bit NF4/FP4 ykn 8-bit INT8. | NVIDIA CUDA fi hirkattummaa filannoo; qorannoo dhugaa NF4 fi INT8. |
| **EXL3** | Galmeewwan moodeela Safetensors kuwantii ta’an guutuu kanneen karaa ExLlamaV3 fe’aman; dhaloota qabatamaa CUDA waliin qoratameera. | NVIDIA GPU, naannoo fi ijaarsa walsimsiisu adda Python 3.12; lakk CPU duubatti deebi'uu. |
| **EXL2** | Fe'aa ExLlamaV2 kan of kenne; streaming, cancellation fi unload GPU. irratti qoratameera | CUDA xiyyeeffannaan tuullaa sooftiweerii qoratameef ifatti filatamuu qaba; buufata sakatta’iinsa moodeela guutuu fi VRAM argamu barbaachisa. |
| **MLX** | Moodeelota walsimsiisan Apple Silicon irratti. | MLX motora fi waltajjii deeggarame. |

Hub amma pin godha **LFM3-1.7B** akka yaada isaa LiquidAI qindaa'inoota walsimsiisuuf, garaagarummaa Q4_K_M, Q6_K fi Q8_0 waliin. Moodeelli fiigicha jalqabaa isa qindeessaa qajeelfama armaan olitti tarreeffame ta'ee hafa.

Ulfaatina buufachuu irraa calaluu **1 GB hanga 500 GB fi isaa ol jalatti**, sana booda walsimsiisaa haardwaarii, guddina, yeroo dhiyoo ykn buufachuudhaan saagi. Bu’aan tartiibaan fe’ama; calaqqeewwan moodeelota fidaman fi garaagarummaa durtii isaanii irratti raawwatu. Gorsi yaadannoo RAM/VRAM jiran, qaamolee haalaa fi hiriyyaa fayyadama, yaadannoo GPU qoodame dachaa lama osoo hin lakkaa'in.

AWQ 4-bit, GPTQ 4-bit, NF4 fi INT8 tokkoon tokkoon isaanii barruu an RTX 5070 Laptop moodeelota xixiqqoo hin leenjifamne kanneen sarara ala uumaman fayyadamuun. Kunis fe'iinsaa fi raawwii mirkaneessa malee qulqullina ykn raawwii moodeela hunda miti. **Dabalataan kun madda keessa jiru: irra deebiin ijaaruu fi hirkattummaa walsimsiisu barbaachisa; fooyya'iinsi README kun baayinarii fe'ame hin fooyyessuu.**

**RTX 5070 Laptop irratti kan safarame:** Qwen2.5-0.5B-Instruct, haalata 2,048, gaaffii 272 mallattoolee, 128 mallattoolee uumaman, fiigicha ho'ifame shan: hiikuu gidduugaleessaa **GGUF Q4_K_M 402.7 tokens/s · EXL3 4 bpw 312.5 · EXL2 4 bpw 146.9**. Faayidaan saffisa GGUF ol asitti hin agarsiifamne. Kuwantiilayizimii/safartuun garaagarummaa qaba, fi EXL3 aarri herregaa tokko kufe; bu’aan kun saffisa waliigalaa ykn sadarkaa qulqullinaa miti. [Safartuuwwanii fi daangaa guutuu](deliverables/exllama-2026-10-30/validation.md).

**TabbyAPI** filannoo, addaan bulfamu OpenAI-walsimsiisaa sarvarii walqabsiisa, durtii hanqifame. Argannoo fi yaa'iinsa moodeela EXL3 mirkanaa'e qoratameera. Daandiin naannoo ExLlama bulfamu adda ta'ee jira. [ExLlama qindeessuu fi TabbyAPI walqabsiisa](transformers-server/README.md#exl3-first-exl2-second--nvidia-execution).

Sassaabni durtii haardwaarii-madaqfame gadhiifama haaraa sadarkaa walsimsiisaa fi yaadannoo-argamaa walfakkaataa keessatti fayyadu. Moodeelonni dhaabbatan ofumaan hin bakka bu'an.

[Saagi Safetensors baay’inaan ibsame](transformers-server/README.md#quantized-safetensors--source-integration-29-october-2026) · [Akkaataa, dursa kennuu fi mirkaneessuu](docs/SUIVI_MOTEURS.md)

Maddoonni haaromfaman dabalaniiru **qaamolee filannoo bulfaman Qindeessitoota Windows x64 keessatti**: naannoowwan Paayitoon dhuunfaa, piroofaayilii CPU/CUDA pinned, tilmaama fi mirkaneessuu osoo hin buufachuu, mirkaneessuu, suphuu fi balleessuu. Daandiiwwan hiikkaa amala filannoowwan sadarkaa olaanaa jala turu. Mootoroonni dhalootaan GGUF qaamolee isaanii jiran ni eegu; mobaayila fi duumessaa desktop Python/PyTorch hin buufanne. Piroofaayiloonni dhuunfaa CPU/al-ergii sadii meeshaalee sintetiksii dhugaa ta’aniin shaakalaman; Kunuunsaan fayyadama deeskitooppii milkaa'aa ta'e 1 Sadaasa 2026 irratti gabaasa; GPU piroofaayilii fi clean-PC fe'iinsi ammallee adda ta'e, bal'inaan mirkaneessuu barbaachisa. [Profaayilii fi daangaa qorannoo](docs/REPRISE_COMPOSANTS_GERES_80_LANGUES.md). Tuullaa EXE keessatti galchuun yeroo biraatti darba.

| Qonna, nyaataa fi hawaasa baadiyyaa | Beekumsa qabatamaa qooddachuu, karoora deeggaruu fi meeshaalee naannootti faayidaa qaban qopheessuu. |
| Naannoo, haala qilleensaa, bishaanii fi heddummina lubbu qabeeyyii | Ragaa ni ibsu, ilaalcha deeggaru fi hawaasni pirojektoota akka karoorfatan gargaaruu. |
| Annisaa, industirii, ijaarsaa fi hojii harkaa | Sanada deeggarsa, dizaayinii, suphaa, barumsa teeknikaa fi fooyya’iinsa adeemsaa. |
