እነዚህ የአስተዋጽኦ እና የዕድገት አቅጣጫዎች እንጂ እያንዳንዱ ሴክተር ተኮር አፕሊኬሽን ቀድሞ ቀርቧል ወይም ተረጋግጧል ማለት አይደለም። ለዕለታዊ አጠቃቀም ቀላል መመሪያ፣ አስፈላጊ በሚሆንበት ጊዜ የላቁ አማራጮችን፣ ግልጽ የሃርድዌር እና የደመና መስፈርቶች፣ እና እያንዳንዱን መስክ እና አካባቢያዊ አውድ ከሚያውቁ ሰዎች ጋር ትብብር እንፈልጋለን።
